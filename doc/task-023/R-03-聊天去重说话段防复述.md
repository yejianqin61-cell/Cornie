# R-03 聊天去重-说话段防复述（Speak Prompt Anti-Echo）

## 背景

Cornie-023 §3.1 问题一次因：`streamFinalSpeak`（`orchestrator.js:67-78`）+ `buildSpeakPrompt`（`orchestrator.js:57-64`）把 finalReply 原文整段喂给模型要求"重新说一遍"，模型易原样复述/回声 → 单条气泡内出现两句一样。

## 目标

1. 说话段 prompt 去掉 finalReply 原文整段回显，改为传"要点"。
2. 加负向约束：禁止逐字复述/重复原句。
3. 说话段仍保持"铃湾口吻、一两句话"的自然重说语义。

## 范围

- `electron/backend/agent/orchestrator.js`（`buildSpeakPrompt`）
- `tests/orchestrator/conversation-orchestrator.test.mjs`（若可测：prompt 文本断言）

## 设计要求

### 1. Prompt 改造

- 现状（大意）：`请把下面这版回应，用你自己的口吻重新说一遍……你心里想好的回应：${assistantReply}`。
- 目标：把"回应原文"替换为**要点摘要式**输入（如只保留关键信息点/意图，不给整句原文），并追加负向约束：`不要逐字复述或重复原句；用新的句子表达同样的意思；不要加引号、不要解释、不要 Markdown。`
- 注意保持最终回复语义不丢：若直接删原文可能让模型编造——折中：原文保留但明确"这是内容草稿，请用完全不同的句子重新组织，禁止原样重复"。
- 实现时以实际对话质量为判据：优先"要点化"，若要点化导致信息丢失，则保留原文 + 强负向约束。

### 2. 兼容性

- 流式路径（streamFinalSpeak）与非流式路径（无说话段）行为不变；speak 失败仍 fallback 到信封回复（现有 catch 逻辑保留）。

## 验收标准

1. `buildSpeakPrompt` 输出包含防复述负向约束（文本断言）；不再整段回显原文（或明确标注为草稿+禁止复述）。
2. 现有 orchestrator 流式测试不回归；`npm run test:full` 全绿。
3. 人工冒烟（可选）：本地对话确认说话段不与最终回复逐字重复。
4. 提交为 `fix(backend): ...` 单提交，符合 commit 规范。

## 依赖

- 无（P1，独立可穿插；若 R-01/R-02 后实际输出已无复述，可仅加负向约束）。
