# R-10 按钮强调与说明弱化（CTA Prominence & Hint De-emphasis）

## 背景

Cornie-023 §3.3 按钮不突出典型区块：
- `ObserveMemoryHome.vue:208-211`："去聊天"主 CTA 做成句内文字链（`omQuickLink`），被 30 字说明包裹。
- `MemoryWikiTopicIndexPanel.vue:18-20,55`：卡头三行文案，唯一"保存主题别名"按钮藏在详情区尾部。
- `MemoryPageList.vue:192-198`：区块头无动作，主按钮"新建记忆"（:144）被 hint 稀释。
- `MemoryWikiGovernanceDetailPanel.vue:15-21`：approve/defer/reject 三按钮在长 subhint+cardHint 之下。

## 目标

1. 主 CTA 一律实心 primary 按钮，禁文字链冒充按钮。
2. 说明文字移卡片尾部弱化（`--muted` 小字），不夹在标题与按钮之间。
3. 高频动作按钮在视觉层级中突出（区块头右侧/首屏可见）。

## 范围

- `src/renderer/components/ObserveMemoryHome.vue`（或 R-04 拆分后的观察/记忆 home）
- `src/renderer/components/MemoryWikiTopicIndexPanel.vue`、`MemoryWikiGovernanceDetailPanel.vue`、`MemoryPageList.vue` 等（按钮层级调整）
- `src/renderer/style.css` 或各组件 scoped 样式（primary 按钮强化、hint 弱化类）
- `tests/frontend/` 新增/更新断言（按钮为真 button、样式类存在）

## 设计要求

### 1. 按钮语义化

- 文字链冒充按钮（omQuickLink 等）改为真 `<button>`（实心 primary 或明确定级的 ghost），或并入区块 CTA。
- 高频动作（新建记忆、记一件小事、保存、确认中心操作）在卡头右侧或首屏按钮位，不藏在长文案后。

### 2. 说明弱化

- 说明文字统一弱化样式（`--muted`、小字号、卡尾位置）；卡头只放标题 + 主按钮。
- 与 R-09 协同：文案删除后自然让位给按钮。

### 3. 兼容

- 交互行为不变（只改视觉层级与元素类型）；键盘可达性保持（button 天然可达）。

## 验收标准

1. 抽查区块：主 CTA 为 `<button>` 且实心样式；无"文字链冒充按钮"。
2. 卡头结构 = 标题 + 主按钮（无长说明夹在中间）。
3. `npx vitest run tests/frontend` 全绿（a11y/dead-interaction 等既有断言不回归）。
4. 人工冒烟：各首页主按钮一眼可见、可点。
5. 提交为 `fix(frontend): ...` 单提交，符合 commit 规范。

## 依赖
