# R-04 记忆三栏-导航入口拆分（Three-Column Navigation Split）

## 背景

Cornie-023 §3.2 M1/M2：左侧导航"观察与记忆"（`App.vue:29`）一个入口混装"观察日志 + 记忆 Wiki"两个概念，日记独立成栏 → 无"三栏"结构；ObserveMemoryHome 首页先"记一件小事"再记忆、记忆只显示身份 4 类、观察被压到底部（`ObserveMemoryHome.vue:206-295,69`）。

用户期望：记忆层鲜明分为**观察日志 / 当天日记 / 记忆 Wiki** 三栏。

## 目标

1. 左侧导航拆为「观察日志」「当天日记」「记忆 Wiki」三个平级入口（替代原"观察与记忆"单入口；原「日记」入口更名"当天日记"）。
2. 各入口独立 home 视图：观察日志 home（当天观察 + 记一件小事入口）、记忆 Wiki home（列表/翻阅入口 + 最新记忆 + 新建入口）。
3. 旧 ObserveMemoryHome 拆解：观察相关区块归观察日志 home，记忆相关区块归记忆 Wiki home。

## 范围

- `src/renderer/App.vue`（sections 数组、mode 状态机、视图挂载）
- `src/renderer/components/ObserveMemoryHome.vue`（拆解为 观察日志 home + 记忆 wiki home 两个组件，或保留 ObserveMemoryHome 做记忆 wiki home + 新建观察 home）
- `src/renderer/components/MemoryPageList.vue`（记忆 wiki home 的入口复用/调整）
- `tests/frontend/app-navigation.test.mjs`、相关组件测试（适配导航变更）

## 设计要求

### 1. 导航结构

- sections 增/改：`{ id: 'observe', label: '观察日志', ... }`、`{ id: 'diary', label: '当天日记', ... }`、`{ id: 'memory', label: '记忆 Wiki', ... }`；移除原 `observe-memory`。
- mode 状态机与子视图（omView 等）按新 id 迁移；观察日志与记忆 Wiki 各自独立子视图栈（如 observeView / memoryView）。

### 2. 首页拆分

- **观察日志 home**：当天观察记录（列表/最近 N 条）+ "记一件小事"入口（快速记录）+ 查看全部观察。
- **记忆 Wiki home**：记忆页概览（**全部页类型**，去掉身份 4 类过滤）+ 最新记忆 + 新建记忆 + 查看完整列表。
- 旧 ObserveMemoryHome 中"去聊天告诉铃湾"引导按 ID-10 弱化或移除（与 R-09 文案批次协同）。

### 3. 兼容

- 现有 @go 跳转（memory-detail / observation-detail / observation-list / memory-create 等）在新结构下保持可达；旧 `goChat` 等事件语义不变。
- 前端测试（app-navigation、memory-page-user-flow、observe 相关）随导航调整适配，行为不回归。

## 验收标准

1. 导航渲染三个入口（观察日志 / 当天日记 / 记忆 Wiki），点击进入各自 home；原"观察与记忆"入口消失。
2. 观察日志 home 只含观察内容；记忆 Wiki home 含全部页类型记忆（含 event/topic/goal 等普通类型）。
3. `npx vitest run tests/frontend` 全绿（导航/记忆/观察相关测试适配后通过）。
4. 提交为 `refactor(frontend): ...` 单提交（可拆 2 个：导航结构 / 首页拆分，各保持全绿），符合 commit 规范。
