# R-09 文案精简-按文件批次（Copy Slimming）

## 背景

Cornie-023 §3.3：前端约 **28 处 A 类**（产品/功能说明）+ 12 处 B 类（操作引导）+ 8 处 C 类（空态/错误）。A 类密度集中在 Memory Wiki 工作台（8 个子面板卡头说明）与观察/记忆首页。Top 清单见 Cornie-023 §3.3（W1-W16）。

## 目标

1. A 类产品/功能说明删除或压成一行（≤6 字副标题）。
2. B 类操作引导压到 8 字内。
3. C 类空态保留但 ≤15 字；同一概念只保留一处。
4. 按文件批次落地，每批测试全绿。

## 范围

- 按批次处理（建议 3 批）：
  - 批次 1：Memory Wiki 工作台面板（`MemoryWikiWorkspaceHead`、`GovernanceQueuePanel`、`ConfirmationPanel`、`GovernanceDetailPanel`、`PageListPanel`、`TopicIndexPanel`、`VersionPanel`、`PageEditorPanel`——W1-W9）
  - 批次 2：记忆/观察普通页面（`MemoryPageList` W10、`MemoryPageDetail` W11、`ObserveMemoryHome` W12-13、`ObservationList` W14、`ObservationDetail` W15）
  - 批次 3：业务页与收尾（`LedgerHome` W16、`DiaryHome`、`TodoHome`、`ScheduleHome` 等 B 类压缩 + 全仓复查）
- `tests/frontend/` 新增文案断言测试

## 设计要求

### 1. 分级标准

- 卡头：标题 + ≤6 字副标题（如"治理建议"→ 可无副标题）。
- "这是什么"（A 类）：删除。
- "怎么用"（B 类）：≤8 字（如"先选页面，再编辑"）。
- 空态/错误（C 类）：保留，≤15 字。
- 同一概念只留一处（如"不会写成流水账"在 ObserveMemoryHome 与 ObservationList 出现 4 次，只留观察日志首页一处）。

### 2. 表单引导移入占位符

- MemoryPageDetail 已示范（placeholder 承载引导）；其余页面（ObserveMemoryHome 快速记观察等）跟进。

### 3. 文案断言

- 新增断言测试：抽样 A 类清单文案（W1/W2/W5/W12 等 5-8 条）在对应组件渲染后不存在；B 类抽查长度（≤8 字）。

## 验收标准

1. A 类 Top 清单文案从渲染文本消失（断言通过）；B 类压缩到位。
2. 空态/错误文案保留且不超长；无功能损失（按钮/跳转/交互不变）。
3. `npx vitest run tests/frontend` 全绿（文案断言 + 既有用例）；若既有测试断言旧文案，同步适配（逐条说明）。
4. 提交：每批一个 `refactor(frontend): ...` 或 `fix(frontend): ...` 提交（共 3 批左右），各保持全绿，符合 commit 规范。
