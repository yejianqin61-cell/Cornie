# R-06 记忆详情-阅读与编辑两态（Read / Edit Dual Mode）

## 背景

Cornie-023 §3.2 M4：`MemoryPageDetail.vue:355` 整卡即编辑表单，无独立阅读态——查看记忆像"打开一个表单"，体验差；来源溯源等区块（:398-472）与表单混排，语义穿插。

## 目标

1. 详情默认**阅读态**：标题/摘要/正文/来源/相关页干净排版，弱化展示。
2. "编辑"按钮进入**编辑态**（现有表单），保存/取消返回阅读态。
3. 新建页保持直接编辑态（无阅读态）。

## 范围

- `src/renderer/components/MemoryPageDetail.vue`（拆阅读/编辑两态）
- `tests/frontend/memory-page-user-flow.test.mjs`（适配：默认阅读态、编辑切换）

## 设计要求

### 1. 阅读态

- 展示：类型标签 + 标题 + 摘要 + 正文（markdown/纯文本按现状）+ 来源溯源（chat/observation/related，弱化小字）+ 相关页链接。
- 操作：编辑（primary）、归档/恢复（次要）、删除（danger，确认流保留）。
- 不渲染表单字段（identity 字段等阅读时折叠为"详情字段"块或隐藏）。

### 2. 编辑态

- 复用现有表单与保存逻辑（`savePage` 等不变）；保存成功回到阅读态（刷新数据）。
- 取消编辑回到阅读态（丢弃未保存改动需确认——沿用现有 dirty 守卫）。

### 3. 新建

- `memory-create` 模式直接编辑态（isCreateMode 逻辑保留）；创建成功后进入阅读态。

### 4. 兼容

- 对外接口（props id / emits back/created/deleted/open-*）不变；App.vue 挂载方式不变。
- 来源跳转（open-chat-source / open-observation / open-memory）在阅读态可用。

## 验收标准

1. 详情默认渲染阅读态（无表单控件）；点"编辑"进入表单；保存/取消返回阅读态且数据正确。
2. 新建流程直接编辑态，创建后阅读态。
3. 来源溯源/相关页在阅读态可跳转；`npx vitest run tests/frontend` 全绿（memory-page-user-flow 适配后通过）。
4. 提交为 `refactor(frontend): ...` 单提交，符合 commit 规范。
