# R-08 日记-当天观察联动（Diary & Observation Linkage）

## 背景

Cornie-023 §3.2 M6：`DiaryHome.vue:64-77` 双栏（我今天写的 + 铃湾今天写的）与观察/记忆零联动——用户期望"观察 → 日记 → Wiki"形成阅读流。

## 目标

1. 当天日记首页双栏旁增加"当天观察"片段入口（展示当天观察摘要 N 条 + 跳观察日志）。
2. 形成"当天观察 → 当天日记 → 记忆 Wiki"的阅读路径。

## 范围

- `src/renderer/components/DiaryHome.vue`（新增当天观察区块）
- `src/renderer/api.js`（若需：`listObservations({ date })` 已有，复用）
- `tests/frontend/app-diary-flow.test.mjs`（新增联动断言）

## 设计要求

### 1. 当天观察区块

- DiaryHome 加载当天观察（`listObservations({ date: today, limit: N })`），展示摘要列表（标题 + 类型），点击跳观察日志当天视图（或观察详情）。
- 区块位置：日记双栏之下或侧栏；弱化样式（不抢占日记主体）。
- 空态："今天还没有留下观察"（C 类文案，简短）。

### 2. 跳转

- 跳观察日志当天（R-04 后 observe 入口的当天视图）或观察详情；跳转路径在新导航结构下可达。

### 3. 兼容

- 日记编辑/回顾流程不变；加载失败静默（不阻断日记页）。

## 验收标准

1. DiaryHome 渲染"当天观察"区块（有条目时显示摘要；无条目时简短空态）。
2. 点击观察条目跳转观察日志当天/详情；`npx vitest run tests/frontend` 全绿（app-diary-flow 适配后通过）。
3. 提交为 `feat(frontend): ...` 单提交，符合 commit 规范。

## 依赖

- R-04（观察入口新结构）。
