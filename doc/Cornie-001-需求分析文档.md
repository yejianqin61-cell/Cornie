## 1. 产品概述

### 1.1 产品背景

用户在日常记录与回忆回顾的场景中，发现现有工具存在以下问题：

- **日记类应用**：功能冰冷，缺乏情感陪伴，用户难以坚持
- **桌宠类应用**：停留于简单的娱乐互动，缺乏深层价值
- **AI助手应用**：多为云端服务，隐私顾虑大，缺乏个性化的长期陪伴
- **往年今日功能**：虽有部分应用支持，但缺乏“第二视角”的情感厚度

基于上述痛点，结合创始人个人对“独角山羊”形象的喜爱，以及对“铃湾”这个名字的情感沉淀，决定开发Cornie（铃湾）——一个将桌宠陪伴、双视角日记、本地AI深度融合的桌面应用。

### 1.2 产品定位

**一只趴在屏幕角落的独角山羊，用双视角日记为你守护每一段回忆。**

Cornie不是一个“工具”，而是一个“存在”。它不是被用户“使用”的，而是被用户“相处”的。

### 1.3 核心价值主张

| 价值维度     | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **陪伴价值** | 一个永远在屏幕右下角的、有生命的、会回应的存在，提供持续的情感陪伴 |
| **记录价值** | 不仅记录“用户写了什么”，还生成“Cornie看到了什么”，形成独特的双视角日记 |
| **时间价值** | “往年今日”功能，让回忆从孤立的日期变成跨越时空的对话         |
| **隐私价值** | 所有数据本地存储，大模型本地运行，无须联网，用户完全掌控自己的数据 |

### 1.4 目标用户画像

| 用户类型       | 特征描述                                              |
| -------------- | ----------------------------------------------------- |
| **记录者**     | 有写日记习惯或希望养成该习惯的人，注重生活记录        |
| **陪伴需求者** | 需要情感陪伴、喜欢桌宠/养成类元素的用户，多为年轻群体 |
| **成长复盘者** | 注重个人成长、喜欢回顾过去、进行自我复盘的用户        |
| **隐私敏感者** | 对数据隐私高度关注，不愿将日记内容上传云端的技术人群  |

### 1.5 竞品分析

| 竞品类型  | 代表产品          | 优势             | 劣势                           | Cornie的差异化                             |
| --------- | ----------------- | ---------------- | ------------------------------ | ------------------------------------------ |
| 纯桌宠    | Bongo Cat、桌面喵 | 轻量、可爱       | 无记录功能，停留于娱乐         | 桌宠+日记深度融合                          |
| 纯日记App | Moo日记、Day One  | 记录功能成熟     | 无“生命体”陪伴感               | Cornie作为“第二视角”共同记录               |
| AI伴侣    | Replika、Glow     | 对话能力强       | 云端服务，隐私存疑，无时间维度 | 本地运行+往年今日+双视角                   |
| 日记+宠物 | 回音岛            | 宠物有性格可聊天 | 宠物不写日记，无往年今日       | Cornie独立撰写日记，形成时间轴上的双线叙事 |

## 2. 产品命名与形象

### 2.1 命名体系

| 名称类型 | 名称       | 读音              | 使用场景                         |
| -------- | ---------- | ----------------- | -------------------------------- |
| 英文名   | **Cornie** | /ˈkɔːrni/ “扣-昵” | 应用名称、界面文字、国际市场     |
| 中文名   | **铃湾**   | líng wān          | 中文应用名、正式称呼             |
| 小名     | **湾湾**   | wān wān           | 亲密场景、用户与Cornie互动时自称 |

### 2.2 命名内涵

**Cornie**：

- C-o-r-n-i-e，五个字母，-ie结尾自带“小东西/亲近的人”的昵称感
- 与“Corny”（意为“陈词滥调”“老套”）区分，寓意“新鲜”“原创”“独特”

**铃湾**：

- **铃**：脖子上铃铛的意象，代表空灵、调皮、圣洁。铃铛声提醒用户每一个该被记住的瞬间
- **湾**：水也。象征温柔随和、包容接纳、能流过一切坎坷。读音婉转，读完嘴角自然上扬
- **叶铃湾**：创始人珍藏多年的、为未来女儿准备的名字，赋予产品深厚的情感底蕴

### 2.3 形象设定

| 部位     | 设计描述                                                     | 设计寓意                                                     |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 物种     | 只有一只角的山羊                                             | 灵感源自电影《神偷奶爸3》中的Lucky；接纳“不完美”，不完美的反而是最独特的 |
| 额角     | 半透明水晶质感，会凝聚“回忆的露水”                           | 记忆的容器，时间的结晶                                       |
| 铃铛     | 脖子上悬挂，摇响时发出“水滴落潭”的声音（“叮——咚——”），非普通铃声 | 听觉上的“水”元素；将铃铛声与水声融合                         |
| 尾巴     | 一小截“凝固的水波”，半透明，Q弹质感，会随情绪变化形态        | 视觉上的“水”元素；“湾”的具象化                               |
| 身下     | 一小片浅浅的、泛着微光的水镜，作为栖息之地                   | “湾”的空间锚点；Cornie趴在哪里，哪里就是安全的港湾           |
| 常驻位置 | 电脑屏幕右下角                                               | 安静、不打扰、始终可见的陪伴位置                             |
| 状态行为 | 有呼吸感、会眨眼、会打盹、尾巴会动、铃铛会响                 | 营造“活着”的幻觉，而不仅仅是一个静态图片                     |

### 2.4 品牌Slogan（备选）

> *“Cornie，趴在你的角落，吃掉旧时光，吐出温暖的回忆。”*

> *“铃湾——你的第二双眼睛，你的记忆港湾。”*

> *“一只角的山羊，一辈子的陪伴。”*

### 3.2 MVP版本（v0.5）——验证核心闭环

**目标**：以最快速度验证“用户通过**对话**与Cornie互动 → Cornie自动生成日记 → 用户可查看双视角日记和往年今日”的核心闭环。

**核心洞察**：MVP阶段的Cornie日记，**不是基于用户写的“日记文本”生成的，而是基于用户与Cornie的“对话内容”自动生成的**。也就是说，用户甚至不需要“写日记”——只需要像和朋友聊天一样和Cornie说话，Cornie就会在每天结束时（或对话后），自动生成一篇“Cornie视角的日记”，记录下今天聊了什么、主人心情如何。

#### 3.2.1 桌宠模块

| 功能点   | 描述                                                         | 优先级 |
| -------- | ------------------------------------------------------------ | ------ |
| 桌面显示 | Cornie常驻桌面右下角，透明背景，始终置顶                     | P0     |
| 呼吸动画 | 待机状态有微弱的呼吸起伏感，伴随眨眼                         | P0     |
| 点击反馈 | 点击Cornie时：铃铛晃动 + 尾巴摆动 + **打开对话框**（而非随机文字气泡） | P0     |
| 窗口穿透 | 点击Cornie身体区域可交互，点击背景区域穿透到下层桌面         | P0     |

#### 3.2.2 对话模块（新增，核心）

| 功能点           | 描述                                                         | 优先级 |
| ---------------- | ------------------------------------------------------------ | ------ |
| 对话框           | 点击Cornie后弹出聊天窗口，用户可输入文字与Cornie对话         | P0     |
| AI回复           | Cornie使用本地Qwen3.5模型回复用户，语气温柔、童真、带一点调皮 | P0     |
| 对话存储         | 所有对话内容按日期存储到本地数据库，关联当日日记             | P0     |
| 对话上下文       | 同一日内的对话保持上下文连贯性（同一会话）                   | P0     |
| 多轮对话         | 支持用户与Cornie进行多轮自由对话                             | P0     |
| 快捷入口         | 对话框提供“我今天很开心”“我今天有点累”“没什么特别的”等快捷语句 | P1     |
| 语音输入（可选） | 支持语音转文字输入（调用系统语音识别）                       | P2     |

#### 3.2.3 双视角日记（核心：基于对话生成）

| 功能点                 | 描述                                                         | 优先级 |
| ---------------------- | ------------------------------------------------------------ | ------ |
| **Cornie日记自动生成** | 每天最后一次对话结束后（或用户主动触发/每天固定时间），Cornie基于**当日所有对话内容**，自动生成一篇“Cornie视角的今日日记” | P0     |
| 生成规则               | Cornie日记采用第一人称，总结今天聊了什么、主人的情绪、Cornie的感受，语气温柔、童真，字数50-150字 | P0     |
| 用户日记（可选）       | 用户可额外撰写传统日记（纯文本），若不写，则“用户日记”字段可为空，仅展示Cornie日记 | P0     |
| 日记存储               | 日记（用户日记+Cornie日记）与对话记录关联存储，以日期为键    | P0     |
| 日记查看               | 用户可在日历视图中查看历史日记，切换查看“我的日记”（若有）和“Cornie的日记” | P1     |
| 日记编辑               | 用户可编辑Cornie生成的日记内容（若AI总结不准）               | P1     |
| 重新生成               | 用户对Cornie日记不满意时，可点击“重新生成”，Cornie基于同一天的对话重新生成一篇 | P0     |

#### 3.2.4 往年今日

| 功能点     | 描述                                                         | 优先级 |
| ---------- | ------------------------------------------------------------ | ------ |
| 日期定位   | 首页默认展示“历史上的今天”，显示往年同日是否有日记（优先展示Cornie日记） | P0     |
| 双视角展示 | 若有日记，同时展示往年同日的用户日记（如有）和Cornie日记     | P0     |
| 跳转查看   | 点击可跳转至完整日记页面，并可查看当日的完整对话记录         | P1     |
| 无记录提示 | 若无往年记录，显示Cornie的安慰文案：“那时候我还没出生呢，不过现在我在了。” | P1     |

#### 3.2.5 本地化与隐私

| 功能点     | 描述                                                      | 优先级 |
| ---------- | --------------------------------------------------------- | ------ |
| 完全本地   | 所有对话记录、日记数据本地存储，不上传任何服务器          | P0     |
| Ollama集成 | 应用启动时检测Ollama及Qwen3.5模型可用性，未安装时引导用户 | P0     |
| 离线可用   | 不依赖互联网连接，所有功能离线可运行                      | P0     |
| 数据清除   | 用户可一键删除所有对话和日记数据                          | P1     |

#### 3.2.6 MVP不包含的功能

- 情绪标签手动选择（但从对话中可自动判断情绪）
- 多设备同步
- 皮肤/主题系统
- 图片附件
- 成就系统
- 复杂的尾巴情绪系统（MVP仅为简单的静态尾巴，V1再做动态）
- 主动提醒（V1再做）

### 3.3 V1版本（v1.0）——完善与深化

**目标**：在MVP基础上，提升交互深度和情感共鸣，使Cornie具备公开发布所需要的完整度和精致度。

#### 3.3.1 桌宠交互深化

| 功能点       | 描述                                                         | 优先级 |
| ------------ | ------------------------------------------------------------ | ------ |
| 尾巴情绪系统 | 尾巴根据对话情绪和情境变化形态（开心时翘起摇摆、难过时耷拉、长时间不理时缩成水珠） | P0     |
| 多状态动画   | 增加瞌睡、开心、好奇、思考（生成日记时）等状态动画           | P0     |
| 点击不同部位 | 点击角/铃铛/尾巴触发表情或小动作（非对话）                   | P1     |
| 鼠标跟随     | Cornie眼睛/头部轻微跟随鼠标移动                              | P0     |
| 铃铛视觉反馈 | 对话过程中、日记生成完成时，铃铛晃动并播放水滴声             | P0     |

#### 3.3.2 对话功能增强

| 功能点        | 描述                                                         | 优先级 |
| ------------- | ------------------------------------------------------------ | ------ |
| 主动发起对话  | Cornie会根据条件（长时间未对话、往年今日提醒、固定时间）主动问候用户 | P0     |
| 情绪感知      | Cornie在对话中能识别用户情绪词（开心、难过、累等），做出相应回应 | P0     |
| 长期记忆      | Cornie能够记住之前对话中提到的重要信息（如用户名字、宠物名字、重要日期），在后续对话中引用 | P0     |
| 对话历史查看  | 用户可按日期查看与Cornie的完整对话记录                       | P1     |
| 删除/编辑对话 | 用户可删除或编辑某条对话，Cornie日记同步更新                 | P1     |
| 多种语气风格  | 用户可在设置中调整Cornie的语气（更活泼/更安静/更幽默）       | P1     |

#### 3.3.3 双视角日记增强

| 功能点           | 描述                                                         | 优先级 |
| ---------------- | ------------------------------------------------------------ | ------ |
| 日记统计         | 展示总对话天数、Cornie写日记总数、累计对话条数等             | P0     |

| 日记分享（脱敏） | 用户可选择匿名分享Cornie日记到社交媒体（纯文本，不含隐私信息） | P1     |
| 每日总结         | 每天固定时间（如晚上10点），Cornie主动生成当日日记并提示用户查看 | P0     |

#### 3.3.4 提醒功能（新增）

| 功能点       | 描述                                                     | 优先级 |
| ------------ | -------------------------------------------------------- | ------ |
| 喝水提醒     | Cornie定时提醒用户喝水，用户可通过对话回复“喝了”或“等会” | P0     |
| 休息提醒     | 每隔一段时间（可设置）提醒用户站起来活动                 | P0     |
| 日记提醒     | 每晚提醒用户“今天还没聊天哦”，鼓励对话                   | P0     |
| 往年今日提醒 | 有往年今日记录时，启动时Cornie提醒                       | P0     |

#### 3.3.5 往年今日增强

| 功能点     | 描述                                                         | 优先级 |
| ---------- | ------------------------------------------------------------ | ------ |
| 对话回放   | 查看往年今日时，除了日记，还可查看当天的对话记录（精华片段） | P0     |
| 对比视图   | 同时展示往年今日的对话情绪标签对比（如“去年今天你聊了很多开心的事”） | P1     |
| 时光机动画 | 查看往年今日时，Cornie播放特殊动画（尾巴涟漪、铃铛响、角发光） | P0     |

#### 3.3.6 设置与数据

| 功能点         | 描述                                                     | 优先级 |

#### 3.3.7 V1不包含的功能

- 皮肤/主题市场

### 3.4 V2版本（v2.0）——智能化与生态扩展

**目标**：围绕“长期陪伴”与“深度记忆”，增加更智能的特性，并扩展用户触点。

#### 3.4.1 智能化升级

| 功能点         | 描述                                                         | 优先级 |
| -------------- | ------------------------------------------------------------ | ------ |
| 情绪趋势分析   | 基于长期对话内容，分析用户情绪变化趋势，生成可视化报告       | P0     |
| 主动关怀       | Cornie根据情绪趋势（如连续低落）主动发起关怀对话             | P0     |
| 成长纪事       | 自动生成“季度回忆录”：这三个月的重要对话、情绪变化、Cornie的陪伴记录 | P0     |
| 关联推荐       | “今天和你去年今日聊的话题很像呢”“你每次提到项目上线都会紧张” | P1     |
| 自定义模型微调 | 高级用户可基于自己的对话数据对模型进行轻量微调（LoRA）       | P2     |

## 5. 技术架构概要

### 5.1 核心技术栈

| 层级       | 技术选型                 | 说明                             |
| ---------- | ------------------------ | -------------------------------- |
| 桌面框架   | Electron                 | 跨平台桌面应用容器               |
| 前端框架   | Vue 3                    | UI构建                           |
| 动画引擎   | Live2D                   | 桌宠动画（呼吸、眨眼、情绪反应） |
| 本地数据库 | SQLite                   | 轻量级本地存储                   |
| 本地大模型 | Qwen3.5 (通过Ollama调用) | 日记生成 + 对话                  |
| 模型调用   | IPC + 子进程             | Electron主进程调用Ollama API     |
| 打包分发   | electron-builder         | 生成安装包，支持代码签名         |

### 5.2 架构原则

- **本地优先**：所有数据处理、存储、AI推理均在用户本地完成
- **离线可用**：不依赖互联网连接，任何网络环境下功能完整
- **隐私第一**：不上传任何用户数据，Ollama模型调用不经过任何中间服务器
- **轻量优雅**：在保证功能完整性的前提下，尽可能降低资源占用

### 5.3 数据流示意

text

```
用户撰写日记 → 存入SQLite → 触发Cornie日记生成请求
         ↓
主进程调用Ollama（Qwen3.5，本地推理）
         ↓
生成结果返回 → 存入SQLite（关联用户日记） → 前端展示
         ↓
用户可查看/编辑/重新生成Cornie日记
```

## 6. 用户故事

### 6.1 核心场景故事

**场景一：初次见面**

> 小张下载并安装了Cornie。首次启动时，一只白色的小山羊出现在屏幕右下角，周围泛着淡淡的水光。它摇了摇铃铛，发出“叮——咚——”的清脆水声，气泡里显示：“我是Cornie，中文名叫铃湾。我是一只只有一只角的山羊，以后请多多关照。”

**场景二：日常记录**

> 小张写了一天的代码，晚上打开Cornie，点击日记本开始写：“今天解决了两个bug，很有成就感。”写完后，Cornie的尾巴轻轻摆了几下，铃铛轻响一声。几秒钟后，Cornie的日记生成：“今天主人一直在认真敲键盘，偶尔会皱眉头，但最后开心地伸了个懒腰。我虽然不太懂代码，但我觉得主人好厉害。”

**场景三：往年今日**

> 一年后的某天，小张打开Cornie。屏幕右下角，Cornie的尾巴散开一圈涟漪，弹出提示：“今天有去年的回忆哦。”点击查看，屏幕上并排显示去年的今天：小张写的是“刚学React，脑子一团浆糊”，而Cornie当时写的是：“主人今天对着屏幕发了好久的呆，我用角碰了碰他，他回过头来冲我笑了笑。”

**场景四：心情低落**

> 小张连续一周没有写日记。Cornie的尾巴慢慢缩成了一颗小水珠。周末小张终于打开电脑，看到Cornie可怜的样子，点了一下它。Cornie抬起头说：“你最近是不是很忙？我一直在等你哦。”
