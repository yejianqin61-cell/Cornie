## 2. What it means

长期信息会带着用户消息来源写入页面。相关问题能读取记忆摘要，页面详情能显示来源预览。

高风险变更仍需先批准，之后才出现应用入口。页面级更正复用现有 API，不新增自动治理。

验证已通过：`npm run test:full`、`npm run build`、记忆组件测试和三条 Phase 3 服务测试。
