# 7.3 工具层能力对齐阶段验收

## 1. 文档目的

本文件用于证明 `7.3 工具层能力对齐` 已完成收口，并可无歧义转入 `7.4 最小测试体系`。

## 2. 本阶段目标回顾

根据 `doc/Cornie-004-当前模块实现度评估与下阶段开发建议.md` 与 `doc/Cornie-003-当前开发进度评估与下一阶段路线图.md`，`7.3` 的核心目标是：

- 补齐收支记录工具全生命周期
- 补齐待办与日程类目删除能力
- 修正日程 delete / cancel 语义
- 补齐系统只读工具
- 把新增工具同步收口到协议层与策略层

### 3.2 已对齐能力

#### 收支领域

- 已新增：
  - `ledger.get_entry`
  - `ledger.list_today`
  - `ledger.list_by_range`
  - `ledger.update_entry`
  - `ledger.delete_entry`

#### 待办 / 日程领域

- 已新增：
  - `todo_category.delete`
  - `schedule_category.delete`
- 已修正：
  - `schedule.cancel` 保留“状态取消”语义
  - `schedule.delete` 改为真实删除语义

#### 系统只读领域

- 已新增：
  - `settings.get_runtime_context`
  - `health.get_model_status`

#### 协议 / 风险 / 策略层

- `ledger.update_entry` 已纳入类目参数校验范围
- `settings.*` / `health.*` 已明确为低风险只读工具
- 系统只读工具已可由策略层直通放行
