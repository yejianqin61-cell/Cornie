# Cornie 009 前端交互与确认流模块改进设计

## 1. 模块目标

负责把 AI 的工具执行结果、确认请求、追问请求以清晰的前端交互方式呈现给人类用户。

## 2. 模块范围

- 工具执行结果展示
- 确认流 UI
- 追问 UI
- 观察日志 / 日记 / 记忆入口

## 3. 交互场景

| 场景 | 前端行为 |
| --- | --- |
| AI 自动记账成功 | 显示“已记录”提示 |
| 需要新增类目确认 | 弹出确认卡片 |
| 需要追问金额或类目 | 直接在对话中继续追问 |
| 写入长期记忆待确认 | 展示可同意/拒绝的确认项 |

## 4. 状态类型

- 普通回复
- 工具成功
- 工具失败
- 待确认
- 待追问
