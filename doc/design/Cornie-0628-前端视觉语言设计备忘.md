## 2. 文档目标

这份文档不是完整品牌手册，而是给前端重构阶段使用的视觉准绳。

目标只有一个：

`让 Cornie 从“灰蓝紫后台风”变成“温和、舒服、适合普通人长期使用的陪伴型桌面应用”。`

## 3. 当前视觉问题判断

基于当前样式现状，存在以下问题：

1. 深色背景 + 玻璃拟态 + 蓝紫点缀，整体偏冷、偏后台。
2. 页面块很多，但主次关系不强。
3. 留白不足，卡片边界太多。
4. 普通人打开后更像在看工具台，而不是在和铃湾相处。
5. 情绪气质偏“技术感”，不偏“陪伴感”。

## 4. 总体视觉方向

Cornie 的视觉方向建议定义为：

`温和、轻柔、清爽、有呼吸感、适合长期陪伴使用`

不是：

1. 科技控制台
2. SaaS 后台
3. 炫技玻璃风
4. 冷色深夜黑客风
5. 紫色 AI 套壳产品风

## 5. 色彩方向

## 5.1 总原则

1. 避免大面积纯深色背景。
2. 避免蓝紫为主的 AI 套路色。
3. 采用柔和、干净、偏自然的浅色体系。
4. 强调色要少，不要每个模块都抢。

## 5.2 推荐基底色

建议整体以浅暖中性色为主：

1. 奶白
2. 浅米色
3. 雾灰白
4. 极浅的暖灰

页面背景不要纯白，可以稍微带一点点暖意。

## 5.3 推荐强调色

建议从下面几类里选一组，不要全用：

1. 柔和珊瑚色
2. 雾粉色
3. 浅茶橙色
4. 鼠尾草绿
5. 低饱和海盐蓝

说明：

1. 强调色只用于主按钮、关键状态、小面积点缀。
2. 不要让强调色进入大面积背景。

## 5.4 模块色彩建议

建议不同模块可以有轻微色偏，但不要做成彩虹：

1. 聊天：暖白 + 柔和珊瑚
2. 日记：奶白 + 雾粉
3. 收支：浅米色 + 鼠尾草绿
4. 待办 / 日程：雾灰白 + 浅茶橙
5. 观察与记忆：暖灰白 + 海盐蓝

## 5.5 明确禁止

1. 不要默认紫色主导
2. 不要黑底蓝光
3. 不要赛博霓虹色
4. 不要大面积高对比渐变

## 6. 字体与排版方向

## 6.1 字体原则

1. 避免明显后台系统感的默认字体堆叠表现。
2. 中文场景优先考虑温和、清晰、适合长时间阅读。
3. 标题要有一点情绪感，但不能花哨。

## 6.2 排版原则

1. 标题层级要明显
2. 正文字重不要太重
3. 行距要松
4. 单屏文字块不要太密
5. 卡片里的说明文案不能像接口文档

## 6.3 文本气质

文字应当给人感觉：

1. 被温柔接住
2. 不被催促
3. 不被系统命令
4. 不被技术术语压迫

## 7. 留白与密度

## 7.1 总原则

Cornie 的页面要“有空气”，不能“塞满”。

## 7.2 页面密度建议

1. 一级页面首屏只放 3 到 5 个区块
2. 区块之间留出明显呼吸空间
3. 卡片内部 padding 要宽一点
4. 列表项不要挤成表格感

## 7.3 不要做成什么

1. 不要左右两栏都塞满
2. 不要一屏出现十几个操作按钮
3. 不要大量细边框分隔
4. 不要所有信息都卡片化

## 8. 卡片与容器风格

## 8.1 卡片原则

卡片不是越多越高级。

建议：

1. 重要信息用卡片
2. 次要信息直接做成轻区块
3. 卡片圆角柔和
4. 阴影很轻，不做悬浮控制台风

## 8.2 容器风格建议

1. 轻边框
2. 浅阴影
3. 低对比背景层次
4. 少量柔和分区

## 8.3 明确禁止

1. 大量玻璃拟态
2. 重模糊
3. 过多半透明叠层
4. 满屏霜玻璃卡片

## 9. 按钮与交互控件

## 9.1 主按钮

主按钮必须：

1. 明确
2. 温和
3. 看起来愿意点

不要：

1. 太硬
2. 太科技
3. 太系统工具化

## 9.2 次级按钮

次级按钮要明显退后，不和主按钮抢位。

## 9.3 危险按钮

危险按钮要提示风险，但不要像报错。

建议：

1. 用低饱和暖红
2. 只在真正危险时使用

## 10. 状态提示风格

## 10.1 成功提示

要像“已经帮你做好了”，不要像“操作成功 code 200”。

## 10.2 失败提示

要像“这次没做好，我们再试试”，不要像控制台报错。

## 10.3 加载状态

要轻，不要像系统在疯狂运行。

## 10.4 空状态

空状态应该：

1. 安静
2. 温柔
3. 不让用户觉得自己做错了

## 11. 动效原则

## 11.1 总原则

动效要少，但要自然。

## 11.2 建议动效

1. 页面淡入
2. 卡片轻微上浮
3. 列表项轻微过渡
4. 输入区域柔和聚焦

## 11.3 明确禁止

1. 大量弹跳
2. 夸张缩放
3. 强烈光效
4. 高频闪烁

## 12. 铃湾气质在视觉上的体现

铃湾的气质不应靠：

1. 满屏可爱贴纸
2. 过量粉色
3. 幼态插画堆叠

而应靠：

1. 温和的配色
2. 柔软的留白
3. 平静的文案
4. 轻轻的反馈
5. 不吓人的界面层级

## 13. 对当前样式的直接修正建议

当前 `style.css` 一眼能看出的方向问题包括：

1. 深色底
2. 蓝紫强调
3. 玻璃卡片
4. 后台风按钮

建议直接改成：

1. 浅色暖底
2. 低饱和强调色
3. 轻卡片或分区式布局
4. 更像生活应用而不是控制台

## 14. 给 Claude Code 的直接执行要求

做 UI 时请直接遵循：

1. 不要深色玻璃后台风
2. 不要紫色 AI 套路色
3. 不要大面积卡片堆墙
4. 要明显突出聊天与日记的情感主位
5. 要让普通人第一眼觉得“好亲近”
6. 要让页面看起来适合每天打开，而不是只适合演示

## 15. 最终结论

Cornie 的视觉语言，应当让用户觉得：

1. 这里不是系统后台
2. 这里有人味
3. 这里可以放心停留
4. 这里适合把生活交给铃湾一点点帮忙整理

一句话总结：

`Cornie 的视觉设计应该像温和陪伴型生活应用，而不是冷色技术面板。`
