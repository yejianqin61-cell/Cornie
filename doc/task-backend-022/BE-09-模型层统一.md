# BE-09 模型层统一（Model Layer Unification）

## 背景

模型层三处问题（Cornie-022 §3.3.1 B6 + §3.3.2 N6/N7）：

1. **fetch 脚手架双实现**：`model/deepseek/client.js:12-45`（deepseekFetch 非流式）与 `101-177`（chatStream）各自写 headers/错误映射/超时，chatStream 未复用。
2. **chatStream 无网络层重试**（协议轮重试在外层，网络层一次即败）。
3. **坏 SSE 行静默吞**：`client.js:161-163` 心跳/注释行与真坏数据无法区分。
4. **EOF 截断误标完成**（N7）：SSE 在 `[DONE]` 前 EOF 时 while 循环正常退出并返回 `finishReason:'stop'` 的部分内容——截断被伪装成完整回复。
5. **legacy 估计函数双实现**（N6）：`promptBuilder.js:152-172` 的 estimate 函数与 builder 同构（仅序列化方式不同）。

## 目标

1. 统一 fetch 封装（非流式/流式共用 headers/错误映射/超时）。
2. chatStream 网络层加指数退避重试（仅可重试错误）。
3. SSE 解析区分心跳/注释行；记录是否收到 `[DONE]`，EOF 未见 `[DONE]` 返回 `finishReason:'incomplete'`（由调用方决定回退）。
4. 删除 legacy 估计双实现（单一 builder 返回 prompt/chars/legacyChars）。

## 范围

- `electron/backend/model/deepseek/client.js`（统一 fetch + 重试 + EOF 完整性）
- `electron/backend/model/config.js`（如需重试配置）
- `electron/backend/agent/promptBuilder.js`（legacy 估计收敛）
- `electron/backend/agent/orchestrator.js`（EOF incomplete 的处理：回退非流式或标记）
- 新增 `tests/services/deepseek-client.test.mjs`（mock fetch/SSE：重试、EOF、坏行、超时）

## 设计要求

### 1. 统一 fetch

- 单一底层请求函数支持 `{ stream: false }` / `{ stream: true }`（或导出共用的 headers/错误映射/超时工具），chatStream 与 deepseekFetch 复用同一实现；错误分类（timeout/network/http）一致。

### 2. 重试

- chatStream 对可重试错误（网络瞬时失败/5xx）做指数退避重试（如 2 次、退避 200ms/400ms）；超时与协议层错误不重试（由外层处理）；重试次数计入 telemetry（attempt 字段，与 BE-05 的失败分类兼容）。

### 3. SSE 健壮性

- 心跳行（`:` 开头）与空行跳过且不告警；JSON.parse 失败的行记录一次（不再完全静默）但继续。
- 维护 `sawDone` 标记：EOF 时若未见 `[DONE]` → 返回 `{ finishReason: 'incomplete', ... }`（不抛也可，由调用方决定回退）；调用方（orchestrator 流式路径）对 incomplete 回退为非流式完整回复或错误提示。

### 4. legacy 估计收敛

- `buildLookupFollowupPrompt` 单一实现返回 `{ prompt, chars, legacyChars }`；删除 estimate 函数；orchestrator 的 `legacyPromptCharsEstimate` 消费点改读返回结构。

## 验收标准

1. 新增 `deepseek-client.test.mjs` 通过：网络错误重试（首次失败→重试成功）；5xx 重试；超时不重试；EOF 未见 `[DONE]` → `finishReason:'incomplete'`；坏行不中断；心跳行不触发事件。
2. 既有 orchestrator 流式测试不回归（incomplete 回退路径有覆盖）；`npm run test:full` 全绿。
3. 提交为 `refactor(backend): ...` 或 `fix(backend): ...` 单提交（可拆 2 个：fetch/重试/EOF / legacy 估计，各保持全绿），符合 commit 规范。
