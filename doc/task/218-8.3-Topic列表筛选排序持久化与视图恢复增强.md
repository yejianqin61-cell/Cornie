# 218-8.3-Topic列表筛选排序持久化与视图恢复增强

## 1. 任务目标

在 `210` Topic 列表搜索筛选体验基础上，继续补齐筛选、排序和当前列表视图的持久化与恢复能力，让用户在反复切换 Topic 详情和列表时，仍能保持浏览上下文。

## 2. 背景与现状

Topic 列表层一旦补齐搜索筛选，很快也会遇到和 Memory Wiki 列表类似的问题：

1. 切到详情页再回来后，列表条件丢失
2. 排序方式被重置
3. 用户重新进入列表时需要重新找主题

## 3. 涉及范围

- Topic 列表区
- 搜索 / 筛选 / 排序状态管理
- 对应前端测试

## 4. 前置依赖

1. `210-8.3-Topic搜索筛选与列表扫描体验增强.md` 已完成或至少已有 Topic 列表搜索筛选

## 5. 具体开发项

### 5.1 列表状态持久化

1. 记住主题搜索词
2. 记住筛选与排序条件
3. 记住最近选中的 Topic

### 5.2 返回列表时的恢复

1. 从 Topic 详情返回列表时恢复原条件
2. 若原 Topic 仍存在，恢复高亮或选中状态
3. 若条件已失效，优雅回落到默认列表

### 5.3 状态重置入口

1. 提供一键清空当前 Topic 列表条件
2. 避免持久化变成“看不懂为什么列表是空的”
3. 让恢复与重置入口都清楚可见

### 5.4 测试补齐

1. 覆盖列表条件持久化
2. 覆盖从详情返回后的恢复
3. 覆盖失效条件回落逻辑
4. 覆盖一键重置分支

## 6. 验收标准

1. 用户能在 Topic 列表与详情之间保持浏览连续性
2. 列表恢复逻辑稳定，不制造迷失感
3. Topic 列表更适合长期反复使用
4. 对应前端测试通过
