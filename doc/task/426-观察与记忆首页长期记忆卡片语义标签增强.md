# 426-观察与记忆首页长期记忆卡片语义标签增强

## 1. 任务目标

当前“观察与记忆”首页已经能展示：

1. 主身份优先卡
2. 其他最近长期记忆卡片

但其他长期记忆卡片仍然比较平，用户需要点进去才知道它是：

1. 重要的人
2. 你的偏好
3. 你的特征

本任务要为首页长期记忆卡片补上轻量语义标签和更清楚的阅读提示，让普通用户一眼就能分辨这些记忆大致在记什么。

## 3. 当前问题

首页其他长期记忆卡片现在主要只展示：

1. 标题
2. 摘要或正文截断

这会导致：

1. 卡片之间差异感不强
2. 普通用户要先点进去，才知道它到底是“人物记忆”还是“偏好记忆”
3. 首页的长期记忆区仍然偏像“文本列表”，不够像有层次的阅读入口

---

## 4. 设计原则

1. 标签要轻，不做后台字段暴露  
   用户看到的是“重要的人 / 你的偏好 / 你的特征”，而不是 `identity_person` 之类技术名。

2. 信息分层要清楚  
   至少让用户先看到“这张卡片在记什么类型的事”，再看标题和摘要。

3. 不喧宾夺主  
   主身份优先卡仍是最强入口，其他卡片只做轻量增强。

4. 保持首页阅读速度  
   增强后依然要一眼扫读，不要把卡片做得太重。

---

## 5. 具体改造

### 5.1 类型标签映射

为首页长期记忆卡片建立普通用户标签映射：

1. `identity_person` -> `重要的人`
2. `identity_preference` -> `你的偏好`
3. `identity_trait` -> `你的特征`
4. `identity_profile` -> `关于你`

### 5.2 卡片信息层次

对其他长期记忆卡片补充：

1. 顶部轻标签
2. 标题
3. 摘要正文

若需要，可再加一句极轻的辅助提示，但不要把卡片变成大说明块。

### 5.3 主身份卡保持更高优先级

主身份优先卡仍保持：

1. 更大面积
2. 更强背景强调
3. 不与普通卡片做成同层级外观

---

## 6. 验收标准

满足以下条件视为完成：

1. 首页其他长期记忆卡片具备清楚的普通用户类型标签
2. 用户一眼能分辨“人物 / 偏好 / 特征”大类
3. 不出现技术字段名
4. 主身份卡仍明显高于普通卡片
5. 构建通过，不影响首页现有跳转逻辑
