# 333-收支页日历筛选与图表可视化增强

## 1. 任务目标

将收支页从“能记录”升级为“能回看、能筛选、能理解”，补齐日历视图、图表视图和列表层次增强。

## 2. 对应来源

- GitHub Issue `#2` 收支页面更丰富一点
- 设计文档：`doc/design/Cornie-0629-GitHub-Issue-001-005前端体验增强落地设计.md`

## 3. 背景与现状

当前收支页已具备：

1. 本月概览
2. 快速记一笔
3. 最近记录
4. 类目入口

但缺少：

1. 按日期定位收支的入口
2. 图形化理解支出结构和趋势的能力
3. 列表层面对收入/支出的强区分

## 4. 涉及范围

- `src/renderer/components/LedgerHome.vue`
- `src/renderer/components/LedgerWorkspace.vue`
- `src/renderer/api.js`
- 如需新增图表组件，可新增：
  - `src/renderer/components/LedgerCalendar.vue`
  - `src/renderer/components/LedgerCategoryChart.vue`
  - `src/renderer/components/LedgerTrendChart.vue`

## 5. 前置依赖

1. 收支列表接口可返回足够的日期、类目、金额信息。
2. 当前收支工作台已能稳定新增和刷新记录。

## 6. 拆分策略

本任务工作量较大，要求按三个阶段落地，避免一口气做成大杂烩。

### 阶段 A：列表增强

#### 6.1 列表信息补齐

每条记录至少清晰展示：

1. 事项名称
2. 类目名称
3. 日期
4. 金额

#### 6.2 收入支出强区分

1. 收入与支出使用高对比度颜色区分。
2. 除颜色外，图标或符号也应有区分，避免只靠颜色识别。

#### 6.3 基础筛选

为列表增加轻量筛选：

1. 日期范围
2. 收入 / 支出类型

### 阶段 B：日历视图

#### 6.4 收支月历

在页面上部增加月历视图：

1. 当前月日期展示
2. 有收支记录的日期做标记
3. 点击日期后，筛选当日收支记录

#### 6.5 快捷切换

至少提供：

1. 今天
2. 清除筛选
3. 月份切换

### 阶段 C：图表视图

#### 6.6 类目饼图

展示当月支出按类目的分布结构。

#### 6.7 日期折线图

展示按日期推进的金额趋势，至少支持：

1. 支出趋势
2. 收入趋势

初版可默认展示支出趋势，必要时再补切换。

## 7. 技术建议

### 7.1 图表库引入

如当前项目未接图表能力，优先调研并引入一套轻量可控方案：

1. `ECharts`
2. `Chart.js`

需要在任务内输出明确选择结论，不要模糊悬空。

### 7.2 数据处理策略

尽量基于现有列表数据在前端聚合，避免本期为图表单独新增统计型后端接口。  
仅当性能或数据量明显不足时，再考虑补专用统计接口。

### 7.3 页面层次建议

推荐顺序：

1. 本月概览
2. 月历筛选
3. 图表区
4. 快速记账
5. 记录列表

避免把图表塞在最底部导致价值感弱化。

## 8. 明确不做

本任务不纳入：

1. 年度报表
2. 多账本体系
3. 预算管理
4. 复杂钻取分析

## 9. 验收标准

1. 收入与支出记录在列表中具有清晰区分。
2. 用户可通过日历按日期筛选记录。
3. 用户可通过饼图快速理解支出类目结构。
4. 用户可通过折线图快速理解日期趋势。
5. 页面信息虽然更丰富，但不出现明显堆叠和压迫感。

## 10. 自测清单

1. 新增多条不同日期、不同类目的记录，确认列表展示完整。
2. 切换日期筛选，确认列表联动正确。
3. 切换月份，确认月历与图表同步变化。
4. 类目饼图占比与原始记录金额核对一致。
5. 折线图与每日金额聚合核对一致。
