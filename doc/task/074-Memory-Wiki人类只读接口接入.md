# 074 Memory Wiki 人类只读接口接入

## 1. 任务目标

为 `M6 人类接口集对齐模块` 先接入人类侧只读接口，让用户可以查看 wiki 页面、页面列表和主题索引，形成与模型只读工具对齐的人类入口。

## 2. 任务来源

- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 10.4A 节
- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 16.3.6 节 `M6 人类接口集对齐模块`

## 3. 前置依赖

- `M5 工具集增量补全模块` 已完成

## 4. 涉及范围

- `electron/backend/memory-wiki/`
- `electron/backend/http/` 或对应 routes
- `src/renderer/`
- `scripts/`

## 5. 当前问题

模型已经有只读工具了，但人类还没有对等的人类入口，不符合“模型工具集全等于人类接口集”原则。

## 6. 目标设计

本任务完成后应具备：

- 人类侧页面列表接口
- 人类侧页面详情接口
- 人类侧主题索引列表接口
- 人类侧主题索引详情接口

## 7. 实现步骤

### Step 1

定义后端只读接口。

### Step 2

接入前端 API 调用封装。

### Step 3

补最小展示或最小验证。

## 8. 测试点

- 人类侧可读取页面和索引。
- 返回结构与模型侧语义一致。

## 9. 完成标准

- 人类侧具备与只读工具对等的只读入口。

## 10. 交付物

- 后端接口代码
- 前端 API 封装
- 对应验证脚本
