# 172-8.1-聊天记录工作台产品化增强

## 1. 任务目标

在当前聊天记录按天翻阅能力基础上，把 `ChatHistory` 从“仅能看当天消息列表”的轻量页面，升级为更接近正式工作台的可读、可筛、可定位的人类入口。

## 2. 背景与现状

当前聊天记录已经支持：

1. 按月份列出有聊天的日期
2. 进入某一天查看消息列表

但目前仍存在明显不足：

1. 页面结构偏薄，只有最基础的日期侧栏和消息气泡
2. 缺少当天摘要、消息数量、空态和上下文提示增强
3. 缺少“快速跳转今天 / 最近一次有记录日期 / 当前月份为空时的说明”
4. 缺少更清晰的人类可理解文案，难以作为正式历史工作台

## 3. 涉及范围

- `src/renderer/ChatHistory.vue`
- 如有必要，补充渲染层 API 辅助调用
- 对应前端测试

## 4. 具体开发项

### 4.1 工作台头部与摘要增强

1. 增加页面标题、副标题、当前日期摘要区
2. 明确展示当前选中日期的消息总数
3. 增加“回到今天”或等价快捷入口

### 4.2 日期列表交互增强

1. 强化月份为空时的空态说明
2. 当选中日期不在当前月份数据里时，自动回落逻辑需可见、可理解
3. 提升日期行的信息密度，例如显示消息条数、是否为今天

### 4.3 对话内容阅读体验增强

1. 区分主人与铃湾的消息视觉层次
2. 补充当天无消息、加载中、加载失败等状态提示
3. 让消息区更适合翻阅长对话，而不只是简单冒泡列表

### 4.4 测试补齐

1. 覆盖月份为空时的空态
2. 覆盖日期切换与默认回落
3. 覆盖消息数摘要与主要状态文案

## 5. 验收标准

1. 聊天记录页具备正式工作台的基本阅读体验
2. 用户能更轻松地定位某一天并理解当天记录状态
3. 对应前端测试通过
