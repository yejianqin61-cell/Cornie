# 210-8.3-Topic搜索筛选与列表扫描体验增强

## 1. 任务目标

在现有 Topic Index 工作台基础上，补齐 Topic 列表的搜索、筛选与扫描体验，让用户不仅能进入单个 Topic 详情，也能先在列表层高效定位自己关心的主题。

## 2. 背景与现状

当前 Topic 详情、时间轴、热度可读化方向都已逐步拆开，但 Topic 列表层还缺：

1. 主题搜索入口
2. 主题筛选与排序能力
3. 面向人类阅读的扫描效率优化

## 3. 涉及范围

- Topic 列表区
- 如有必要，搜索筛选栏
- 对应前端测试

## 4. 前置依赖

1. `178-8.3-Topic-Index详情与主题治理工作台增强.md` 已完成或至少已有 Topic 列表入口
2. `206-8.3-Topic热度与最近活跃可读化增强.md` 已形成 Topic 状态表达方向

## 5. 具体开发项

### 5.1 搜索能力

1. 支持按主题名搜索
2. 支持按别名搜索
3. 搜索无结果时给出明确提示

### 5.2 筛选与排序

1. 支持按热度筛选或排序
2. 支持按最近活跃排序
3. 支持按关联页面数进行轻量排序或筛选

### 5.3 列表扫描效率

1. 每个 Topic 条目至少展示主题名、热度摘要、最近活跃信息
2. 当前选中 Topic 状态清晰可见
3. 长列表下保持快速扫描能力

### 5.4 空态与无结果态

1. 无 Topic 时展示全局空态
2. 搜索或筛选无结果时展示不同状态
3. 保持文案平实，不堆过多治理术语

### 5.5 测试补齐

1. 覆盖主题名 / 别名搜索
2. 覆盖热度 / 最近活跃排序
3. 覆盖空态与无结果态
4. 覆盖选中状态与列表渲染

## 6. 验收标准

1. 用户能在 Topic 列表层快速定位目标主题
2. Topic 列表具备正式工作台级的搜索与筛选体验
3. 搜索、排序、列表阅读三者形成完整入口层
4. 对应前端测试通过
