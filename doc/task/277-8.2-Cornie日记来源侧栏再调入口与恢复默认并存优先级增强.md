# 277-8.2-Cornie日记来源侧栏再调入口与恢复默认并存优先级增强

## 1. 任务目标

在 `262`、`267`、`274` 已补齐恢复默认入口、重置反馈与撤销超时后的再调入口基础上，继续明确“继续调整”和“恢复默认”两个入口并存时的优先级、位置和语义边界。

## 2. 背景与现状

一旦两个入口都存在，就需要回答：

1. 用户现在最该看到哪个入口
2. 两个入口会不会互相抢焦点
3. 如何避免把一个侧栏控制点做成操作按钮集合

## 3. 涉及范围

- Cornie 日记回看页
- 来源侧栏控制区
- 再调入口与恢复默认入口
- 对应前端测试

## 4. 前置依赖

1. `262-8.2-Cornie日记来源侧栏恢复默认入口与偏好重置增强.md` 已完成或至少已有恢复默认入口
2. `274-8.2-Cornie日记来源侧栏撤销超时后的再调入口增强.md` 已完成或至少已有再调入口
3. `267-8.2-Cornie日记来源侧栏重置后的确认反馈微交互增强.md` 已完成或至少已有重置反馈语义

## 5. 具体开发项

### 5.1 入口优先级

1. 明确在不同状态下哪个入口为主，哪个入口为辅
2. 例如刚超时进入稳定态时优先展示“继续调整”，平稳浏览时优先隐藏或降级再调入口
3. 恢复默认入口在长期偏好调整场景中仍保持可发现

### 5.2 布局与位置

1. 两个入口不应并排抢主位
2. 依据当前情境决定一个为主动作、一个为次级入口
3. 保持侧栏控制区整洁，不像设置面板

### 5.3 语义边界

1. “继续调整”强调继续微调当前状态
2. “恢复默认”强调回到系统推荐状态
3. 文案上严格区分两者，不让用户混淆

### 5.4 状态切换兼容

1. 在弱数据态、普通态、刚重置后稳定态三类场景下保持一致优先级规则
2. 用户完成一次新调整后，入口层级随之更新
3. 与撤销超时逻辑和固定偏好记忆保持兼容

### 5.5 测试补齐

1. 覆盖两个入口并存时的优先级
2. 覆盖不同场景下的主次入口切换
3. 覆盖语义文案区分
4. 覆盖完成新调整后的层级更新

## 6. 验收标准

1. Cornie 日记来源侧栏控制点保持清楚主次
2. 用户能明确区分“再调”和“恢复默认”
3. 两个入口并存时不显得拥挤或混乱
4. 对应前端测试通过
