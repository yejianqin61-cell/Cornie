# 264-8.2-Cornie日记来源弱数据态与手动关闭记忆交叉分支增强

## 1. 任务目标

在 `259` 已补齐 Cornie 日记来源侧栏弱数据态、`254` 已补齐状态记忆基础上，继续细化“弱数据态”和“用户手动收起或关闭侧栏偏好”交叉时的行为规则，避免两套机制互相打架。

## 2. 背景与现状

当某天素材很少，而用户又手动收起过侧栏或切过密度，系统就会同时面临两种逻辑：

1. 数据稀疏时系统想更克制
2. 用户手动偏好又希望被记住
3. 两者若没有明确交叉规则，就会让页面行为显得不稳定

## 3. 涉及范围

- Cornie 日记来源侧栏
- 弱数据态逻辑
- 用户偏好记忆逻辑
- 对应前端测试

## 4. 前置依赖

1. `254-8.2-Cornie日记来源侧栏折叠状态记忆与默认密度增强.md` 已完成或至少已有偏好记忆
2. `259-8.2-Cornie日记来源侧栏弱数据态与多来源稀疏场景增强.md` 已完成或至少已有弱数据态
3. `262-8.2-Cornie日记来源侧栏恢复默认入口与偏好重置增强.md` 已完成或至少已有恢复默认方向

## 5. 具体开发项

### 5.1 交叉优先级规则

1. 明确弱数据态默认策略与用户手动偏好谁优先
2. 当用户主动展开侧栏时，不应被弱数据态立即打回
3. 当用户未主动干预时，弱数据态可接管默认表达

### 5.2 状态恢复一致性

1. 从同日总览或其他页面回流时，保持交叉规则稳定
2. 切换到数据更丰富的日期后，正确恢复普通逻辑
3. 再切回稀疏日期时，避免表现突变

### 5.3 用户感知

1. 用户应能理解“这是因为今天素材少，所以页面更克制”
2. 同时也应感受到“我自己刚才的选择被记住了”
3. 行为规则要可预期，不神秘

### 5.4 重置兼容

1. 执行恢复默认后，重新回到弱数据态推荐策略
2. 重置不应清掉与业务数据本身相关的判断
3. 保持重置、弱数据态、偏好记忆三者关系清楚

### 5.5 测试补齐

1. 覆盖弱数据态下用户主动展开侧栏
2. 覆盖弱数据态下未主动干预的默认策略
3. 覆盖跨日期往返时的交叉恢复行为
4. 覆盖重置后的规则回归

## 6. 验收标准

1. Cornie 日记来源侧栏在弱数据态与用户偏好交叉时仍表现稳定
2. 用户能感受到页面既智能克制又尊重个人选择
3. 交叉规则清楚，不出现来回打架
4. 对应前端测试通过
