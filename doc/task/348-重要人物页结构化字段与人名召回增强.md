# 348-重要人物页结构化字段与人名召回增强

## 1. 任务目标

根据 `Cornie-0630-Identity记忆实体模型与页面结构设计.md`，将 `identity_person` 从通用人物页升级为正式的“重要人物实体页”，补齐结构化字段、正文模板、Topic 联动表达和对话召回增强。

## 2. 任务来源

- `doc/design/Cornie-0630-Identity记忆实体模型与页面结构设计.md`
- `doc/design/Cornie-0630-记忆层改进治理总纲-第一版.md`

## 3. 涉及范围

- `electron/backend/memory-wiki/pageModel.js`
- `electron/backend/memory-wiki/storage.js`
- `electron/backend/memory-wiki/service.js`
- `electron/backend/agent/wikiContext.js`
- `src/renderer/components/MemoryWikiWorkspace.vue`

## 4. 当前问题

当前 `identity_person` 已经有页类型，但仍缺少正式的人物结构字段，无法稳定表达：

- 人物和用户的关系
- 人物在用户叙事中的身份位置
- 人物性格
- 共同经历时间线
- 情感权重

这会导致人名召回更多依赖 title/alias 命中，而不是依赖结构化人物页。

## 5. 目标设计

为 `identity_person` 增加结构化字段：

- `personName`
- `relationshipToUser`
- `roleSummary`
- `personalitySummary`
- `sharedExperienceSummary`
- `emotionalWeight`
- `timelineSummary`
- `firstKnownPeriod`
- `lastMentionedAt`

并补齐：

- 默认 summary/body 模板
- `wikiContext` 中的人名命中优先召回
- 与 Topic Index 的人名页摘要表达协同

## 6. 实现步骤

### Step 1

补人物页字段模型与 frontmatter 存储。

### Step 2

补人物页自动正文模板。

### Step 3

增强 `wikiContext` 对人名/别名命中的 `identity_person` 召回排序。

### Step 4

补前端工作台人物页字段编辑区。

## 7. 测试点

- 人物页结构字段可保存、可读回
- 人名命中时人物页优先进入 memory summary
- 与 Topic Index 联动时不破坏既有人名主题跳转

## 8. 完成标准

- 重要人物页成为正式人物实体
- 对话提到关键人物时召回稳定性增强
