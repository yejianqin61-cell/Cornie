# 166-8.2-待办与日程类目及生命周期闭环增强

## 1. 任务目标

在 `165` 的基础上，进一步补齐待办和日程的人类操作闭环，重点处理类目治理、完成 / 取消 / 恢复 / 删除等生命周期动作的清晰表达。

## 2. 本任务聚焦

1. 类目新增、调整、停用 / 恢复的治理体验
2. 待办完成 / 重开，日程取消 / 恢复的反馈收口
3. 编辑态与新建态切换更自然

## 3. 涉及范围

- `src/renderer/components/TodoWorkspace.vue`
- `src/renderer/components/ScheduleWorkspace.vue`
- 对应前端测试

## 4. 具体开发项

### 4.1 待办闭环增强

1. 让待办状态切换后的反馈更清楚
2. 让类目管理区更接近正式管理面
3. 让删除、重开、完成三类动作更易理解

### 4.2 日程闭环增强

1. 让取消、恢复、删除三类动作的后果更清楚
2. 让类目排序与停用反馈更明确
3. 让时间、地点等信息的编辑体验更稳定

### 4.3 回归测试

1. 补充生命周期按钮状态断言
2. 补充类目排序 / 停用 / 恢复断言

## 5. 验收标准

1. Todo / Schedule 已具备更完整的人类生命周期操作闭环
2. 类目管理不再只是最小可用，而是接近正式治理页
3. 前端测试通过
