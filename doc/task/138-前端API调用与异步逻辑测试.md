## 2. 任务来源

- `doc/Cornie-013-当前项目完成度复评与后续行动建议.md` 第 `8.5` 节

## 5. 当前问题

即使有了基础渲染测试，当前仍缺：

- API mock 与契约测试
- 异步请求成功/失败路径测试
- 保存配置、刷新状态、工作台刷新等流程测试

## 6. 目标设计

- Mock `fetch` 或等价请求层
- 覆盖关键异步状态：
  - loading
  - success
  - failure
- 覆盖配置保存、刷新、清空与工作台刷新流程

## 7. 实现步骤

### Step 1

建立前端请求 mock 工具。

### Step 2

为 `App.vue` 的引导页保存/清空/重试逻辑补齐测试。

### Step 3

为工作台刷新、错误态、空态补齐异步测试。

## 8. 测试点

- API 成功时状态更新正确
- API 失败时错误提示合理
- 异步流程前后 UI 状态切换正确
