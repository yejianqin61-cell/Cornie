# 328-桌宠窗口重设计联调验收与文档收口

## 1. 任务目标

在桌宠新壳层、新视觉、新同步、新边界全部落地后，补齐联调验证、文档收口与基础验收记录。

## 2. 背景与现状

桌宠改造跨越：

1. 视觉层
2. 交互层
3. 聊天同步层
4. 边界治理层

因此需要单独的验收任务，避免只做代码修改而没有最终收口证据。

## 3. 涉及范围

- 桌宠相关代码
- `doc/design/*` 相关引用
- 如有必要的验证脚本或验收文档

## 4. 前置依赖

1. `325-327` 已完成。

## 5. 具体开发项

### 5.1 联调验证

1. 验证桌宠窗口可正常启动。
2. 验证桌宠悬浮、输入、发送、收起行为正常。
3. 验证主窗口与桌宠消息同步。
4. 验证待确认场景在桌宠端表现为轻提示而非厚组件。

### 5.2 文档收口

1. 补充必要的验收记录或设计引用更新。
2. 确保旧桌宠设计文档不会与当前主链路冲突。
3. 如有新增组件或状态机抽象，补充最小说明。

### 5.3 最小验证输出

1. 至少完成构建验证。
2. 若存在现成测试入口，可补跑相关测试。
3. 说明仍未覆盖的风险点。

## 6. 验收标准

1. 桌宠重设计主链路可运行。
2. 设计、实现、验收文档口径一致。
3. 至少完成构建验证并记录结果。
