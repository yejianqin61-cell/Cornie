# 177-8.2-观察日志联动阅读与来源追溯增强

## 1. 任务目标

在 `173` 观察日志人类工作台首轮落地之后，继续把观察日志页升级为“事实记录层工作台”，让用户不仅能 CRUD 观察日志，还能看见观察日志与长期记忆、主题索引、Cornie 日记来源之间的联动关系。

## 2. 背景与现状

当前系统已经具备：

1. 观察日志到 Memory Wiki 来源补链
2. 观察日志写入前去重与增量调整
3. 观察日志到 Topic Index 沉淀链路
4. 观察日志将作为 Cornie 日记的重要输入来源

但前端当前即便完成 `173` 首轮工作台，也仍可能缺少：

1. 观察日志被哪些记忆页面引用的可见性
2. 观察日志关联了哪些主题的可见性
3. 观察日志与 Cornie 日记、人类日记的关系解释
4. 观察日志在“事实层 -> 记忆层 -> 日记层”链路中的前端承接

## 3. 涉及范围

- `src/renderer/components/ObservationWorkspace.vue`
- `src/renderer/api.js`
- 如有必要，补充观察日志联动只读接口
- 对应前端测试

## 4. 前置依赖

1. `173-8.2-观察日志人类工作台首轮落地.md` 已完成
2. 观察日志联动后端链路已可被前端读取

## 5. 具体开发项

### 5.1 观察日志来源追溯摘要区

1. 在单条观察日志详情区增加“联动去向”摘要
2. 展示该日志是否已被 Memory Wiki 页面引用
3. 展示该日志是否已命中某些主题索引
4. 对尚未产生联动的日志给出平实空态

### 5.2 相关记忆页面联动阅读

1. 支持展示引用当前观察日志的 Memory Wiki 页面
2. 至少显示页面标题、状态、摘要片段、重要性
3. 支持跳转到相关记忆页面

### 5.3 相关主题联动阅读

1. 支持展示当前观察日志沉淀到的主题项
2. 至少显示主题名、相关日期、关联页面数
3. 支持从日志页进入主题详情或主题面板

### 5.4 观察日志与日记边界说明增强

1. 明确说明观察日志是事实记录层
2. 明确说明 Cornie 日记是文学化关怀层
3. 明确说明人类日记是用户主观表达层
4. 让用户理解一条观察日志可能会成为日记和长期记忆的素材，但三者不是同一份数据

### 5.5 今日观察与当天日记的阅读辅助

1. 在按日查看时，支持显示“当天观察日志条数”
2. 可选展示当天是否已有 Cornie 日记或人类日记记录
3. 重点是帮助用户理解“今天的事实素材是否已经充分”

### 5.6 测试补齐

1. 覆盖有相关 Memory Wiki 页面时的渲染分支
2. 覆盖有相关 Topic 时的渲染分支
3. 覆盖无联动时的空态
4. 覆盖边界说明文案渲染

## 6. 验收标准

1. 观察日志页具备“事实记录层工作台”的联动阅读能力
2. 用户可从观察日志追到相关记忆页面与主题
3. 前端能清晰解释观察日志、日记、长期记忆三者边界
4. 对应前端测试通过
