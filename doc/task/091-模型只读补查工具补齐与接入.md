# 091 模型只读补查工具补齐与接入

## 1. 任务目标

为 `M10` 补齐模型按需补查长期记忆所需的只读工具，让模型在默认摘要不足时，可以自己查页面、查主题索引、查聊天日期、查观察日志，而不是依赖超长 prompt 全量注入。

## 2. 任务来源

- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 13.3 节
- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 16.3.10 节

## 3. 前置依赖

- `090-长期记忆Wiki摘要注入主链替换.md` 已完成

## 4. 涉及范围

- `electron/backend/chatlog/`
- `electron/backend/observation/`
- `electron/backend/memory-wiki/`
- `electron/backend/tools/`
- `scripts/`

## 5. 当前问题

当前只读补查能力还不完整，模型虽然能查一部分 memory wiki，但缺少围绕长期记忆正式方案的全套只读补查入口。

## 6. 目标设计

本任务完成后应具备：

- 查询单页 wiki 正文与摘要。
- 查询 topic index 单项与列表。
- 查询按日聊天记录与关键词命中日期。
- 查询指定日期观察日志。

## 7. 实现步骤

### Step 1

梳理已有只读工具缺口。

### Step 2

补齐只读工具与统一返回结构。

### Step 3

补验证脚本并接入工具网关。

## 8. 测试点

- 模型可读取指定日期聊天记录。
- 模型可按关键词查询聊天命中日期。
- 模型可读取指定日期观察日志与 wiki 页面。

## 9. 完成标准

- 模型具备长期记忆正式方案所需的完整只读补查能力。
