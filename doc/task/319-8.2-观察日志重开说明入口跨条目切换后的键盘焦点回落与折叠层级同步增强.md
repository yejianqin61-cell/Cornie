# 319-8.2-观察日志重开说明入口跨条目切换后的键盘焦点回落与折叠层级同步增强

## 1. 任务目标

在 `315` 已补齐观察日志重开说明入口跨条目后按钮文案与动作目标重算的基础上，继续细化跨条目切换、重新展开来源说明、再次收起和切换到下一条目时的键盘焦点回落与默认折叠层级同步，避免条目切了但焦点和展开层级还停留在上一条。

## 2. 背景与现状

当前观察日志这条链路已经逐步补齐：

1. 来源说明入口可手动重开
2. 跨条目时旧摘要会清理
3. 按钮文案与动作目标会重算

但如果焦点和折叠层级不同步，仍会出现：

1. 已切到条目 B，焦点却停在条目 A 的旧说明按钮上
2. 条目 B 默认应折叠，却继承了条目 A 的展开深度
3. 键盘用户继续操作时，不知道当前正在操作的是哪一条观察

## 3. 涉及范围

- 观察日志来源说明重开入口
- 跨条目切换后的焦点回落
- 折叠层级、默认展开深度与重开状态同步
- 对应前端测试

## 4. 前置依赖

1. `315-8.2-观察日志重开说明入口在跨条目后按钮文案与动作目标重算增强.md` 已完成或至少已有动作重算
2. `307-8.2-观察日志来源说明重开后再次收起的默认折叠层级增强.md` 已完成或至少已有层级规则
3. `311-8.2-观察日志来源说明跨条目重开时的旧摘要语义清理增强.md` 已完成或至少已有跨条目清理

## 5. 具体开发项

### 5.1 跨条目后的焦点重挂载

1. 切换到新条目后，若旧焦点属于上一条说明入口或展开区，必须重挂到当前条目的首个有效入口
2. 不允许焦点停留在不可见或失效的旧条目控件上
3. 若当前条目无可展开说明，则回落到条目正文或稳定操作区

### 5.2 折叠层级同步重算

1. 新条目进入时，默认折叠层级必须按新条目规则重新计算
2. 不允许沿用上一条目的展开深度和滚动位置
3. 手动重开后再次收起，应回到当前条目的默认层级，而不是旧条目的记忆

### 5.3 焦点与层级联动

1. 用户通过键盘重开说明时，焦点应落到当前层级的首个可读位置
2. 收起后焦点回到当前条目的重开按钮
3. 跨条目切换后再次重开，应开启新一轮焦点与层级判定

### 5.4 测试补齐

1. 覆盖跨条目后的焦点回落
2. 覆盖新条目折叠层级不继承旧条目
3. 覆盖重开后收起的焦点返回
4. 覆盖跨条目后再次重开的新一轮状态判定

## 6. 验收标准

1. 观察日志跨条目切换后，焦点、层级、动作目标都只属于当前条目
2. 键盘用户不会误操作上一条观察的说明入口
3. 默认折叠和手动重开规则在多条目切换中保持稳定
4. 对应前端测试通过
