# 278-8.3-治理结果历史页多次往返后的默认动作漂移保护增强

## 1. 任务目标

在 `263` 和 `265` 已补齐治理结果历史页空态下默认动作排序与来源提示记忆交叉规则基础上，继续明确多次跨页往返后默认动作不应逐步漂移的保护策略。

## 2. 背景与现状

用户在提醒中心、待审核池、历史页之间反复往返后，页面容易被临时上下文影响过深。若没有保护，会出现：

1. 默认动作越来越偏向某条历史路径
2. 用户下一次回到同类空态时，看到的主动作和第一次不一样
3. 空态动作排序变得难以预测

## 3. 涉及范围

- 治理结果历史页空态动作区
- 多次往返后的默认动作判定
- 临时上下文与基线规则隔离
- 对应前端测试

## 4. 前置依赖

1. `263-8.3-治理结果历史页空态下次级入口排序与默认动作增强.md` 已完成或至少已有默认动作规则
2. `265-8.3-治理结果历史页空态动作与来源提示记忆交叉分支增强.md` 已完成或至少已有交叉逻辑
3. `256-8.3-治理结果历史页到提醒中心与待审核池的跨页回流说明增强.md` 已完成或至少已有跨页回流语义

## 5. 具体开发项

### 5.1 基线规则保护

1. 为每类空态保留稳定的默认动作基线
2. 临时回流来源只能有限影响默认动作，不应长期改写基线
3. 明确何时允许临时上浮，何时必须回到基线

### 5.2 漂移识别

1. 识别因连续往返导致默认动作排序偏离基线的情况
2. 对累积的临时影响设置衰减或重置条件
3. 避免默认动作随着用户绕圈而越来越奇怪

### 5.3 恢复时机

1. 切换筛选、重置条件或回到历史页稳态浏览时恢复基线
2. 解除空态后清理临时动作优先级影响
3. 多次跨页链路结束后，下一次进入同类空态时重新从基线计算

### 5.4 用户可预期性

1. 用户面对同类空态时应大致看到同样的主动作
2. 临时变化若存在，也应能从当前上下文看懂
3. 不制造“刚才这个按钮在这儿，为什么现在跑了”的困惑

### 5.5 测试补齐

1. 覆盖同类空态在多次往返后的默认动作稳定性
2. 覆盖临时上下文上浮后的回归基线
3. 覆盖重置筛选后的动作恢复
4. 覆盖跨页链路结束后的临时影响清理

## 6. 验收标准

1. 治理结果历史页空态主动作不会因多次往返而漂移失控
2. 默认动作规则保持长期可预测
3. 临时上下文影响有限且可回收
4. 对应前端测试通过
