# 170-8.3-Memory-Wiki版本历史与回滚界面化

## 1. 任务目标

在 [167-8.3-Memory-Wiki页面与Topic治理首轮产品化.md](/C:/Users/USER/Desktop/Cornie/Cornie/doc/task/167-8.3-Memory-Wiki页面与Topic治理首轮产品化.md:1) 与 [168-8.3-治理待审核区与确认中心产品化收口.md](/C:/Users/USER/Desktop/Cornie/Cornie/doc/task/168-8.3-治理待审核区与确认中心产品化收口.md:1) 基础上，把 Memory Wiki 的“版本回滚”从 prompt 式入口升级为显式的人类界面。

## 2. 背景与现状

当前 Memory Wiki 已支持：

1. 页面编辑
2. 页面归档 / 恢复
3. 版本回滚接口

但前端目前仍是：

1. 点击“版本回滚”
2. 弹出 `window.prompt`
3. 人工输入版本 ID

这明显不符合正式产品体验，也不利于普通用户理解。

## 3. 涉及范围

- `src/renderer/components/MemoryWikiWorkspace.vue`
- 如有必要，新增版本列表子区域
- 对应前端测试

## 4. 具体开发项

### 4.1 版本区显式化

1. 选中页面后可看到版本历史入口或版本列表
2. 至少展示版本 ID、时间或简要标识
3. 用户不再需要手输版本 ID 才能回滚

### 4.2 回滚交互升级

1. 明确当前将回滚到哪个版本
2. 回滚前给出更清楚的提示
3. 回滚后页面重新加载状态明确

### 4.3 测试补齐

1. 覆盖版本列表展示
2. 覆盖指定版本回滚
3. 覆盖无版本 / 取消操作等边界

## 5. 验收标准

1. 版本回滚不再依赖 prompt 手工输入
2. 用户可以在界面中理解并执行回滚
3. 对应前端测试通过
