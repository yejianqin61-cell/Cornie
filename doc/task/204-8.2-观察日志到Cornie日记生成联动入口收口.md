# 204-8.2-观察日志到Cornie日记生成联动入口收口

## 1. 任务目标

在 `177` 和 `180` 已经建立“观察日志是 Cornie 日记来源之一”的前端表达基础上，继续补齐一个明确的生成联动入口，让用户在观察日志视角下能够更自然地进入“整理成 Cornie 日记”的下一步。

## 2. 背景与现状

当前任务链已经能表达：

1. 观察日志是事实记录层
2. Cornie 日记是整理后的关怀表达层
3. 当观察日志存在而 Cornie 日记为空时，可以提示“可生成 Cornie 日记”

但仍缺少更正式的任务化收口：

1. 从观察日志页发起日记生成的入口
2. 生成前素材状态摘要
3. 生成后回看链路

## 3. 涉及范围

- 观察日志工作台
- 日记页联动入口
- 如有必要，生成前状态摘要展示
- 对应前端测试

## 4. 前置依赖

1. `177-8.2-观察日志联动阅读与来源追溯增强.md` 已完成或至少已有联动信息区
2. `180-8.1-聊天记录与观察日志日记关系工作台.md` 已完成或至少已有“可以生成 Cornie 日记”提示方向
3. `184-8.1-Cornie日记来源透明与生成后工作流.md` 已形成 Cornie 日记生成后工作流方向

## 5. 具体开发项

### 5.1 生成入口

1. 当当天观察日志已具备一定素材时，展示“整理成 Cornie 日记”入口
2. 若当天已存在 Cornie 日记，则改为查看或回看入口
3. 保持入口语义温和，不制造被催促感

### 5.2 生成前素材摘要

1. 展示当天观察日志条数
2. 可选展示当天是否已有聊天记录、人类日记
3. 帮助用户判断当前素材是否足够整理

### 5.3 生成后回看联动

1. 生成成功后支持跳转到当天 Cornie 日记
2. 支持回看当天观察日志来源
3. 保持观察日志页与日记页的双向理解关系

### 5.4 测试补齐

1. 覆盖生成入口展示条件
2. 覆盖已存在 Cornie 日记时的替代入口
3. 覆盖生成前素材摘要渲染
4. 覆盖生成后跳转分支

## 6. 验收标准

1. 用户可以从观察日志页自然进入 Cornie 日记生成链路
2. 生成入口与事实层 / 表达层边界表达清楚
3. 生成后能顺畅回看当日日记与来源
4. 对应前端测试通过
