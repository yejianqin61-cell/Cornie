# 217-8.3-Memory-Wiki详情页滚动定位与回退体验增强

## 1. 任务目标

在 `175`、`201`、`205` 等详情阅读任务基础上，继续补齐 Memory Wiki 详情页内部的滚动定位、区块跳转和回退体验，让用户在阅读来源、相关页面、正文、版本等长内容时，不容易迷路。

## 2. 背景与现状

当前详情页已经越来越丰富，但随着区块增多，仍会出现：

1. 长页面中很难快速定位到来源区或相关页面区
2. 跳到别的页面后，回退路径不够清晰
3. 用户连续阅读多个页面时容易失去当前位置

## 3. 涉及范围

- Memory Wiki 页面详情区
- 页面内锚点或区块导航
- 对应前端测试

## 4. 前置依赖

1. `175-8.3-Memory-Wiki来源引用与关联阅读增强.md` 已完成或至少已有来源与相关页面区
2. `201-8.3-Memory-Wiki来源引用区分组阅读与原始来源跳转增强.md` 已完成或至少已有来源阅读区
3. `205-8.3-Memory-Wiki相关页面区阅读与关系说明增强.md` 已完成或至少已有相关页面区

## 5. 具体开发项

### 5.1 页面内定位

1. 提供跳到正文、来源区、相关页面区、版本区的定位入口
2. 长页面滚动后仍能快速回到顶部或核心区块
3. 当前所在区块在视觉上有轻量提示

### 5.2 跨页阅读后的回退体验

1. 从相关页面跳转后保留回退路径
2. 从来源区跳到原始来源再返回时，尽量恢复原阅读位置
3. 不让用户每次返回都掉回完全默认位置

### 5.3 长内容阅读稳定性

1. 页面较长时保持阅读区结构清楚
2. 避免不同区块堆叠导致定位困难
3. 保持详情页内部信息架构稳定

### 5.4 测试补齐

1. 覆盖区块定位入口
2. 覆盖回到顶部或核心区块
3. 覆盖跨页跳转后回退恢复
4. 覆盖长页面阅读分支

## 6. 验收标准

1. 用户能在长详情页中快速定位核心区块
2. 跨页阅读后的返回路径清楚
3. Memory Wiki 详情页具备更稳定的深度阅读体验
4. 对应前端测试通过
