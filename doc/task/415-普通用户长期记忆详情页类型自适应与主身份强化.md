# 415-普通用户长期记忆详情页类型自适应与主身份强化

## 1. 任务目标

把当前普通用户长期记忆详情页从“同一套通用输入框”升级为“会根据记忆类型切换提示与编辑语境”的详情页，重点强化：

1. 关于你
2. 重要的人

让用户在编辑时更容易理解“这一页到底该写什么”，而不是面对一块抽象的通用表单。

## 3. 背景与现状

当前普通用户长期记忆详情页已经具备：

1. 新建
2. 编辑
3. 删除
4. 来源摘要
5. 相关记忆阅读

但它仍然存在几个明显问题：

1. 四类记忆页虽然名字不同，编辑表单却几乎一样
2. 用户不容易判断“关于你”这一页应优先写哪些内容
3. “重要的人”页面缺少更贴近关系记忆的填写引导
4. 当前详情页更像一个通用编辑器，而不是普通用户可理解的记忆整理页

## 4. 涉及范围

- `src/renderer/components/MemoryPageDetail.vue`

## 5. 开发项

### 5.1 增加类型自适应的页面说明

在详情页顶部或正文前，按不同记忆类型给出更具体的编辑说明：

1. 关于你：名字、关系、近况、想让铃湾记住的核心自我信息
2. 重要的人：人物是谁、和你的关系、你们的重要经历
3. 你的偏好：喜欢什么、不喜欢什么、怎样会更舒服
4. 你的特征：习惯、表达方式、压力下的样子

### 5.2 动态调整字段标题与占位文案

不同类型的记忆页，应至少在以下方面切换文案：

1. 标题字段
2. 摘要字段
3. 详细内容字段

要求：

1. 文案必须是普通用户语言
2. 不出现 `identity_profile` 之类技术名词
3. “关于你”和“重要的人”要最明显

### 5.3 主身份页强化

当页面类型为“关于你”时，详情页要更明确地传达：

1. 这是铃湾理解“你是谁”的核心页
2. 这里的信息会比普通记忆更值得认真维护

但本任务不引入任何治理提示，也不做高风险确认流。

### 5.4 不做事项

本任务不处理：

1. 结构化字段拆表单
2. Topic Index 联动
3. 审计、版本、回滚
4. 高级工作台透传

## 6. 验收标准

1. 长期记忆详情页会根据记忆类型切换说明和填写语境
2. “关于你”和“重要的人”两类页面的引导明显 stronger
3. 字段标题与占位文案不再是单一通用版本
4. 页面整体仍保持普通用户语义，不暴露技术术语

## 7. 自测清单

1. 新建“关于你”页面，检查文案是否明显围绕主身份
2. 新建“重要的人”页面，检查文案是否明显围绕人物关系
3. 切换到“偏好”“特征”时，检查说明和 placeholder 是否同步变化
4. 编辑已有页面时，确认来源摘要区仍正常显示
5. 手机宽度下详情页说明区不应挤坏
