# 423-长期记忆详情聊天来源回跳与消息定位增强

## 1. 任务目标

当前普通用户在长期记忆详情页中，已经能看到“铃湾是从这些聊天里慢慢记住它的”，但这部分仍只是静态摘要。  
本任务要补齐从长期记忆详情回跳到聊天记录的闭环，并尽量定位到对应消息，让用户能顺着来源回看“当时是怎么说的”。

完成后，普通用户应当能够：

1. 在长期记忆详情页点击聊天来源。
2. 直接打开对应日期的聊天记录。
3. 若来源里带有 `messageId`，尽量定位并高亮那条消息。

## 3. 当前问题

当前长期记忆详情页中：

1. 聊天来源可以看到日期和摘要
2. 但用户不能点开原聊天
3. 即使系统知道 `messageId`，前端也没有利用起来

这导致“来源透明”停留在说明层，没有真正做到“带用户回去看证据”。

---

## 4. 设计原则

1. 仍然使用普通用户口吻  
   让用户感知到的是“点开看看当时怎么说的”，而不是技术回溯。

2. 优先打开可读内容  
   至少能回到当天聊天记录；若能定位到具体消息则进一步增强。

3. 不破坏现有聊天历史浏览路径  
   新增的是记忆详情到聊天日视图的快捷入口，不替代原聊天历史页面。

4. 消息定位失败也要优雅降级  
   若消息已不存在或未命中，仍正常展示当天聊天记录。

---

## 5. 具体改造

### 5.1 `MemoryPageDetail.vue`

新增一个对外事件：

- `open-chat-source`

聊天来源列表改造：

1. 对有 `date` 的聊天来源卡片添加点击能力
2. 点击后发出 `open-chat-source`
3. 事件参数带上：
   - `date`
   - `messageId`
4. 页面上提示“点开看看当时怎么说的”

### 5.2 `App.vue`

在主应用层新增聊天来源回跳状态：

1. 记录当前要打开的聊天日期
2. 记录可选的 `focusMessageId`
3. 收到 `open-chat-source` 后：
   - 切换到 `mode = 'chat'`
   - 切换到 `chatView = 'day'`
   - 设置对应日期与消息 id

### 5.3 `ChatDayView.vue`

增强日视图能力：

1. 新增可选 `focusMessageId`
2. 加载当日消息后，若目标消息存在：
   - 自动滚动到对应消息
   - 给该消息一个短暂但稳定的高亮态
3. 若目标消息不存在：
   - 仅展示当天聊天，不报错

---

## 6. 验收标准

满足以下条件视为完成：

1. 长期记忆详情中的聊天来源可以点击
2. 点击后能打开对应日期的聊天记录
3. 若消息存在，可定位到对应消息
4. 若消息不存在，也能正常浏览当天聊天
5. 构建通过，不影响原聊天历史入口
