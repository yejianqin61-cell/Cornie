# 389 聊天记录单日导出系统工具补齐

## 目标

补齐聊天记录“单日导出”到模型侧系统工具，使模型侧与人类侧的聊天导出能力进一步对齐。

## 设计依据

- `doc/design/Cornie-0630-聊天记录存储与历史归档改造方案.md`
- 其中明确要求：
  - 增加聊天记录导出能力

## 当前缺口

- 人类侧目前已支持：
  - 按日导出聊天记录
  - 按月导出聊天记录
- 模型侧系统工具目前已支持：
  - `conversation.export_month_record`
- 但仍缺：
  - `conversation.export_day_record`

## 本任务范围

1. 在 system tools 中补齐聊天记录单日导出工具
2. 保持只读、低风险
3. 不改动现有 chatlog service 协议

## 实现要求

1. 新增工具：
   - `conversation.export_day_record`
2. 工具应支持：
   - `date`
   - `format`
3. 若未显式提供 `date`，可回退到上下文日期
4. 不移除现有月份导出工具

## 验收标准

1. 工具集中能注册 `conversation.export_day_record`
2. 工具可返回单日导出 payload
3. 默认上下文日期回退可用
4. 验证脚本通过
5. `npm run build` 通过
