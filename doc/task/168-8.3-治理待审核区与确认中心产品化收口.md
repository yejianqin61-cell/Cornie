# 168-8.3-治理待审核区与确认中心产品化收口

## 1. 任务目标

在 `167` 基础上，继续收口 Memory Wiki 工作台中“治理待审核区”和“高风险确认中心”的正式产品化表现。

## 2. 本任务聚焦

1. 待审核治理建议与高风险确认请求的区分更明确
2. 治理详情、证据、处理动作的信息层级更清晰
3. 让普通用户更容易理解“为什么需要我确认 / 审核”

## 3. 涉及范围

- `src/renderer/components/MemoryWikiWorkspace.vue`
- `src/renderer/components/ConfirmCard.vue`
- 对应前端测试

## 4. 具体开发项

### 4.1 治理待审核区收口

1. 列表、详情、过滤器的关系更清楚
2. 巡检入池结果的证据展示更可读
3. 标记已处理 / 稍后再看 / 驳回建议的动作更明确

### 4.2 高风险确认中心收口

1. 区分“治理建议”和“高风险操作确认”
2. 确认卡片状态、错误反馈、处理中状态更明确
3. 普通用户能理解确认动作的影响

### 4.3 测试补齐

1. 补齐治理请求筛选与详情切换断言
2. 补齐确认状态流转断言
3. 补齐失败提示断言

## 5. 验收标准

1. 治理待审核区与高风险确认中心具备正式产品界面雏形
2. 用户能明确理解每类请求的意义和处理方式
3. 前端测试通过
