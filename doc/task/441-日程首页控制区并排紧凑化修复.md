# 441 日程首页控制区并排紧凑化修复

## 背景

GitHub Issue `#14` 指出当前日程首页顶部区域存在明显的纵向堆叠问题：

1. “当前查看”卡片过长。
2. “新增安排”展开后与上方信息区上下罗列。
3. 页面视觉重心分散，不够紧凑。

用户期望这两个卡片缩短，并尽量放到同一行，减少堆叠感。

## 目标

1. 将日程首页顶部的查看区与新增安排区改为并排布局。
2. 在桌面宽度下优先保持双栏紧凑结构。
3. 在窄屏下仍自动回落为单列，保证可用性。

## 范围

- `src/renderer/components/ScheduleHome.vue`

本任务不修改日程数据结构，不扩展新功能，不改动日历组件本身。

## 设计要求

### 1. 顶部控制区改为双卡并排

当“新增安排”展开时：

1. 左侧保留“当前查看”信息与操作按钮。
2. 右侧单独展示“新增安排”表单卡片。
3. 两块区域在同一行显示，避免继续纵向堆叠。

当“新增安排”未展开时：

1. 仅显示左侧查看卡片。
2. 整体宽度自然回收，不保留空白占位。

### 2. 信息收口

左侧查看卡片只保留：

1. 当前筛选说明。
2. 回到今天。
3. 清除筛选。
4. 管理类目。
5. 新增安排。

不再在同一卡片内部额外展开大块表单区域。

### 3. 新增卡片紧凑化

新增安排卡片应：

1. 标题区更短。
2. 表单行距更紧。
3. 桌面宽度下与左卡视觉高度接近。

### 4. 响应式

在移动端或窄宽度下：

1. 自动恢复单列纵向排列。
2. 操作按钮允许换行，但不应横向溢出。

## 验收标准

1. 日程首页顶部在桌面端展开新增安排时，为左右并排而非上下堆叠。
2. “当前查看”卡片与“新增安排”卡片视觉长度明显缩短。
3. 回到今天、清除筛选、管理类目、新增安排仍全部可用。
4. 窄屏下不会因双栏布局导致内容挤压或溢出。
