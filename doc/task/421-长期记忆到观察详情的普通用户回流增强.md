# 421-长期记忆到观察详情的普通用户回流增强

## 1. 任务目标

在普通用户的长期记忆详情页里，已经能够看到“这页记忆是怎么来的”以及其中的观察来源摘要。  
本任务要补齐从长期记忆详情回到原观察详情的阅读闭环，让用户可以顺着来源继续往回翻，而不是只能看一眼摘要。

完成后，普通用户应当能够：

1. 在长期记忆详情页看到观察来源时，直接点开对应观察详情。
2. 从长期记忆页顺着来源回看“当时记下了什么”。
3. 在不进入高级工作台的前提下，完成“记忆内容 -> 观察来源”的自然回流。

## 3. 当前问题

当前长期记忆详情页已经展示了：

1. 聊天来源摘要
2. 观察来源摘要
3. 相关记忆摘要

但观察来源仍只是静态展示：

1. 用户能看到标题和日期
2. 不能点击进入原观察详情
3. “观察与记忆”工作流被截断在摘要层

这会导致：

1. 来源透明度只做了一半
2. 普通用户无法顺着线索继续读
3. 长期记忆和观察日志之间的产品化连接仍不完整

---

## 4. 设计原则

1. 不引入高级术语  
   页面上只强调“点开看看当时记下了什么”，不出现 source trace、governance 等术语。

2. 保持普通用户语义  
   这不是开发者调试跳转，而是“从记忆翻回当时的小事”。

3. 不破坏现有首页与列表导航  
   新增的是记忆详情中的补充入口，而不是替换原有观察列表入口。

4. 只在有真实 observationId 时允许跳转  
   避免不可点击项造成误导。

---

## 5. 具体改造

### 5.1 `MemoryPageDetail.vue`

新增一个对外事件：

- `open-observation`

改造观察来源列表：

1. 对有 `observationId` 的观察来源卡片添加点击能力
2. 点击后发出 `open-observation`
3. 事件参数为该观察的 `observationId`
4. 增加可点击的 hover / cursor 样式
5. 在文案层面提示用户这是可以继续点开的来源

### 5.2 `App.vue`

在普通用户“观察与记忆”主链中接住这个事件：

1. 收到 `open-observation`
2. 设置 `omDetailId`
3. 切换 `omView = 'observation-detail'`

这样就能形成：

`长期记忆详情 -> 观察详情`

的回流闭环。

---

## 6. 验收标准

满足以下条件视为完成：

1. 长期记忆详情中的观察来源可以点击进入观察详情
2. 点击后跳转到正确的 `ObservationDetail`
3. 无 `observationId` 的项不会误导性地表现为可点击
4. 页面语义仍保持普通用户口吻
5. 构建通过，不影响现有观察与记忆主导航
