# 079 长期记忆写入与合并确认流

## 1. 任务目标

为 `M7` 补齐长期记忆写入、页面合并、页面回滚等高风险 Memory Wiki 动作的确认流，让模型提出动作后不会直接落库，而是进入可审查的确认链。

## 5. 当前问题

高风险动作如果没有确认流，就和设计原则相冲突。

## 6. 目标设计

本任务完成后应具备：

- 长期记忆页面创建确认。
- 页面合并确认。
- 页面回滚确认。
- 页面归档/状态升级确认。

## 7. 实现步骤

### Step 1

定义确认场景和提示内容。

### Step 2

接入策略层返回确认请求。

### Step 3

补最小验证脚本。

## 8. 测试点

- 高风险动作返回确认而不是直接执行。
- 确认请求中包含足够业务信息。

## 9. 完成标准

- Memory Wiki 高风险动作进入正式确认流。
