# 133 未配置 API Key 持续引导页与拦截态

## 1. 任务目标

在前端正式落地“未配置有效 DeepSeek API Key 时持续进入引导态”的产品体验，而不是只显示工程化 banner。

## 2. 任务来源

- `doc/Cornie-013-当前项目完成度复评与后续行动建议.md` 第 `8.4` 节

## 3. 前置依赖

- `132` 已完成

## 4. 涉及范围

- `src/renderer/`
- `src/renderer/components/`
- `src/renderer/api.js`

## 5. 当前问题

当前前端只有顶部提示条：

- 没有独立引导页
- 没有持续拦截态
- 没有真实的 API Key 保存动作

## 6. 目标设计

- 落地独立引导页或全局拦截层
- 用户可输入并保存 DeepSeek API Key
- 未配置或配置无效时持续停留在引导态
- 配置成功后自动恢复主工作台

## 7. 实现步骤

### Step 1

新增前端模型设置表单与引导容器。

### Step 2

将主工作台接入“未配置即拦截”的状态切换逻辑。

### Step 3

打通保存、重试、清空配置等基础交互。

## 8. 测试点

- 未配置时进入引导页
- 保存成功后恢复主界面
- 删除配置后再次回到引导页
- 请求失败时有明确错误提示

## 9. 完成标准

- 前端不再只显示工程化提示条
- 引导页具备真实保存与恢复能力

## 10. 交付物

- 引导页/拦截层
- 前端设置交互
- 对应验证脚本
