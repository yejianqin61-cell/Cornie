# 220-8.3-聊天侧工具卡展开收起记忆与默认密度增强

## 1. 任务目标

在 `212` 的多工具步骤回放卡基础上，继续把工具卡的展开 / 收起体验做得更稳定，包括记住用户最近的展开偏好、控制默认信息密度、避免每次都重复展开相同细节。

## 2. 背景与现状

当前多工具回放卡已经具备展开收起方向，但继续推进时仍缺：

1. 用户展开后切页回来又丢失状态
2. 默认密度可能过高或过低
3. 复杂轮次里每次都重新点开相同细节会增加负担

## 3. 涉及范围

- 聊天侧工具卡
- 步骤回放卡组件
- 对应前端测试

## 4. 前置依赖

1. `212-8.3-聊天侧多工具步骤回放卡与摘要链路增强.md` 已完成或至少已有展开 / 收起机制

## 5. 具体开发项

### 5.1 展开收起状态记忆

1. 记住当前轮次中用户最近的展开状态
2. 在合理范围内恢复工具卡展开 / 收起状态
3. 不让状态记忆污染到完全无关的轮次

### 5.2 默认信息密度

1. 默认展示最重要摘要
2. 将细节放入可展开层
3. 保持复杂轮次下聊天区不被工具卡淹没

### 5.3 交互稳定性

1. 展开后不应导致聊天区明显跳动
2. 收起后摘要仍能表达核心结果
3. 保持成功、失败、待确认等不同状态下的密度一致性

### 5.4 测试补齐

1. 覆盖展开状态恢复
2. 覆盖默认摘要渲染
3. 覆盖展开 / 收起后的布局分支
4. 覆盖不同结果态下的密度表现

## 6. 验收标准

1. 工具卡展开收起更稳定、更省心
2. 默认密度适合日常聊天阅读
3. 复杂轮次下工具卡不会持续打断主对话流
4. 对应前端测试通过
