# 355-聊天记录分页检索契约与驱动升级边界收口

## 1. 任务目标

在现有按日聊天历史基础上，补齐后端分页与关键词检索契约，为后续 `better-sqlite3` 升级提供稳定查询接口层。

## 2. 任务来源

- `doc/design/Cornie-0630-聊天记录存储与历史归档改造方案.md`

## 3. 涉及范围

- `electron/db.js`
- `electron/backend/chatlog/service.js`
- `electron/backend/chatlog/routes.js`
- `src/renderer/ChatHistory.vue`

## 4. 当前问题

当前聊天历史能看，但接口仍偏“整天全量读出”，对超长单日、关键词片段、分页游标的支持还不够明确。

## 5. 目标设计

- 增加单日分页读取能力
- 增加日期搜索结果中的命中摘要
- 保持上层 API 兼容未来 SQLite 驱动替换

## 6. 实现步骤

### Step 1

定义分页与检索返回结构。

### Step 2

在 service/routes 层实现兼容式扩展。

### Step 3

前端历史页对接新的分页与片段字段。

## 7. 测试点

- 单日聊天可按页读取
- 搜索结果可返回命中片段
- 现有历史页主流程不回归

## 8. 完成标准

- 聊天记录查询契约从“能看”升级为“可持续扩展”
