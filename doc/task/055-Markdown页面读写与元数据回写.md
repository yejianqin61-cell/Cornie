# 055 Markdown 页面读写与元数据回写

## 1. 任务目标

在 `054` 的页面模型基础上，实现 Markdown wiki 页面的创建、读取、解析、更新与回写能力，确保页面正文和元数据能稳定双向转换。

## 2. 任务来源

- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 6.2 节
- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 8 节
- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 16.3.1 节

## 3. 前置依赖

- `054-Markdown-Wiki目录规范与页面模型落地.md` 已完成

## 4. 涉及范围

- `electron/backend/memory-wiki/storage.js`
- `scripts/`

## 5. 当前问题

虽然会有目录和页面模型，但如果没有真实的 `md` 读写能力，就还不能称为 wiki 存储底座。

## 6. 目标设计

本任务完成后应具备：

- 从页面对象生成 Markdown 文本。
- 从 Markdown 文本解析出元数据和正文。
- 新建页面并保存。
- 读取既有页面。
- 更新页面并回写。

## 7. 实现步骤

### Step 1

定义页面序列化格式。

### Step 2

实现 Markdown -> 页面对象解析。

### Step 3

实现页面对象 -> Markdown 文本回写。

### Step 4

补充创建、读取、更新验证。

## 8. 测试点

- 新建页面后能正确落盘。
- 再次读取时字段和正文一致。
- 更新后元数据和正文都被正确回写。

## 9. 完成标准

- Markdown 页面可稳定创建、读取、更新。
- 元数据解析与回写规则已固化。

- 对应验证脚本
