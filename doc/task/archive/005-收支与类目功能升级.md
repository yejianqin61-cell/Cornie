# 005 收支与类目功能升级

## 1. 任务目标

建立完整的收入、支出、收支类目能力，并支持 AI 在对话中：

- 自动识别收入/支出意图
- 基于现有类目进行映射
- 在无法映射时发起新增类目确认
- 成功记账后同步写入观察日志

本任务完成后，Cornie 至少应支持“花钱/收入表达 -> AI 记账 -> 类目确认 -> 观察日志联动”的业务闭环。

## 5. 数据结构设计

### 5.1 记账表

建议新增：

```sql
CREATE TABLE IF NOT EXISTS ledger_entries (
  id TEXT PRIMARY KEY,
  type TEXT NOT NULL,             -- income | expense
  occurred_at TEXT NOT NULL,
  amount REAL NOT NULL,
  currency TEXT NOT NULL,
  category_id TEXT,
  category_name TEXT,
  merchant TEXT,
  item TEXT,
  source_text TEXT,
  confidence REAL,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```

### 5.2 收支类目表

```sql
CREATE TABLE IF NOT EXISTS ledger_categories (
  id TEXT PRIMARY KEY,
  type TEXT NOT NULL,             -- income | expense
  name TEXT NOT NULL,
  is_active INTEGER NOT NULL DEFAULT 1,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```

### 5.3 索引建议

```sql
CREATE INDEX IF NOT EXISTS idx_ledger_entries_occurred_at ON ledger_entries(occurred_at);
CREATE INDEX IF NOT EXISTS idx_ledger_entries_type ON ledger_entries(type);
CREATE INDEX IF NOT EXISTS idx_ledger_categories_type_active ON ledger_categories(type, is_active);
```

## 6. 工具接口定义

### 6.1 `ledger.add_expense`

输入：

```json
{
  "amount": 28,
  "currency": "CNY",
  "category_id": "exp_food",
  "category_name": "餐饮",
  "item": "咖啡",
  "merchant": "未知",
  "occurred_at": "2026-06-25T14:30:00+08:00",
  "source_text": "我今天买咖啡花了28块",
  "confidence": 0.92
}
```

输出：

```json
{
  "ok": true,
  "result": {
    "id": "ledger_xxx",
    "type": "expense"
  }
}
```

### 6.2 `ledger.add_income`

结构与 `ledger.add_expense` 对称，区别在于 `type=income`。

### 6.3 类目工具

- `ledger_category.list_income`
- `ledger_category.create_expense`
- `ledger_category.create_income`

- `ledger_category.delete`

## 7. 类目映射规则

### 7.1 prompt 注入

每次涉及收支时，必须向模型注入：

- 当前全部支出类目
- 当前全部收入类目

### 7.2 映射结果分支

| 场景 | 处理方式 |
| --- | --- |
| 可映射到现有类目 | 直接返回 `category_id` |
| 多个候选类目 | 选择最优候选并附置信度 |
| 无法映射 | 生成新增类目确认请求 |
| 金额缺失 | 不写账，先追问 |

## 9. 测试点

### 9.1 单元测试建议

- 能成功新增支出
- 能成功新增收入
- 类目列表读取正确
- 无金额时不允许记账
- 无法映射类目时返回确认流

### 9.2 联调测试

- 用户说“我今天买咖啡花了28块”时，AI 可正确走支出记录流程
- 用户说“今天发工资了”时，AI 可记录收入
- 用户说“我今天给猫买罐头花了89块”且无类目时，系统请求新增类目确认
