# 009 聊天记录按天归档与历史翻阅

## 1. 任务目标

建立“每天一份聊天记录”的会话视图和数据组织方式，使同一天的对话内容按日聚合，并可在前端按日期翻阅历史聊天记录。

本任务完成后：

- 同一天的对话消息按日期聚合展示
- 前端可以切换查看不同日期的完整聊天
- 仍然保留实时聊天体验
- 后续可和观察日志、Cornie 日记入口联动

## 5. 数据结构设计

### 5.1 现有对话表继续复用

当前聊天记录本身已经按 `date` 存储在 `conversations` 表中，因此本任务优先复用现有表，不必重新建一张聊天主表。

### 5.2 建议增加索引

```sql
CREATE INDEX IF NOT EXISTS idx_conversations_date_created_at ON conversations(date, created_at);
```

### 5.3 视图模型

按天聚合时建议返回：

```ts
type DailyConversation = {
  date: string
  messages: Array<{
    id: string
    role: 'user' | 'cornie'
    content: string
    createdAt: number
  }>
}
```

## 6. 接口设计

### 6.1 获取某天聊天记录

建议接口：

`GET /api/chatlogs/:date`

响应：

```json
{
  "date": "2026-06-25",
  "messages": [
    {
      "id": "m1",
      "role": "user",
      "content": "今天好累",
      "createdAt": 1719300000000
    }
  ]
}
```

### 6.2 获取某段历史日期列表

建议接口：

`GET /api/chatlogs`

可选查询参数：

- `month=YYYY-MM`

响应：

```json
{
  "entries": [
    {
      "date": "2026-06-25",
      "messageCount": 12
    }
  ]
}
```

## 7. 前端交互设计

### 7.1 核心 UI

- 左侧日期列表
- 中间当天聊天消息
- 支持上一天 / 下一天 / 选择日期

### 7.2 行为

- 默认进入“今天”
- 切换日期时加载该日所有聊天消息
- 若当天没有消息，显示空状态

## 8. 实现步骤

### Step 1

确认聊天消息是否继续完全复用 `conversations` 表

- 推荐继续复用
- 不额外拆分主聊天存储

### Step 2

新增聊天历史服务 `chatlog/service.js`

- 按日期返回所有消息
- 按月返回日期列表

### Step 3

新增路由 `chatlog/routes.js`

- `GET /api/chatlogs/:date`
- `GET /api/chatlogs`

### Step 4

新增前端组件 `ChatHistory.vue`

- 支持日期翻页
- 支持历史列表
- 支持当天完整消息渲染

### Step 5

把聊天历史入口接入主界面

- 可在 `App.vue` 作为一个 tab
- 或放在日记页的侧栏/抽屉中

## 9. 测试点

### 9.1 单元测试建议

- 查询某天消息可按时间排序返回
- 空日期返回空数组
- 月度日期列表可正确聚合

### 9.2 联调测试

- 同一天对话可完整回看
- 切换日期后消息列表正确刷新
- 不影响当前实时聊天窗口

## 10. 完成标准

- 按日期查看聊天记录可用
- 按月/按日翻阅历史聊天可用
- 与实时对话体验互不干扰

## 11. 注意事项

- 聊天记录视图要和观察日志、Cornie 日记明确区分
- 历史聊天量大时要注意前端加载性能
