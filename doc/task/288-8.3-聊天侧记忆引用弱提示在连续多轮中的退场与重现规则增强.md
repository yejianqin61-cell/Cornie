# 288-8.3-聊天侧记忆引用弱提示在连续多轮中的退场与重现规则增强

## 1. 任务目标

在 `174`、`199`、`284` 已补齐记忆引用透明提示、来源展开卡和可达性基础上，继续细化记忆引用弱提示在连续多轮对话中的退场、抑制和重新出现规则，避免“每轮都提醒用了记忆”带来重复感或恐怖谷感。

## 2. 背景与现状

记忆引用透明提示的目的，是让用户知道本轮参考过哪些历史线索，而不是不断强调“我记得你”。随着多轮连续对话出现，若规则过弱，会出现：

1. 连续多轮都展示相似记忆提示，造成噪音
2. 用户刚关闭提示，下一轮又马上重复出现
3. 记忆来源有变化时，又需要适度重新提醒

## 3. 涉及范围

- 聊天侧记忆引用弱提示
- 轮次级提示记忆、关闭状态与重现策略
- 对应前端测试

## 4. 前置依赖

1. `174-8.3-记忆引用透明提示与工具结果面板增强.md` 已完成或至少已有记忆引用提示
2. `199-8.3-聊天侧记忆来源展开卡与引用边界增强.md` 已完成或至少已有来源展开能力
3. `284-8.3-聊天侧工具透明提示的可达性与键盘阅读顺序增强.md` 已完成或至少已有弱提示可达性规范

## 5. 具体开发项

### 5.1 连续多轮抑制规则

1. 当连续多轮使用近似同一组记忆来源时，不必每轮重复完整提示
2. 第二轮起可降级为更轻的提示形态，或直接折叠为可展开说明
3. 避免让用户感觉系统在反复强调记忆能力本身

### 5.2 手动关闭后的重现规则

1. 用户刚关闭记忆提示后，短时间内不应立即重复出现同类提示
2. 若后续轮次引用了明显不同的新来源组，可重新出现
3. 若只是引用量变化但语义未变，可继续保持抑制

### 5.3 提示重现的触发条件

1. 当引用来源类型从聊天记录切换到长期记忆或观察日志时，可重新提醒
2. 当引用来源数量显著增加且影响回答理解时，可重新提醒
3. 当本轮还伴随确认卡或工具失败提示时，记忆弱提示应继续让位

### 5.4 视觉与语义边界

1. 重现后的提示仍保持轻量，不升级为强提醒
2. 与最终回复、工具卡、确认卡并存时保持辅助地位
3. 提示文案继续使用“本轮参考了哪些线索”风格，不强调人格化记忆

### 5.5 测试补齐

1. 覆盖连续多轮同源记忆引用的抑制
2. 覆盖手动关闭后短周期内的提示抑制
3. 覆盖来源组显著变化后的重新出现
4. 覆盖与确认卡、失败提示并存时的优先级

## 6. 验收标准

1. 记忆引用提示在多轮对话中足够透明，但不过度刷存在感
2. 用户关闭提示后，不会被同类提示立即反复打扰
3. 当来源语义明显变化时，系统仍能适度重新提醒
4. 对应前端测试通过
