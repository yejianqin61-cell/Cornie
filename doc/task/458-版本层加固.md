# 458 版本层加固

## 背景

`memory-wiki/versionStore.js` 快照为整页全量 JSON；`diffVersions` 只返回布尔标志 + 全量正文，无字段级 diff；无保留上限（主身份页已有 24 个版本快照）；回滚一次 +2 个版本（Cornie-018 D-04）。前端 MemoryWikiWorkspace 还存在"版本和自己比"问题（Cornie-019 前端审查 P1-2）。

## 目标

1. 版本快照增加字段级 diff 与保留上限（建议 50 + 时间压缩）。
2. 回滚不再无条件 +2 版本。
3. 修复前端"版本差异自比"（diff 应为"当前页 vs 所选版本"）。

## 范围

- `electron/backend/memory-wiki/versionStore.js`
- `electron/backend/memory-wiki/service.js`（update/rollback 版本策略）
- `src/renderer/components/MemoryWikiWorkspace.vue`（版本 diff 展示）

## 设计要求

### 1. 字段级 diff

- `diffVersions` 返回 `changedFields`（标题/摘要/状态/importance/正文/aliases/来源）；正文差异用逐行比对标记 added/removed，避免整段全量输出。

### 2. 保留策略

- 每页版本数上限（建议 50）+ 时间压缩（超上限或超 90 天的旧版本只保留 frontmatter 字段与 body 行数摘要）。
- 回滚策略：保留 before 快照，after 快照改为可选（默认不拍）。

### 3. 前端展示

- "当前页 vs 所选版本"的 diff（修复自比：`selectVersion` 传同一 versionId 的问题）。

## 验收标准

1. 版本上限生效；diff 输出字段级。
2. 回滚后版本数不再 +2。
3. 前端版本摘要显示"所选版本相对当前页改了什么"。
4. verify 脚本（可并入本任务）断言以上三点。
