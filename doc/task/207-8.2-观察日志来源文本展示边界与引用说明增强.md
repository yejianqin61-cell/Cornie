# 207-8.2-观察日志来源文本展示边界与引用说明增强

## 1. 任务目标

在 `173` 和 `193` 已允许观察日志展示与编辑来源文本的基础上，继续明确“来源文本应展示到什么程度、如何说明它的作用、如何避免与最终表达层混淆”，让观察日志详情更稳定、更好懂。

## 2. 背景与现状

当前观察日志字段中已经包含来源文本方向，但仍缺：

1. 来源文本的展示边界不清楚
2. 用户容易把来源文本和最终正文混为一谈
3. 缺少来源文本在后续记忆 / 日记链路中的作用说明

## 3. 涉及范围

- 观察日志详情区
- 观察日志编辑表单
- 对应前端测试

## 4. 前置依赖

1. `173-8.2-观察日志人类工作台首轮落地.md` 已完成或至少已有详情页
2. `193-8.2-观察日志详情编辑表单与删除确认收口.md` 已完成或至少已有来源文本字段编辑

## 5. 具体开发项

### 5.1 来源文本展示边界

1. 在详情页中明确区分正文与来源文本
2. 来源文本默认不抢正文主体注意力
3. 长来源文本可折叠展示

### 5.2 作用说明

1. 明确说明来源文本是事实依据或原始线索
2. 说明它可能影响后续长期记忆和 Cornie 日记整理
3. 不把来源文本表达成最终成品内容

### 5.3 编辑边界与提示

1. 在编辑时说明来源文本的用途
2. 对空来源文本、过长来源文本给出校验或提醒
3. 避免用户误把来源文本当成正文复制区

### 5.4 测试补齐

1. 覆盖正文与来源文本区分渲染
2. 覆盖长来源文本折叠
3. 覆盖来源文本说明文案
4. 覆盖编辑时的校验提示

## 6. 验收标准

1. 用户能看懂来源文本和正文不是一回事
2. 来源文本展示不会干扰主要阅读体验
3. 观察日志详情对来源文本的用途表达清楚
4. 对应前端测试通过
