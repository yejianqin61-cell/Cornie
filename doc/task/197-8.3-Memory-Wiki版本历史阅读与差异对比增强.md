# 197-8.3-Memory-Wiki版本历史阅读与差异对比增强

## 1. 任务目标

在 `170` 版本历史与回滚界面化基础上，继续把版本面板从“能选版本回滚”升级为“可阅读、可比较、可理解”的历史工作区，让用户能够：

1. 快速看懂每个版本做了什么
2. 对比相邻版本或当前版本差异
3. 在回滚前有更扎实的判断依据

## 2. 背景与现状

`170` 已经解决了“不能再靠手输版本 ID 回滚”的问题，但如果继续提升可用性，仍缺：

1. 版本列表的信息密度仍不够支撑阅读
2. 用户还看不到足够清楚的版本差异
3. 回滚前的判断仍然偏依赖猜测

## 3. 涉及范围

- Memory Wiki 版本历史面板
- 如有必要，版本 diff 展示子组件
- 对应前端测试

## 4. 前置依赖

1. `170-8.3-Memory-Wiki版本历史与回滚界面化.md` 已完成或至少已有显式版本面板

## 5. 具体开发项

### 5.1 版本列表信息增强

1. 每个版本展示时间、操作类型、简短变更摘要
2. 若有执行来源信息，可轻量展示人为编辑、治理动作或系统写入来源
3. 当前版本与历史版本区分清楚

### 5.2 差异对比阅读

1. 支持查看当前版本与选中历史版本的差异
2. 支持查看相邻版本差异
3. 至少让用户看清标题、摘要、别名、正文是否变化

### 5.3 回滚前辅助判断

1. 在回滚前展示目标版本与当前版本的关键差异摘要
2. 明确说明回滚将覆盖哪些主要内容
3. 不把回滚确认做成纯按钮点击的黑箱动作

### 5.4 空态与长历史处理

1. 无历史版本时给出清楚空态
2. 历史版本较多时保持列表可扫描性
3. 保证版本阅读区不会挤压主页面详情到不可用

### 5.5 测试补齐

1. 覆盖版本列表增强渲染
2. 覆盖相邻版本 / 当前版本差异查看
3. 覆盖回滚前差异摘要
4. 覆盖无历史版本空态

## 6. 验收标准

1. 用户能够把版本面板当成历史阅读区使用
2. 用户能够在回滚前看懂关键差异
3. 版本历史从“可回滚”提升为“可理解、可比较”
4. 对应前端测试通过
