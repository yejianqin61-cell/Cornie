# 327-桌宠轻提示确认流与旧实现退场

## 1. 任务目标

将桌宠中的复杂确认卡、工具结果卡、旧桌宠调试表达彻底收口，改为轻提示与回主窗口处理的边界实现。

## 2. 背景与现状

当前桌宠仍然会直接展示：

1. `ToolResultPanel`
2. `ConfirmCard`
3. `AskBackBubble`
4. 旧桌宠调试逻辑与旧资源依赖

这与新版设计要求冲突。新版桌宠应是轻陪伴层，不是治理与执行细节展示层。

## 3. 涉及范围

- `src/renderer/CorniePet.vue`
- `src/renderer/composables/useChat.js`
- `src/renderer/components/ChatHome.vue`
- 旧桌宠调试相关依赖的退场处理

## 4. 前置依赖

1. `326-桌宠共享聊天会话与双窗口同步.md` 已完成或至少已完成共享会话收口。

## 5. 具体开发项

### 5.1 轻提示确认边界

1. 桌宠不再直接渲染完整确认卡。
2. 遇到待确认事项时，只展示一句轻提示。
3. 轻提示文案应符合“小铃湾”口吻。
4. 需要给出“去主窗口查看”或等价引导入口。

### 5.2 工具结果与问询边界

1. 桌宠不再展示工具结果面板。
2. 工具执行成功后的反馈应收敛成一句自然语言。
3. 追问信息也应收敛成轻量聊天反馈，不保留厚重组件。

### 5.3 旧实现退场

1. 去除桌宠对旧拼装、旧调试、旧动画链路的直接依赖。
2. 对仍保留在仓库中的旧文件做“已退场”边界处理，不继续让桌宠入口依赖它们。
3. 保证桌宠当前主实现链路已经完全落到新方案。

## 6. 验收标准

1. 桌宠不再展示工具结果卡与复杂确认卡。
2. 桌宠只保留轻提示与轻对话反馈。
3. 桌宠主组件不再依赖旧桌宠拼装链路。
4. 项目构建通过。
