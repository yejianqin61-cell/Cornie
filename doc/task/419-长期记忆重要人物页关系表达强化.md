# 419-长期记忆重要人物页关系表达强化

## 1. 任务目标

把普通用户长期记忆中的“重要的人”页面，从通用文本记忆页，强化成更适合表达人物关系的页面。

重点不是做结构化治理后台，而是让普通用户在写“重要的人”时，能自然表达：

1. 这个人是谁
2. 他和你是什么关系
3. 为什么重要
4. 你们之间有哪些值得留下来的共同经历

## 3. 背景与现状

当前长期记忆详情页已经支持类型自适应，但“重要的人”仍然主要靠：

1. 标题
2. 摘要
3. 正文

来承载全部人物信息。

这会带来几个问题：

1. 人物关系表达仍然偏散
2. 用户不容易一眼分清“名字 / 关系 / 意义 / 经历”
3. 人物页还不够像“人物记忆页”，更像“普通文本页”

## 5. 开发项

### 5.1 增加人物关系提示区

当页面类型为“重要的人”时，详情页应增加一块轻量提示：

1. 这个人是谁
2. 你们是什么关系
3. 他对你来说为什么重要

### 5.2 增加人物写作骨架

在正文前增加人物写作骨架提示，帮助用户自然组织：

1. 关系
2. 性格印象或角色印象
3. 共同经历
4. 这段关系对你的意义

### 5.3 强化人物页字段语义

继续优化“重要的人”类型下的：

1. 标题占位
2. 摘要占位
3. 正文占位

让它更明确围绕人物关系，而不是泛泛而谈。

### 5.4 保持普通用户边界

本任务不引入：

1. 高级关系链路治理
2. Topic Index 操作
3. 结构化字段保存
4. 审计、版本、回滚

## 6. 验收标准

1. “重要的人”页面具有明显区别于其他记忆类型的关系表达语境
2. 用户能更自然地写出人物关系和共同经历
3. 页面不暴露高级治理术语
4. 现有来源摘要、保存、删除能力不受影响

## 7. 自测清单

1. 新建“重要的人”页面，检查提示区是否明显围绕关系表达
2. 检查摘要和正文占位是否更聚焦“人物关系”
3. 切回其他类型，确认人物专属提示不会误显示
4. 保存、删除、来源摘要仍正常
