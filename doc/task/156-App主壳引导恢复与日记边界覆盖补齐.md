# 156-App主壳引导恢复与日记边界覆盖补齐

## 1. 任务目标

在 `8.5 前端测试脚手架与回归模块` 内，继续补齐 `App.vue` 的主壳层、DeepSeek 引导恢复态、日记页月份切换、往年今日空值/错误兜底与模式切换分支测试，进一步推进前端总体覆盖率。

本任务完成后仍需根据真实 coverage 判断是否继续停留在 `8.5`，不得提前进入 `8.6`。

## 2. 背景与现状

根据当前 `coverage/frontend/coverage-summary.json`：

- `App.vue`
  - Statements：`90.9%`
  - Branches：`80.79%`
  - Functions：`85.36%`
  - Lines：`90.67%`

当前 `App.vue` 已有基础引导流、日记主流程、导航主链路测试，但仍有不少高价值尾部分支未覆盖，是总体 `95%+` 目标的主要阻塞点之一。

## 3. 开发范围

涉及文件：

- `tests/frontend/app-settings-flow.test.mjs`
- `tests/frontend/app-diary-flow.test.mjs`

## 4. 具体开发项

### 4.1 DeepSeek 引导与恢复态

补测试覆盖以下行为：

1. `configured = true` 但 `ok = false` 时，展示“铃湾暂时没连上 DeepSeek”
2. `reason = request_failed` 时，展示对应恢复提示组
3. `configured = true` 且 `ok = true` 时，展示“已经连上啦”状态提示
4. `modelStatus.model` 为空时，摘要区回退到 `modelSettings.model`
5. `settingsData.settings.model / timeoutMs` 缺失时走默认值回退
6. `resetModelSettings` 失败时展示友好错误
7. `toFriendlySettingsError` 的空字符串兜底文案

### 4.2 日记页月份与日期边界

补测试覆盖以下行为：

1. `selectedMonth` 切换触发 `refreshList`
2. 点击“回到今天”后切回当天日期
3. `listEntries` / `getEntry` 失败时的 `String(error)` 兜底
4. `listOnThisDay` 返回空数组时显示“那时候我还没出生呢”
5. `userText / cornieText` 为空时显示 `（空）`

### 4.3 主壳模式切换边界

补测试覆盖以下行为：

1. `modeMeta` 对未知 `mode` 回退到默认 section
2. 导航切到 `todo / schedule / cornie-composer` 时，主标题正确切换
3. 引导态下导航按钮保持禁用

## 5. 验收标准

1. 新增测试全部通过
2. `npm.cmd run test:frontend` 通过
3. `npm.cmd run test:frontend:coverage` 通过
4. `App.vue` 覆盖率相较任务前有可见提升
5. 更新 `8.5` 阶段验收文档中的测试结果与覆盖率记录

## 6. 备注

若本任务完成后总体覆盖率仍未达到 `95%+`，则继续留在 `8.5`，优先处理 `MemoryWikiWorkspace.vue` 的剩余治理和详情边界分支。
