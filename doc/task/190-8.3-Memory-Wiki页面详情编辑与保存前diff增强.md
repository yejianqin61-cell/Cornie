# 190-8.3-Memory-Wiki页面详情编辑与保存前diff增强

## 1. 任务目标

在现有 Memory Wiki 页面工作台基础上，继续补齐用户直接编辑记忆页面的正式前端体验，支持：

1. 只读 / 编辑模式切换
2. 标题、摘要、别名、正文的结构化编辑
3. 保存前 diff 预览
4. 风险字段变更的明确确认

## 2. 背景与现状

当前前端已经具备或已拆解：

1. Memory Wiki 列表与基础页面详情
2. 来源引用与关联阅读增强任务
3. 版本历史与回滚界面化任务
4. 治理待审核区与审计区任务

但页面详情编辑仍缺少真正可开发的闭环任务：

1. 用户还没有正式的只读 / 编辑双态切换体验
2. 页面关键字段的编辑边界没有细化到任务级
3. 保存前差异预览没有被单独产品化
4. 对高风险改动的前端确认说明仍不够明确

## 3. 涉及范围

- `src/renderer/components/MemoryWikiWorkspace.vue`
- 如有必要，拆分页面详情与编辑子组件
- 如有必要，补充前端 diff 计算或展示适配层
- 对应前端测试

## 4. 前置依赖

1. `126-Memory-Wiki与Topic-Index前端工作台.md` 已完成
2. `170-8.3-Memory-Wiki版本历史与回滚界面化.md` 已完成
3. `175-8.3-Memory-Wiki来源引用与关联阅读增强.md` 已完成或至少提供详情阅读基础

## 5. 具体开发项

### 5.1 只读 / 编辑模式切换

1. 页面详情默认以只读模式展示
2. 提供明确的“进入编辑”入口
3. 编辑中应有醒目的未保存状态提示

### 5.2 结构化字段编辑

1. 支持编辑标题
2. 支持编辑摘要
3. 支持编辑别名列表
4. 支持编辑正文内容
5. 对来源引用等高风险字段如不开放直接编辑，应明确只读边界

### 5.3 保存前 diff 预览

1. 提交保存前展示本次变更摘要
2. 至少能看出哪些字段被改动
3. 对正文较长变更提供折叠式 diff 或摘要式 diff
4. 允许用户在预览时返回继续修改

### 5.4 风险确认与失败兜底

1. 当改动影响别名、摘要、正文等关键字段时，给出简短风险提示
2. 保存失败时保留编辑内容，避免用户丢失修改
3. 保存成功后同步刷新页面详情与版本历史

### 5.5 测试补齐

1. 覆盖只读 / 编辑模式切换
2. 覆盖标题、摘要、别名、正文编辑
3. 覆盖保存前 diff 预览
4. 覆盖保存成功与失败两类分支
5. 覆盖取消编辑与未保存提示

## 6. 验收标准

1. 用户能够在前端正式编辑 Memory Wiki 页面
2. 用户能够在保存前看懂本次修改内容
3. 保存成功后页面详情与版本信息联动刷新
4. 保存失败不会造成内容丢失或状态混乱
5. 对应前端测试通过
