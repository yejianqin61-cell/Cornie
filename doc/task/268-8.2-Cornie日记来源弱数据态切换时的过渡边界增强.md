# 268-8.2-Cornie日记来源弱数据态切换时的过渡边界增强

## 1. 任务目标

在 `259` 和 `264` 已补齐 Cornie 日记来源侧栏弱数据态与偏好交叉规则基础上，继续细化从“稀疏来源日”切换到“丰富来源日”或反向切换时的过渡边界，避免页面密度和结构突变。

## 2. 背景与现状

弱数据态设计做好后，新的问题会出现在状态切换瞬间：

1. 从来源稀疏日切到来源丰富日时，侧栏可能突然膨胀
2. 从丰富日切回稀疏日时，布局又可能突然收缩
3. 若没有过渡边界，用户会感觉页面“抽动”或“变脸”

## 3. 涉及范围

- Cornie 日记来源侧栏
- 不同数据量日期切换时的布局与密度变化
- 过渡时的提示与动画边界
- 对应前端测试

## 4. 前置依赖

1. `259-8.2-Cornie日记来源侧栏弱数据态与多来源稀疏场景增强.md` 已完成或至少已有弱数据态表达
2. `264-8.2-Cornie日记来源弱数据态与手动关闭记忆交叉分支增强.md` 已完成或至少已有交叉优先级规则

## 5. 具体开发项

### 5.1 切换边界规则

1. 明确哪些情况下需要从紧凑稀疏态切换到常规态
2. 明确哪些情况下仅更新内容，不强制调整整体密度
3. 不让轻微数据差异触发过度布局变化

### 5.2 过渡表现

1. 切换时采用克制的过渡，不用夸张动画
2. 保持正文区域尽量稳定
3. 侧栏宽度、折叠状态和摘要区变化应有一致节奏

### 5.3 用户预期

1. 当切换导致明显展示差异时，用户应能理解是因为来源层变化
2. 不需要专门提示卡打断，但界面变化要显得合理
3. 保持“今天素材少，所以更克制”的一贯语义

### 5.4 偏好兼容

1. 用户的手动偏好在切换过程中仍受尊重
2. 若用户选择了固定密度，不应被轻易打破
3. 恢复默认后，重新采用系统的切换边界策略

### 5.5 测试补齐

1. 覆盖稀疏日切到丰富日的过渡
2. 覆盖丰富日切到稀疏日的过渡
3. 覆盖轻微数据变化不触发大改版
4. 覆盖用户固定偏好下的切换表现

## 6. 验收标准

1. Cornie 日记来源侧栏在不同数据量日期切换时表现稳定
2. 用户不会因过渡突变而失去阅读节奏
3. 弱数据态与用户偏好在切换中保持兼容
4. 对应前端测试通过
