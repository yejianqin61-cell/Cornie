# 184-8.1-Cornie日记来源透明与生成后工作流

## 1. 任务目标

在现有日记主页面与同日关系工作台基础上，补齐 `Cornie 日记` 的来源透明展示、生成前后状态提示、生成后联动跳转与复查入口，让用户能够清楚理解：

1. 铃湾这篇日记主要参考了什么
2. 日记生成前素材是否充足
3. 日记生成后可以继续回看哪些原始材料

## 2. 背景与现状

当前前端已经具备：

1. 人类日记主页面
2. 聊天记录按日浏览能力
3. 观察日志工作台的规划与任务拆解
4. 聊天记录 / 观察日志 / 日记的同日关系工作台任务拆解

但对 `Cornie 日记` 仍缺少以下产品化承接：

1. 用户看不到“本篇 Cornie 日记主要来源于当天哪些材料”
2. 日记生成前缺少“素材是否充足”的前端提示
3. 生成后缺少回看原始聊天、观察日志、人类日记的联动入口
4. 用户很难从前端理解“观察日志”和“Cornie 日记”不是一回事

## 3. 涉及范围

- `src/renderer/App.vue`
- 人类日记区域与 Cornie 日记展示区域
- 如有必要，补充按日聚合的只读接口或前端聚合逻辑
- 对应前端测试

## 4. 前置依赖

1. `173-8.2-观察日志人类工作台首轮落地.md` 已完成或至少已具备观察日志读取基础
2. `180-8.1-聊天记录与观察日志日记关系工作台.md` 已完成或至少提供同日关系聚合入口

## 5. 具体开发项

### 5.1 Cornie 日记来源摘要区

1. 在 Cornie 日记展示区增加“这篇日记参考了什么”摘要区
2. 至少展示当天是否参考了聊天记录、观察日志、人类日记、长期记忆
3. 对长期记忆只展示“有无参考”和简短摘要，不展示过度拟人化的细节
4. 文案保持平实，避免制造“铃湾窥视一切”的恐怖谷感受

### 5.2 生成前素材充足度提示

1. 当天聊天记录为空、观察日志为空、人类日记为空时，提示“今天可供整理的材料较少”
2. 当已有观察日志但尚未生成 Cornie 日记时，提示“可以整理成今天的 Cornie 日记”
3. 当素材较完整时，提示“今天的材料已经比较充足”
4. 不把提示做成阻塞弹窗，而是做成页面内轻提示

### 5.3 生成后回溯入口

1. 支持从 Cornie 日记跳转查看当天聊天记录
2. 支持从 Cornie 日记跳转查看当天观察日志
3. 支持从 Cornie 日记跳转回当天人类日记
4. 若存在引用的长期记忆页面，可提供只读跳转入口

### 5.4 边界说明

1. 明确说明观察日志是事实整理层
2. 明确说明 Cornie 日记是铃湾整理后的表达层
3. 明确说明长期记忆仅在需要时参考，不代表每篇日记都会大量使用

### 5.5 测试补齐

1. 覆盖来源摘要区在不同数据组合下的渲染
2. 覆盖素材充足度提示的不同分支
3. 覆盖生成后跳转入口展示
4. 覆盖长期记忆引用存在 / 不存在时的边界展示

## 6. 验收标准

1. 用户能够直观看懂一篇 Cornie 日记主要参考了哪些来源
2. 用户能够在生成前判断当天材料是否足够
3. 用户能够在生成后快速回看原始材料
4. 观察日志、长期记忆、Cornie 日记三者边界表达清楚
5. 对应前端测试通过
