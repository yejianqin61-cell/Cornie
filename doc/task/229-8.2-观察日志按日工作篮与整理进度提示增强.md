# 229-8.2-观察日志按日工作篮与整理进度提示增强

## 1. 任务目标

在 `173`、`192`、`211`、`219` 已补齐观察日志列表、定位、素材完整度提示和空态表达的基础上，继续把观察日志做成真正适合“当天整理”的工作篮，加入按日整理进度、待处理提示和轻量工作篮视图。

## 2. 背景与现状

观察日志与普通列表不同，它常常承接“今天有哪些事实已经记下、哪些还没整理完”。当前即便已有列表和提示，仍会存在：

1. 用户知道今天有日志，但不清楚整理完成度
2. 同一天里多条日志分散展示，缺少“工作篮”视角
3. 无法快速判断今天是否已经足够支撑 Cornie 日记或长期记忆沉淀

## 3. 涉及范围

- 观察日志工作台按日视图
- 当日整理摘要区
- 与日记生成、长期记忆联动提示
- 对应前端测试

## 4. 前置依赖

1. `173-8.2-观察日志人类工作台首轮落地.md` 已完成或至少已有观察日志工作台
2. `192-8.2-观察日志列表筛选与按日定位增强.md` 已完成或至少已有按日浏览能力
3. `211-8.2-观察日志当日素材完整度提示与整理建议增强.md` 已完成或至少已有完整度提示
4. `219-8.2-观察日志联动区空态层次与提示文案增强.md` 已完成或至少已有联动区层次表达

## 5. 具体开发项

### 5.1 当日工作篮视图

1. 在观察日志页增加“今天 / 当前选中日期”的工作篮摘要区
2. 汇总当天日志数量、最近更新时间、是否已有高价值条目等信息
3. 让用户不进单条详情也能先判断当天整理状态

### 5.2 整理进度提示

1. 提示当天是否仍有未补标题、未补来源、未补正文的条目
2. 提示当天是否已具备生成 Cornie 日记的基本素材
3. 提示当天是否已有内容被长期记忆或主题索引引用

### 5.3 快速整理入口

1. 从当日工作篮直接跳到待补完条目
2. 支持快速回到今天
3. 支持从工作篮跳到当日日记联动或长期记忆联动区

### 5.4 文案边界

1. 进度提示应是帮助整理，不是冒充自动判断“是否足够好”
2. 只提示当前系统能看见的结构性缺口，不做夸张推断
3. 让用户清楚“观察日志是素材层，不等于最终表达层”

### 5.5 测试补齐

1. 覆盖当日工作篮摘要渲染
2. 覆盖不同整理进度分支
3. 覆盖快速跳转到待补完条目
4. 覆盖无日志日与低完成度日的提示逻辑

## 6. 验收标准

1. 观察日志页具备“按天整理素材”的工作台感
2. 用户能更快看懂当天是否还需要继续整理
3. 进度提示和联动入口不会喧宾夺主
4. 对应前端测试通过
