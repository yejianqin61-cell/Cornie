# 212-8.3-聊天侧多工具步骤回放卡与摘要链路增强

## 1. 任务目标

在 `189` 和 `208` 的工具结果反馈基础上，继续把“本轮用了多个工具”的情况细化成可回看、可理解的步骤回放卡，让用户在复杂轮次里能看懂铃湾大致做了哪些步骤，而不是只看到零散结果块。

## 2. 背景与现状

当前任务链已经提出多工具可按顺序查看主要步骤，但要落到更直接可开发的粒度，还缺：

1. 步骤回放卡的结构
2. 多工具结果的摘要串联
3. 复杂轮次下的信息压缩方式

## 3. 涉及范围

- 聊天消息渲染链路
- `ToolResultPanel.vue`
- 如有必要，新增步骤回放卡组件
- 对应前端测试

## 4. 前置依赖

1. `189-8.3-聊天侧工具过程态与结果态反馈分层增强.md` 已完成或至少已有多工具顺序展示基础
2. `208-8.3-聊天侧工具失败兜底说明卡与恢复建议增强.md` 已完成或至少已有失败卡方向

## 5. 具体开发项

### 5.1 步骤回放卡结构

1. 对多工具轮次提供统一步骤回放卡
2. 每一步至少展示动作类型、结果状态、简短摘要
3. 支持展开查看更多细节

### 5.2 多工具摘要链路

1. 在顶部提供本轮工具调用的整体摘要
2. 让用户知道是“先查、后写、再确认”还是其他顺序
3. 避免把原始协议或完整 JSON 直接展示给用户

### 5.3 成功与失败混合轮次

1. 某些步骤成功、某些步骤失败时，状态区分清楚
2. 支持用户定位卡在了哪一步
3. 失败步骤可复用失败说明卡思路

### 5.4 测试补齐

1. 覆盖多工具步骤顺序渲染
2. 覆盖整体摘要展示
3. 覆盖成功失败混合轮次
4. 覆盖展开 / 收起分支

## 6. 验收标准

1. 用户能看懂复杂轮次中的主要工具步骤
2. 多工具调用不会在前端碎成难以理解的散块
3. 步骤回放卡兼顾透明度与可读性
4. 对应前端测试通过
