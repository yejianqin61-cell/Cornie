# 175-8.3-Memory-Wiki来源引用与关联阅读增强

## 1. 任务目标

在现有 Memory Wiki 工作台基础上，补齐来源引用与关联阅读能力，让用户不仅能编辑页面本身，还能理解“这页记忆从哪里来、和什么相关”。

## 2. 背景与现状

当前 Memory Wiki 前端已经具备：

1. 页面列表
2. 页面编辑
3. Topic Index 基础查看
4. 治理待审核区
5. 高风险确认中心

但仍缺少对页面来源和关联关系的前端承接：

1. 用户看不到页面来源引用
2. 用户看不到关联页面与关联上下文
3. 用户难以把页面、观察日志、聊天记录、Topic Index 串起来阅读

## 3. 涉及范围

- `src/renderer/components/MemoryWikiWorkspace.vue`
- `src/renderer/api.js`
- 如有必要，补充后端人类只读接口
- 对应前端测试

## 4. 具体开发项

### 4.1 页面来源引用区

1. 在页面详情中增加来源引用展示区
2. 至少支持显示来源类型、来源标识、来源日期或标题
3. 对无来源引用页面给出空态说明

### 4.2 关联页面阅读区

1. 展示相关页面或已建立的页面关联
2. 支持用户从当前页面跳转到关联页面
3. 让用户理解这页记忆不是孤立文本，而是知识网络的一部分

### 4.3 Topic 与页面关系增强

1. 在 Topic 详情中更明确显示关联页面数量与具体页面
2. 页面侧也能体现与 Topic 的连接感

### 4.4 测试补齐

1. 覆盖有来源 / 无来源两类页面状态
2. 覆盖关联页面展示与跳转
3. 覆盖 Topic 与页面关系展示

## 5. 验收标准

1. Memory Wiki 页面不再只是单页编辑器，而是具备来源与关联阅读能力
2. 用户可更容易追溯记忆来源
3. 对应前端测试通过
