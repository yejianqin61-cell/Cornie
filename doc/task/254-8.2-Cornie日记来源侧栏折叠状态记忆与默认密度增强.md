# 254-8.2-Cornie日记来源侧栏折叠状态记忆与默认密度增强

## 1. 任务目标

在 `246` 已补齐 Cornie 日记来源透明侧栏与素材摘要基础上，继续增强来源侧栏的折叠状态记忆与默认密度控制，让回看体验既透明又不笨重。

## 2. 背景与现状

来源侧栏一旦加入日记回看页，新的体验问题会变成：

1. 用户每次打开日记都要重复折叠或展开相同区块
2. 有时想深看来源，有时只想安静读正文，但缺少稳定密度控制
3. 多次回看不同日期时，旧状态可能互相污染

## 3. 涉及范围

- Cornie 日记回看页
- 来源透明侧栏
- 前端本地视图状态持久化
- 对应前端测试

## 4. 前置依赖

1. `246-8.2-Cornie日记回看时的来源透明侧栏与素材摘要增强.md` 已完成或至少已有来源侧栏
2. `249-8.2-Cornie日记回到同日总览的状态保持与回流提示增强.md` 已完成或至少已有日记回看上下文保持

## 5. 具体开发项

### 5.1 折叠状态记忆

1. 记住来源侧栏最近一次展开或折叠状态
2. 在同一日期日记的回看中合理恢复该状态
3. 切换到完全不同日期时，避免不合理继承旧状态

### 5.2 默认密度控制

1. 提供紧凑模式与展开模式两种默认密度
2. 紧凑模式突出来源层级摘要，不展开过多细节
3. 展开模式适合核对素材关系时使用

### 5.3 正文优先边界

1. 在默认场景下保持日记正文优先
2. 侧栏状态变化不应明显挤压正文阅读体验
3. 当来源信息很少时，侧栏自动采用更克制的表达

### 5.4 状态恢复边界

1. 区分“用户主动切换的侧栏状态”和“系统默认状态”
2. 页面刷新或从总览回流时，恢复策略保持一致
3. 提供显式重置入口，避免长期累积误导

### 5.5 测试补齐

1. 覆盖侧栏折叠状态记忆
2. 覆盖紧凑 / 展开两种密度模式
3. 覆盖跨日期切换的状态隔离
4. 覆盖重置入口

## 6. 验收标准

1. Cornie 日记来源侧栏具备稳定的状态记忆能力
2. 日记正文仍保持第一阅读优先级
3. 密度控制清楚、克制、可持续使用
4. 对应前端测试通过
