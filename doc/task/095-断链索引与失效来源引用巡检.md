# 095 断链索引与失效来源引用巡检

## 1. 任务目标

为 `M11` 建立长期记忆数据健康巡检能力，自动检查 topic index 断链、失效页面引用、失效聊天/观察来源引用等问题。

## 2. 任务来源

- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 16.3.11 节

## 3. 前置依赖

- `094-Memory-Wiki关键操作审计日志.md` 已完成

## 4. 涉及范围

- `electron/backend/memory-wiki/`
- `electron/backend/chatlog/`
- `electron/backend/observation/`
- `scripts/`

## 5. 当前问题

随着页面、索引、聊天记录和观察日志越来越多，系统缺少自动发现“引用还在但目标不存在”的健康检查能力。

## 6. 目标设计

本任务完成后应具备：

- 检查 topic index 中指向不存在页面的 `memoryPageIds`
- 检查页面 `sourceRefs` 中失效的聊天/观察来源
- 输出结构化巡检报告

## 7. 实现步骤

### Step 1

定义巡检报告结构。

### Step 2

实现页面、索引、来源三类断链检查。

### Step 3

补验证脚本。

## 8. 测试点

- 缺失页面引用会被识别。
- 缺失聊天/观察来源会被识别。
- 巡检结果可区分问题类型。

## 9. 完成标准

- Memory Wiki 数据健康具备基础断链巡检能力。
