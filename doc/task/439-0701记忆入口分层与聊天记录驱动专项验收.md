# 439-0701记忆入口分层与聊天记录驱动专项验收

## 1. 任务目标

对 0701 设计文档所对应的两条收口线做一次专项验收：

1. 聊天记录 `better-sqlite3` 运行时口径与自检线
2. 长期记忆普通入口 / 高级工作台分层线

本任务不负责铺新功能，而是负责验证“这两条线是否真的落到了当前代码和体验里”。

## 2. 对应来源

- `doc/design/Cornie-0701-记忆层存储与长期记忆前端入口设计说明.md`
- 全文，重点关注第 2、3、7、8、9、10、12 节

## 3. 前置依赖

建议在以下任务完成后执行：

1. `436-聊天记录驱动状态自检与运行口径收口`
2. `437-普通用户长期记忆入口与高级工作台路由隔离`
3. `438-普通用户长期记忆入口去治理术语与能力边界收口`

## 4. 涉及范围

- 聊天记录后端驱动状态读取链路
- 普通用户长期记忆入口
- 高级工作台入口
- 必要的验证脚本、验收文档或回归记录

## 5. 验收项

### 5.1 聊天记录驱动口径验收

确认：

1. 运行时能读到当前驱动状态
2. 状态字段足以判断是否为 `better-sqlite3`
3. 启动与排障时有一致口径

### 5.2 普通用户长期记忆入口验收

确认：

1. 普通用户可在不进入高级工作台的前提下完成长期记忆主流程
2. 普通入口不再直出治理术语
3. 普通入口的主动作只保留必要能力

### 5.3 高级工作台分层验收

确认：

1. 高级工作台仍可独立进入
2. 高级能力未丢失
3. 普通路径不会误跳进高级治理路径

## 6. 产出要求

至少产出以下一种或多种形式的验收证据：

1. 验证脚本输出
2. 本地联调记录
3. 阶段验收文档
4. 回归清单

## 7. 验收标准

1. 0701 文档中关于聊天记录驱动现状的口径，在当前代码中有可验证证据
2. 0701 文档中关于长期记忆双轨入口的描述，在当前前端中有可验证证据
3. 普通入口和高级入口边界清晰，且不会互相污染

## 8. 自测清单

1. 跑一遍聊天记录驱动状态验证
2. 从普通入口完整走一遍长期记忆主流程
3. 从高级入口进入工作台，确认治理能力仍可达
4. 交叉返回数次，确认不会路径串线
