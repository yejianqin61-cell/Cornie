# 314-8.1-聊天记录跨来源快速切换后主按钮语义与返回动作一致性增强

## 1. 任务目标

在 `310` 已补齐聊天记录不同来源入口连续切换时旧轮次彻底出清基础上，继续细化快速切换来源后，聊天记录页主按钮、返回入口和次级动作文案是否始终对应当前来源语义，避免按钮还写着上一来源的动作。

## 2. 背景与现状

当用户在多个来源入口间快速切换时，除提示文案和状态外，动作按钮也会受影响：

1. 回到来源页
2. 重新查看同日关系
3. 继续当前聊天浏览

若按钮语义未及时刷新，会出现：

1. 当前已经是来源 B，但按钮还像来源 A
2. 用户点了按钮却回到错误模块
3. 主按钮文案与顶部提示语义不一致

## 3. 涉及范围

- 聊天记录工作台按钮区
- 主按钮、次级按钮与返回动作
- 来源切换后的文案和动作重算
- 对应前端测试

## 4. 前置依赖

1. `310-8.1-聊天记录不同来源入口连续切换时的旧轮次彻底出清增强.md` 已完成或至少已有来源切换出清
2. `286-8.1-聊天记录多入口回流并发时的主落点判定与提示降级增强.md` 已完成或至少已有主来源判定
3. `294-8.1-聊天记录空态与旧回流恢复态并存时的优先级与文案收口增强.md` 已完成或至少已有空态动作排序

## 5. 具体开发项

### 5.1 主按钮文案重算

1. 来源切换后，主按钮文案必须即时切换到当前来源语义
2. 不允许保留上一来源的动作措辞
3. 当当前来源无明确返回动作时，回落到通用浏览动作

### 5.2 返回动作绑定一致性

1. 主按钮执行目标必须与当前来源一致
2. 次级按钮若保留历史来源动作，必须降级并明示
3. 不让不同来源的返回动作共用同一模糊文案

### 5.3 快速切换稳定性

1. 多次快速切换后，最后一次来源决定最终按钮组
2. 不因中间态造成按钮闪回旧文案
3. 与手动接管、空态和最近访问规则兼容

### 5.4 测试补齐

1. 覆盖 A/B 来源快速切换后的主按钮文案刷新
2. 覆盖按钮动作目标不串来源
3. 覆盖空态分支下的动作回落
4. 覆盖多次切换后最终按钮组稳定

## 6. 验收标准

1. 聊天记录页按钮语义始终跟随当前来源
2. 用户不会因为按钮文案漂移而回错地方
3. 快速切换后按钮区仍保持一致、可预测
4. 对应前端测试通过
