# 424-观察与记忆首页主身份记忆优先露出增强

## 1. 任务目标

当前“观察与记忆”首页已经能展示最近的长期记忆，但它们仍然是统一平铺卡片。  
本任务要把“关于你”主身份页在首页上优先露出，让普通用户一进来就能更自然地理解：

1. 铃湾记住的最核心内容是“你是谁”
2. 长期记忆不是一堆杂项，而是围绕“你”展开
3. 如果已经存在主身份页，它应该比其他记忆更先被看见

## 3. 当前问题

当前首页长期记忆区虽然已经有：

1. 标题
2. 查看全部
3. 新建记忆
4. 最近记忆卡片

但仍存在问题：

1. `identity_profile` 没有在首页得到足够优先级
2. 普通用户不容易一眼看出“哪一页最重要”
3. 首页更像“最近内容列表”，而不是“长期记忆主入口”

---

## 4. 设计原则

1. 强调主身份，不引入复杂结构  
   不做后台式统计面板，而是做清晰、温和的主入口卡片。

2. 保持普通用户口吻  
   用户看到的是“关于你”“铃湾现在记得的你”，而不是 `identity_profile`。

3. 不破坏已有记忆列表入口  
   首页增强的是首屏优先级，不替代完整列表页。

4. 没有主身份页时优雅降级  
   可以引导用户先写下第一张“关于你”页。

---

## 5. 具体改造

### 5.1 首页数据层

在首页长期记忆读取后：

1. 识别 `identity_profile` 页面
2. 若存在，单独提取为“主身份记忆”
3. 其余记忆继续作为最近记忆列表展示

### 5.2 首页展示层

若存在主身份页：

1. 在长期记忆区顶部增加一张更突出的主身份卡
2. 展示：
   - 标题
   - 一句话摘要
   - 温和提示文案，例如“这是铃湾现在最先记住的你”
3. 点击后进入该页详情

若不存在主身份页：

1. 在长期记忆区空态或顶部提示中，鼓励用户先写一页“关于你”
2. 新建按钮语义更偏向“先写下关于你”

### 5.3 最近记忆列表调整

1. 若已抽出主身份页，则列表里不再重复展示同一页
2. 最近记忆区继续保留其他人物、偏好、特征类内容

---

## 6. 验收标准

满足以下条件视为完成：

1. 首页若存在主身份页，会优先露出
2. 首页最近记忆列表不会重复显示同一主身份页
3. 没有主身份页时，首页空态或引导能自然提示先写“关于你”
4. 页面仍保持普通用户语义
5. 构建通过，不影响现有记忆列表与详情跳转
