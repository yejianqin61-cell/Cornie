# 076 Memory Wiki 高风险治理页面入口

## 1. 任务目标

为 `M6` 补齐高风险治理入口，让人类可执行合并、回滚、主题索引维护等治理动作，真正和模型高风险工具能力对齐。

## 5. 当前问题

高风险工具如果只有模型能调用，就会直接违背当前设计原则。

## 6. 目标设计

本任务完成后应具备：

- 人类侧合并入口
- 人类侧回滚入口
- 人类侧主题索引别名维护入口
- 人类侧索引页面关联维护入口

### Step 2

### Step 3
