# 219-8.2-观察日志联动区空态层次与提示文案增强

## 1. 任务目标

在 `177`、`211`、`215` 已经补齐观察日志联动阅读与提示基础上，继续把观察日志联动区的不同空态分层做清楚，让用户能分辨“暂时还没有联动”“今天素材不足”“尚未沉淀到长期记忆”等不同状态。

## 2. 背景与现状

当前观察日志联动区已经开始承接很多信息，但不同“没有”的状态很容易混在一起：

1. 没有相关 Memory Wiki 页面
2. 没有命中 Topic
3. 当天素材不够，尚未形成更上层沉淀
4. 只是当前还没生成 Cornie 日记

## 3. 涉及范围

- 观察日志联动摘要区
- 观察日志详情页空态文案
- 对应前端测试

## 4. 前置依赖

1. `177-8.2-观察日志联动阅读与来源追溯增强.md` 已完成或至少已有联动区
2. `211-8.2-观察日志当日素材完整度提示与整理建议增强.md` 已完成或至少已有素材完整度提示
3. `215-8.2-观察日志中的长期记忆引用提示与跳转增强.md` 已完成或至少已有长期记忆引用提示

## 5. 具体开发项

### 5.1 联动区空态分层

1. 区分“没有相关记忆页”“没有相关 Topic”“尚未生成 Cornie 日记”
2. 区分“没有数据”与“数据仍在逐步沉淀”
3. 不把所有空态都做成一条模糊提示

### 5.2 文案提示增强

1. 文案帮助用户理解当前停在记录链路的哪一层
2. 对素材不足时给出温和说明
3. 对尚未沉淀时给出中性说明，不制造焦虑

### 5.3 空态下的下一步入口

1. 合适时提示可去补观察、补聊天、查看日记或等待沉淀
2. 不强推单一路径
3. 保持工具性，不把空态做成任务压迫感

### 5.4 测试补齐

1. 覆盖不同空态分支
2. 覆盖不同文案渲染
3. 覆盖空态下的入口展示
4. 覆盖完全空白与部分沉淀两类场景

## 6. 验收标准

1. 用户能分辨观察日志联动区里不同类型的“还没有”
2. 联动区空态不再模糊堆叠
3. 观察日志页对记录链路阶段表达更清楚
4. 对应前端测试通过
