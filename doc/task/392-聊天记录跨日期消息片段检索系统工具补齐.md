# 392-聊天记录跨日期消息片段检索系统工具补齐

## 1. 任务目标

根据 `Cornie-0630-聊天记录存储与历史归档改造方案.md` 第 5.1、7、8 节，聊天记录不只要支持“命中哪些日期”，还要支持“按关键词检索日期和消息片段”。

当前系统已经具备：

- 历史日期检索
- 单日分页读取
- 单日关键词过滤

但模型侧还缺一项更直接的只读能力：

- 跨日期按关键词检索具体消息片段，并返回对应日期、消息 id、matchedPreview

## 2. 任务来源

- `doc/design/Cornie-0630-聊天记录存储与历史归档改造方案.md`

## 3. 涉及范围

- `electron/backend/chatlog/service.js`
- `electron/backend/system/tools.js`
- `scripts/`

## 4. 当前问题

现在模型只能：

- 先用 `conversation.search_day_records` 找到命中的日期
- 再逐天调用 `conversation.get_day_page` 做二次补查

这虽然可行，但还不等于设计稿要求的“按关键词检索日期和消息片段能力”已经正式对外开放。

## 5. 目标设计

- 在 chatlog service 中新增跨日期消息检索能力
- 支持：
  - `keyword`
  - `month`
  - `scope`
  - `limit`
  - `cursor`
- 返回：
  - `date`
  - `messageId`
  - `role`
  - `matchedPreview`
  - `content`
  - `pagination`

## 6. 实现步骤

### Step 1

在 chatlog service 中新增 `searchMessageSnippets()`：

- 先复用已有日期归档视图
- 再对命中的日期逐日调用 `searchMessagesByDate`
- 汇总成跨日期消息结果

### Step 2

在 system tools 中新增：

- `conversation.search_message_snippets`

让模型可直接按关键词检索历史消息片段。

### Step 3

补专项验证脚本，证明：

- 能跨多个日期返回消息级片段
- 支持 `scope/month`
- 支持分页

## 7. 测试点

- 工具集注册 `conversation.search_message_snippets`
- 返回结果包含日期、消息 id、角色、matchedPreview
- 多日期检索与分页均可用
- `npm run build` 通过

## 8. 完成标准

- 聊天记录“日期 + 消息片段”检索能力正式对模型开放
- 与 0630 聊天记录设计稿对齐
