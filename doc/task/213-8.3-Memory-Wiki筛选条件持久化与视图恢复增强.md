# 213-8.3-Memory-Wiki筛选条件持久化与视图恢复增强

## 1. 任务目标

在 `196` 和 `209` 已补齐搜索、筛选、空态基础上，继续把 Memory Wiki 列表的筛选条件、排序状态、当前视图恢复能力做成稳定体验，让用户切换页面或刷新后，不必每次重新整理自己的浏览上下文。

## 2. 背景与现状

当前列表工作台已具备搜索筛选能力，但继续走向正式使用时还缺：

1. 筛选条件切走后容易丢失
2. 排序与选中状态恢复不稳定
3. 用户重新进入工作台时上下文连续性不足

## 3. 涉及范围

- Memory Wiki 页面列表区
- 搜索 / 筛选 / 排序状态管理
- 对应前端测试

## 4. 前置依赖

1. `196-8.3-Memory-Wiki页面列表搜索筛选与扫描效率增强.md` 已完成或至少已有搜索筛选能力
2. `209-8.3-Memory-Wiki页面列表空态与无结果状态体系增强.md` 已完成或至少已有不同状态区分

## 5. 具体开发项

### 5.1 筛选与排序状态持久化

1. 记住当前搜索词
2. 记住当前筛选条件
3. 记住当前排序方式

### 5.2 视图恢复

1. 重新进入工作台时恢复最近一次列表视图
2. 若之前选中过页面，可在合理范围内恢复选中状态
3. 若恢复条件已失效，优雅回落到默认视图

### 5.3 状态重置入口

1. 提供清空全部筛选与排序状态入口
2. 避免持久化导致用户迷失在旧条件里
3. 让“恢复”和“重置”边界都清楚

### 5.4 测试补齐

1. 覆盖刷新后恢复搜索词
2. 覆盖恢复筛选与排序状态
3. 覆盖失效条件下的回落逻辑
4. 覆盖一键重置分支

## 6. 验收标准

1. 用户重新进入 Memory Wiki 时能延续上一次浏览上下文
2. 状态恢复不会造成混乱或死锁在旧条件里
3. 列表工作台更接近正式长期使用体验
4. 对应前端测试通过
