# 199-8.3-聊天侧记忆来源展开卡与引用边界增强

## 1. 任务目标

在 `174` 和 `187` 的记忆透明提示基础上，继续把聊天侧“本轮参考了哪些记忆 / 观察 / 历史线索”的展开层做得更可读、更克制，让用户既能看懂来源，又不会被强烈的监视感打扰。

## 2. 背景与现状

当前已经有轻量提示方向，但还缺：

1. 当用户想进一步看时，缺少合适的展开层
2. 引用来源之间的边界仍不够清楚
3. 长期记忆、观察日志、聊天记录被引用时缺少统一的展开表达

## 3. 涉及范围

- 聊天消息渲染链路
- `ToolResultPanel.vue`
- 如有必要，新增记忆来源展开卡组件
- 对应前端测试

## 4. 前置依赖

1. `174-8.3-记忆引用透明提示与工具结果面板增强.md` 已完成或至少已有轻量提示
2. `187-8.3-长期记忆可见边界与记忆采用提示增强.md` 已完成或至少已有采用边界表达

## 5. 具体开发项

### 5.1 来源展开卡

1. 当用户点击轻提示时，可展开来源摘要卡
2. 来源卡按长期记忆、观察日志、聊天记录等分类展示
3. 每类只展示有限数量摘要，避免信息过载

### 5.2 引用边界表达

1. 明确区分“长期记忆引用”“观察日志引用”“聊天历史引用”
2. 不把所有来源混成一句模糊提示
3. 对长期记忆保持克制表达，不拟人化

### 5.3 跳转与关闭体验

1. 支持从来源卡跳转到对应 Memory Wiki 页面、观察日志或聊天日期
2. 支持快速收起来源卡
3. 不让来源卡遮挡聊天主阅读链路

### 5.4 静默边界

1. 当引用来源极少或价值较低时，允许只展示轻提示不展开
2. 当本轮没有引用相关内容时，保持完全静默
3. 避免把每轮对话都渲染得过度“系统化”

### 5.5 测试补齐

1. 覆盖来源展开卡渲染
2. 覆盖不同来源分类展示
3. 覆盖跳转入口
4. 覆盖仅轻提示 / 无提示的静默分支

## 6. 验收标准

1. 用户可以按需展开查看本轮引用来源
2. 长期记忆、观察日志、聊天历史三类来源边界清晰
3. 来源提示保持透明但不过度打扰
4. 对应前端测试通过
