## 3. 目标设计

### 3.1 历史聊天分页

单日聊天记录需要支持：

- offset / cursor 分页
- 长对话懒加载
- 稳定排序

### 3.2 跨日检索

需要支持：

- 按关键词检索日期
- 按关键词检索消息片段
- 返回命中日期、片段、总数

### 3.3 Prompt 边界

主链 prompt 不得因为历史聊天存得多就默认整包带入。

要求：

- 当天近轮真实消息仍保持固定硬裁剪
- 历史聊天仅能通过 recall / tool 按需引入

### 3.4 存储实现边界

保持 `better-sqlite3` 运行时路线，不回退到全量内存整库导出模式。
