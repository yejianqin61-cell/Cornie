# 090 长期记忆 Wiki 摘要注入主链替换

## 1. 任务目标

为 `M10 模型上下文装载模块` 将当前会话 prompt 中的长期记忆部分，从旧 `memory` 表摘要为主，升级为以 `LLM wiki + topic index + 原始事实摘要` 为核心的正式长期记忆上下文装载链。

## 2. 任务来源

- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 13.1 节
- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 16.3.10 节 `M10 模型上下文装载模块`

## 3. 前置依赖

- `M1-M9` 已完成

## 4. 涉及范围

- `electron/backend/agent/`
- `electron/backend/memory-wiki/`
- `scripts/`

## 5. 当前问题

当前 prompt 中虽然有“长期记忆摘要”，但仍主要来自旧 memory 表，不是本期已经建设好的 LLM wiki 体系，导致：

- 新的 wiki 页面无法成为默认上下文主来源。
- topic index 与页面重要性无法参与默认注入优先级。
- 长期记忆和聊天/观察原始事实的正式链路没有真正进入模型主链。

## 6. 目标设计

本任务完成后应具备：

- 默认注入基于 wiki 的长期记忆摘要。
- 注入少量高优先级页面摘要而不是全量正文。
- 保留必要的最近对话、观察日志、待办、日程摘要。

## 7. 实现步骤

### Step 1

定义新的长期记忆上下文摘要结构。

### Step 2

接入 memory wiki 页面摘要和 topic index 辅助信息。

### Step 3

替换会话上下文构建主链并补验证脚本。

## 8. 测试点

- 上下文中可见 wiki 摘要。
- 归档页面不默认进入注入。
- 高重要度页面优先进入摘要。

## 9. 完成标准

- 模型主链已正式使用 LLM wiki 摘要作为长期记忆注入核心。

## 10. 交付物

- 新的上下文装载代码
- 对应验证脚本
