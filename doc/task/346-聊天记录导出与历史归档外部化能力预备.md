# 346-聊天记录导出与历史归档外部化能力预备

## 1. 任务目标

围绕聊天记录长期归档方案，补齐“导出”这一明确的外部化能力，为后续历史备份、迁移、用户自留存和更换底层存储做准备。

## 2. 任务来源

- `doc/design/Cornie-0630-聊天记录存储与历史归档改造方案.md`

## 3. 涉及范围

- `electron/backend/chatlog/service.js`
- `electron/backend/chatlog/routes.js`
- `src/renderer/api.js`
- `src/renderer/ChatHistory.vue` 或对应聊天记录页面

## 4. 当前问题

当前聊天记录已经具备按日归档、按月查看、按关键词搜索能力，但还没有：

- 按日导出
- 按月导出
- 明确导出契约
- 为未来冷归档或手动备份留出接口

## 5. 目标设计

- 提供聊天记录导出接口与统一返回结构
- 支持至少按日导出纯文本或结构化 JSON
- 前端保留导出入口或最小调用能力
- 不与当前 `sql.js` / 未来 `better-sqlite3` 实现细节强耦合

## 6. 实现步骤

### Step 1

定义聊天记录导出的 service 契约与返回结构。

### Step 2

接入路由层与前端 API。

### Step 3

补一个最小前端入口或保留位，并验证导出内容结构。

## 7. 测试点

- 可导出指定日期聊天记录
- 导出结果结构稳定
- 前端不会因底层驱动差异而改动接口层

## 8. 完成标准

- 聊天记录导出能力可用
- 历史归档外部化有正式接口落点
