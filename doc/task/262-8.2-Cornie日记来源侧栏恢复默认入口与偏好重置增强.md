# 262-8.2-Cornie日记来源侧栏恢复默认入口与偏好重置增强

## 1. 任务目标

在 `254` 和 `259` 已补齐 Cornie 日记来源侧栏的状态记忆、密度控制和弱数据态基础上，继续提供清晰的“恢复默认”入口与偏好重置逻辑，让用户在长期使用后能主动回到系统推荐视图。

## 2. 背景与现状

一旦来源侧栏支持折叠、密度和状态记忆，长期使用就会自然积累个性化偏好。若没有显式重置能力，会出现：

1. 用户忘了自己改过什么，侧栏表现越来越不像默认设计
2. 稀疏来源日和丰富来源日之间切换后，旧偏好影响新的阅读感受
3. 出现异常体验时，用户缺少一键回到默认状态的办法

## 3. 涉及范围

- Cornie 日记回看页
- 来源透明侧栏偏好状态
- 恢复默认入口与提示
- 对应前端测试

## 4. 前置依赖

1. `254-8.2-Cornie日记来源侧栏折叠状态记忆与默认密度增强.md` 已完成或至少已有偏好状态记忆
2. `259-8.2-Cornie日记来源侧栏弱数据态与多来源稀疏场景增强.md` 已完成或至少已有弱数据态适配

## 5. 具体开发项

### 5.1 恢复默认入口

1. 提供清晰但不突兀的“恢复默认视图”入口
2. 让用户知道这会重置哪些内容，如折叠状态、默认密度、弱数据态下的自定义偏好
3. 恢复默认入口在需要时易找，但不抢正文焦点

### 5.2 偏好重置逻辑

1. 重置后恢复系统推荐的侧栏密度和折叠策略
2. 区分“临时本次重置”和“长期偏好重置”的行为边界
3. 保持不同日期之间的状态恢复逻辑清楚

### 5.3 弱数据态兼容

1. 在弱数据态下执行恢复默认后，应回到适合稀疏来源的表达
2. 不让重置操作把弱数据态页面变得臃肿
3. 让默认值本身随数据量保持合理弹性

### 5.4 用户感知

1. 恢复默认后给出轻量确认反馈
2. 用户应能明显感受到页面回到了更“原生”的状态
3. 不制造复杂设置面板感

### 5.5 测试补齐

1. 覆盖恢复默认入口展示
2. 覆盖重置后的状态恢复
3. 覆盖弱数据态下的重置效果
4. 覆盖跨日期后的偏好行为一致性

## 6. 验收标准

1. Cornie 日记来源侧栏具备清晰可控的恢复默认能力
2. 长期使用后用户不会被旧偏好困住
3. 重置逻辑与弱数据态兼容良好
4. 对应前端测试通过
