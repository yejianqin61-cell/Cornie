# 186-8.3-Topic-Index日期联动与主题时间轴阅读增强

## 1. 任务目标

在现有 Topic Index 列表与详情基础上，继续补齐“主题 - 日期 - 原始记录”三者之间的阅读链路，让用户能够围绕某个主题直接看到：

1. 这个主题在什么日期被频繁提起
2. 这些日期分别对应哪些聊天记录、观察日志、记忆页面
3. 主题热度是如何随时间变化的

## 2. 背景与现状

当前前端已经具备或已规划：

1. Topic Index 基础列表与详情能力
2. Topic 治理与别名处理入口
3. 聊天记录按天浏览能力
4. 观察日志与 Memory Wiki 的来源追溯任务拆解

但仍缺少以下阅读体验：

1. 用户很难从 Topic 详情直接定位到某个具体日期
2. “龙虾在 6 月 27 日、6 月 30 日被多次提起”这类时间感知仍未前端化
3. 主题热度虽然有治理意义，但缺少对用户可读的时间轴承接
4. Topic 到聊天记录 / 观察日志 / Wiki 的跨域跳转链路仍不完整

## 3. 涉及范围

- `src/renderer/components/MemoryWikiWorkspace.vue` 或 Topic 详情相关组件
- 如有必要，新增 Topic 时间轴子组件
- 如有必要，补充 Topic 日期聚合接口
- 对应前端测试

## 4. 前置依赖

1. `178-8.3-Topic-Index详情与主题治理工作台增强.md` 已完成
2. `176-8.1-聊天记录来源联动与记忆回溯增强.md` 已完成
3. `177-8.2-观察日志联动阅读与来源追溯增强.md` 已完成或至少具备来源跳转基础

## 5. 具体开发项

### 5.1 Topic 日期时间轴

1. 在 Topic 详情页增加按日期排序的时间轴或日期列表
2. 每个日期节点至少展示提及次数、关联来源类型、最后更新时间
3. 支持按最近优先或按热度优先切换排序

### 5.2 日期节点详情抽屉

1. 点击某个日期后，展示当天与该主题相关的聊天记录摘要
2. 展示当天相关观察日志摘要
3. 展示当天相关 Memory Wiki 页面或引用页
4. 若当天存在 Cornie 日记或人类日记，也可提供只读关联入口

### 5.3 热度变化可读化

1. 以简单图表或列表方式展示主题热度变化趋势
2. 明确区分“近期持续活跃”和“历史高峰后衰减”
3. 不要求做复杂可视化，但要让用户能看懂趋势

### 5.4 主题快速回溯入口

1. 支持从 Topic 详情直接跳转到对应日期的聊天记录页
2. 支持跳转到对应观察日志页
3. 支持跳转到相关 Wiki 页面详情
4. 跳转时尽量保留主题过滤条件或回退路径

### 5.5 测试补齐

1. 覆盖 Topic 日期时间轴渲染
2. 覆盖不同排序方式切换
3. 覆盖日期详情抽屉展示
4. 覆盖跨域跳转入口渲染
5. 覆盖无相关日期或低数据量时的空态

## 6. 验收标准

1. 用户能够围绕一个主题快速看到相关日期分布
2. 用户能够从主题直接回看当天聊天、观察、记忆内容
3. 主题热度衰减与活跃变化具备可读化前端表达
4. Topic Index 从“治理面板”进一步提升为“阅读与回溯工作台”
5. 对应前端测试通过
