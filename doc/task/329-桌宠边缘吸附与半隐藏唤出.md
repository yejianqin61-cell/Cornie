# 329-桌宠边缘吸附与半隐藏唤出

## 1. 任务目标

为桌宠窗口补齐边缘吸附与半隐藏唤出能力，让桌宠在拖到屏幕左侧、右侧、顶部边缘时自动缩进去，只保留一部分可见主体，并在鼠标靠近时自动滑出。

## 2. 背景与现状

当前桌宠虽然已经支持：

1. 极简壳层
2. 可拖动
3. 屏幕边界碰撞箱

但仍存在两个体验缺口：

1. 桌宠虽然不会被拖出屏幕，却仍然完整占据边缘区域。
2. 用户在不同页面中希望桌宠“常在但不碍事”，当前仍缺少贴边半隐藏形态。

## 3. 涉及范围

- `electron/main.js`
- `electron/preload.cjs`
- `src/renderer/CorniePet.vue`

## 4. 前置依赖

1. 桌宠碰撞箱已存在。
2. 整个桌宠窗口可拖动能力已存在。

## 5. 具体开发项

### 5.1 吸附判定

1. 当桌宠拖动结束时，判断是否接近屏幕左边、右边、上边。
2. 仅在进入吸附阈值时触发半隐藏。
3. 底边不参与吸附。

### 5.2 半隐藏位置

1. 左侧吸附时，仅露出一部分桌宠主体。
2. 右侧吸附时，仅露出一部分桌宠主体。
3. 顶部吸附时，仅露出一部分桌宠主体。
4. 半隐藏后仍必须保证用户可以重新唤出。

### 5.3 唤出与缩回

1. 鼠标移入桌宠可见区域时，桌宠自动滑出。
2. 鼠标离开后，若未固定、未聚焦、未发送中，则延迟缩回。
3. 输入中、固定中、发送中不自动缩回。

### 5.4 状态同步

1. 渲染层需要知道当前桌宠是否处于贴边隐藏态。
2. 主进程与渲染层之间需要有最小状态同步接口。

## 6. 验收标准

1. 桌宠拖到左、右、上边缘时可自动吸附并半隐藏。
2. 半隐藏后，鼠标靠近能自动唤出。
3. 非交互状态下，鼠标离开后可自动缩回。
4. 构建通过。
