# 062 主题索引存储结构与基础读写

## 1. 任务目标

为 `M3 关键词/主题索引模块` 建立正式索引载体，先实现主题索引文件结构、基础读写、索引项模型和持久化入口。

## 2. 任务来源

- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 11 节
- `doc/design/Cornie-0627-长期记忆LLM-Wiki正式设计.md` 第 16.3.3 节 `M3 关键词/主题索引模块`

- `M1 Markdown Wiki 存储模块` 已完成
- `M2 Memory Wiki 服务模块` 已完成

## 4. 涉及范围

- `electron/backend/memory-wiki/`
- `scripts/`

## 5. 当前问题

现在虽然已有 wiki 页面和页面索引，但还没有正式的关键词/主题索引结构，无法支持：

- 关键词 -> 日期
- 关键词 -> 页面
- 关键词 -> 来源引用

## 6. 目标设计

本任务完成后应具备：

- `keyword-index.json` 正式结构。
- 索引项创建、读取、更新。
- 基础字段：`keyword`、`normalized_key`、`aliases`、`dates`、`memory_page_ids`、`importance`。
