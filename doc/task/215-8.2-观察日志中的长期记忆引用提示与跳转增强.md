# 215-8.2-观察日志中的长期记忆引用提示与跳转增强

## 1. 任务目标

在 `177` 的观察日志联动阅读基础上，继续把“某条观察日志已被长期记忆页面引用”这件事做成更清楚的提示与跳转入口，让用户在观察日志页也能意识到：哪些事实已经进入长期记忆层。

## 2. 背景与现状

当前任务链已经支持观察日志与 Memory Wiki 的联动阅读，但仍缺：

1. 观察日志页里对“已进入长期记忆”的轻提示
2. 从观察日志直接跳到引用它的记忆页面
3. 用户对观察层到记忆层的沉淀感知仍偏弱

## 3. 涉及范围

- 观察日志详情区
- 联动阅读摘要区
- 对应前端测试

## 4. 前置依赖

1. `177-8.2-观察日志联动阅读与来源追溯增强.md` 已完成或至少已有相关记忆页展示

## 5. 具体开发项

### 5.1 长期记忆引用提示

1. 当观察日志已被一个或多个记忆页面引用时，展示轻提示
2. 提示语义强调“已被引用为长期记忆线索之一”
3. 不把提示做成夸张的“永久记住你”表达

### 5.2 跳转入口

1. 支持从观察日志直接跳转到相关 Memory Wiki 页面
2. 若有多个页面，可提供列表式选择
3. 保持回退路径清晰

### 5.3 空态边界

1. 尚未被长期记忆引用时不制造焦虑式提示
2. 可用平实文案说明“目前还没有沉淀到长期记忆页”
3. 保持观察层与记忆层边界清楚

### 5.4 测试补齐

1. 覆盖已被引用时的提示分支
2. 覆盖多页面引用分支
3. 覆盖无引用空态
4. 覆盖跳转入口

## 6. 验收标准

1. 用户能从观察日志页感知哪些事实已进入长期记忆层
2. 用户能顺畅跳到引用它的记忆页面
3. 提示风格透明但不过度拟人化
4. 对应前端测试通过
