# 249-8.2-Cornie日记回到同日总览的状态保持与回流提示增强

## 1. 任务目标

在 `245` 和 `246` 已补齐 Cornie 日记回看链路与来源透明侧栏的基础上，继续增强从 Cornie 日记页返回同日总览时的状态保持和回流提示，让用户回到总览后还能看懂自己刚从哪里回来、刚看过什么。

## 2. 背景与现状

Cornie 日记回看页一旦能跳回同日总览，新的问题就会变成“回来以后还能不能接得上”。如果没有进一步收口，会出现：

1. 用户回到同日总览后，不清楚自己刚才看的是哪一篇日记
2. 总览页状态被重置，之前的展开区块和阅读位置丢失
3. 回流后缺少轻量提示，用户要重新建立上下文

## 3. 涉及范围

- 同日关系总览面板
- Cornie 日记页返回同日总览的链路
- 前端本地状态保持
- 对应前端测试

## 4. 前置依赖

1. `245-8.2-观察日志到Cornie日记生成后回看链路与来源回跳增强.md` 已完成或至少已有日记回跳链路
2. `246-8.2-Cornie日记回看时的来源透明侧栏与素材摘要增强.md` 已完成或至少已有日记回看页来源侧栏
3. `244-8.1-同日关系面板已查看已完成状态与收口增强.md` 已完成或至少已有同日关系面板状态体系

## 5. 具体开发项

### 5.1 返回总览状态保持

1. 从 Cornie 日记回到同日总览时，尽量恢复原来的日期定位
2. 保持总览中已展开区块、已选中卡片或阅读位置
3. 不让日记回流打断用户原本的同日浏览节奏

### 5.2 回流提示

1. 回到总览后，轻量提示“刚刚看过今天的 Cornie 日记”
2. 提示应短暂、可关闭，不长期占据面板焦点
3. 帮助用户迅速确认自己当前位于哪条链路上

### 5.3 状态同步

1. 回流后同步更新同日关系面板中 Cornie 日记的已查看状态
2. 若日记刚刚生成成功，也同步刷新完成态表达
3. 已查看与已完成两类状态要继续保持区分

### 5.4 异常兜底

1. 若返回时同日总览上下文不存在，提供合理默认落点
2. 若当天日记已变更或删除，给出平实说明
3. 不把回流失败包装成严重错误

### 5.5 测试补齐

1. 覆盖从日记页回到总览的状态恢复
2. 覆盖回流提示展示与关闭
3. 覆盖已查看 / 已完成状态同步
4. 覆盖上下文缺失时的默认回退

## 6. 验收标准

1. 从 Cornie 日记返回同日总览后，用户不需要重新找回上下文
2. 同日总览状态保持稳定，不轻易被重置
3. 回流提示轻量、清楚、不打扰
4. 对应前端测试通过
