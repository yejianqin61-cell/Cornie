# 206-8.3-Topic热度与最近活跃可读化增强

## 1. 任务目标

在 `178` 和 `186` 的 Topic 详情基础上，继续把“热度”“最近提及日期”“活跃变化”做成更易读的人类前端表达，让 Topic 详情不只是治理入口，也能成为用户理解主题状态的阅读面板。

## 2. 背景与现状

当前任务链已经提到 Topic 的热度、最近提及日期和时间轴，但仍可以继续细化：

1. 热度数值本身可读性有限
2. 最近活跃与历史高峰的区别不够直观
3. 用户不容易一眼看出某主题现在是活跃、沉寂还是回温

## 3. 涉及范围

- Topic 详情面板
- 如有必要，热度摘要子组件
- 对应前端测试

## 4. 前置依赖

1. `178-8.3-Topic-Index详情与主题治理工作台增强.md` 已完成或至少已有 Topic 详情
2. `186-8.3-Topic-Index日期联动与主题时间轴阅读增强.md` 已完成或至少已有日期时间轴方向

## 5. 具体开发项

### 5.1 热度摘要表达

1. 不只展示热度数值，还展示可读标签
2. 例如区分近期活跃、持续活跃、近期较少提及等状态
3. 保持文案克制，不做夸张拟人化表达

### 5.2 最近活跃信息

1. 清楚展示最近提及日期
2. 若与今天较近，可提示“最近几天仍在被提起”
3. 若长时间未提及，可提示“近期较少出现”

### 5.3 活跃变化辅助阅读

1. 结合时间轴或最近记录提供简短趋势说明
2. 让用户能区分“历史高峰”与“当前活跃”
3. 不要求复杂图表，但要有足够解释力

### 5.4 测试补齐

1. 覆盖不同热度状态标签
2. 覆盖最近活跃日期分支
3. 覆盖历史高峰与当前活跃区分分支
4. 覆盖无足够数据时的简化展示

## 6. 验收标准

1. 用户能直观看懂 Topic 当前活跃程度
2. 热度与最近活跃信息具备人类可读性
3. Topic 详情更像状态面板而不只是治理面板
4. 对应前端测试通过
