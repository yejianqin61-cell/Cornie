# 171-8.3-治理筛选与详情证据面板增强

## 1. 任务目标

在 `168` 完成后，继续增强治理待审核区的筛选与详情证据面板，让“为什么给出这条建议、证据是什么、应该怎么看”更容易被人类理解。

## 2. 背景与现状

当前治理区已经具备：

1. 状态筛选
2. 分区筛选
3. 详情展示
4. 证据块显示

但仍可能存在：

1. 证据阅读成本偏高
2. 列表信息密度不足
3. 筛选后缺少更明显的当前上下文提示

## 3. 涉及范围

- `src/renderer/components/MemoryWikiWorkspace.vue`
- 对应前端测试

## 4. 具体开发项

### 4.1 筛选提示增强

1. 显示当前筛选上下文
2. 让“全部状态 / 分区”与当前结果关系更清楚

### 4.2 证据面板增强

1. 让证据块更易扫描
2. 区分“原因”“证据”“建议动作”
3. 对无证据 / 无原因场景给出更好的说明

### 4.3 测试补齐

1. 覆盖筛选摘要
2. 覆盖证据展示与空证据状态

## 5. 验收标准

1. 治理建议的阅读与理解成本进一步下降
2. 当前筛选条件更明确
3. 对应前端测试通过

## 6. 提交要求

建议提交信息：

`feat(frontend): improve governance evidence and filter context`
