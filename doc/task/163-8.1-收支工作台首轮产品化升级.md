## 4. 具体开发项

### 4.1 页面结构升级

1. 将类目管理区拆成“编辑器 + 分区列表 + 当前操作条”
2. 将支出类目、收入类目分别展示
3. 让“记录区 / 编辑区 / 类目区”形成更清晰的信息层级

### 4.2 类目管理闭环升级

1. 点击类目卡片后，进入编辑态
2. 编辑态应能回填类目名称、类型、排序
3. 编辑态应支持返回“新增类目”模式
4. 当前选中类目应支持停用 / 恢复

### 4.3 文案与反馈升级

1. 页面标题、区块说明、按钮命名更面向人类用户
2. 当前操作对象应有明显提示，例如“正在管理类目：xxx”
3. 停用 / 恢复动作文案要显式对应当前类目

## 5. 验收标准

1. 收支页出现清晰的收入 / 支出类目分区
2. 可以点击类目卡片进入编辑态并保存
3. 可以对当前选中类目执行停用 / 恢复
4. 相关前端异步测试通过
