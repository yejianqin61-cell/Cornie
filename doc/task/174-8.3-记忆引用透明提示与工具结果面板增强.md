# 174-8.3-记忆引用透明提示与工具结果面板增强

## 1. 任务目标

补齐“模型做了什么、用了哪些记忆、哪些工具执行成功或失败”的前端透明提示，让用户在聊天侧能够更自然地理解铃湾的行为，而不是只看到最终回答。

## 2. 背景与现状

当前仓库中已经存在：

1. 工具结果面板 `ToolResultPanel.vue`
2. 对话消息中的工具执行结果展示基础
3. 长期记忆 / 观察日志 / 聊天记录会被装载进模型上下文

但当前前端仍存在缺口：

1. 工具结果信息密度较低，只能看到非常薄的一层“成功/失败”
2. 用户无法感知“这轮对话是否引用了长期记忆”
3. 缺少更适合正式产品的轻提示，而不是完全黑箱

## 3. 涉及范围

- `src/renderer/components/ToolResultPanel.vue`
- 聊天相关组件，例如 `CorniePet.vue` 或其消息渲染链路
- 如有必要，补充前端数据映射
- 对应前端测试

## 4. 具体开发项

### 4.1 工具结果面板增强

1. 区分只读补查、写入、失败三类工具结果
2. 增加更清晰的标题、摘要、来源说明
3. 当无摘要但有结果信息时，提供更友好的兜底展示

### 4.2 记忆引用轻提示

1. 若当前轮使用了长期记忆摘要或观察补查结果，提供轻量可见提示
2. 提示要避免恐怖谷效应，不做“我永远记得你”的重口吻表达
3. 提示应以“本轮参考了哪些历史线索/记忆”一类平实表达为主

### 4.3 聊天阅读体验配套增强

1. 工具结果区与正常聊天内容区分明确
2. 工具失败时给出更容易理解的状态反馈
3. 保持铃湾整体口吻一致，不引入过强工程感

### 4.4 测试补齐

1. 覆盖工具结果成功/失败/只读补查展示
2. 覆盖无摘要时的兜底展示
3. 覆盖记忆引用提示的渲染分支

## 5. 验收标准

1. 用户能更直观看到工具执行结果
2. 用户能轻量感知本轮是否参考了历史记忆
3. 提示风格克制，不制造恐怖谷体验
4. 对应前端测试通过
