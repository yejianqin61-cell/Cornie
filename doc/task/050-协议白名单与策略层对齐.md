# 050 协议白名单与策略层对齐

## 1. 任务目标

把 `7.3` 新增和已有但未放开的工具，统一补进 JSON 协议允许范围、风险等级和策略层准入口径，避免“工具注册了但模型不能合法调用”。

## 2. 任务来源

- `doc/Cornie-004-当前模块实现度评估与下阶段开发建议.md` 第 4.4、4.5 节
- `doc/design/module/003-tool-policy/Cornie-003-工具策略层模块-改进设计.md`
- `doc/design/module/004-tool-gateway-json/Cornie-004-JSON协议与工具网关模块-改进设计.md`

## 3. 前置依赖

- `047-049` 主体完成

## 4. 涉及范围

- `electron/backend/agent/jsonProtocol.js`
- `electron/backend/policy/riskLevels.js`
- `electron/backend/policy/rules.js`

## 5. 当前问题

当前部分工具虽然已经存在，但：

- category mapping 校验只覆盖少数 action tool
- 风险等级与策略层规则未随工具增长同步扩展
- 工具层、协议层、策略层三层存在不一致风险

## 6. 目标设计

- 新增工具进入协议校验范围
- 高风险工具进入确认流或显式策略
- 只读工具默认低风险直通

## 7. 实现步骤

### Step 1

扩展协议层允许工具与参数校验范围。

### Step 2

补齐风险等级映射。

### Step 3

补齐策略层针对新工具的准入规则。

### Step 4

做一轮对齐自检。

## 8. 测试点

- 合法工具调用不被误拦截
- 高风险工具进入确认
- 非法 payload 被正确拒绝

## 9. 完成标准

- 工具注册、协议、风险、策略四层口径一致

- 协议与策略对齐代码
- 对应验证结果
