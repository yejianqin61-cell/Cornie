# 368-聊天记录单日长会话分页与懒加载契约深化

## 1. 目标

在聊天记录 repository 驱动升级基础上，继续深化单日长会话的分页与懒加载契约，为前端“超长日期聊天记录阅读”提供正式的数据接口边界。

- `doc/design/Cornie-0630-聊天记录存储与历史归档改造方案.md`

## 2. 涉及范围

- `electron/backend/chatlog/service.js`
- 聊天记录路由层
- `scripts/`

## 3. 任务要求

- 单日聊天详情支持：
  - 按 cursor / offset / beforeId 形式分页
  - 首屏只拉最近一段
  - 明确是否还有更早消息
- 返回结构需包含：
  - `items`
  - `nextCursor` 或等价游标
  - `hasMore`
  - 当前日期上下文元信息
- 与历史搜索、日期阅读能力保持兼容

## 4. 验收标准

- 单日长会话分页契约完整可用
- 不破坏现有按日读取接口的兼容性
- 新增验证脚本
- `npm run build` 通过
