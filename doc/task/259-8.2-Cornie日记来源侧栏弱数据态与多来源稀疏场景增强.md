# 259-8.2-Cornie日记来源侧栏弱数据态与多来源稀疏场景增强

## 1. 任务目标

在 `254` 已补齐 Cornie 日记来源侧栏状态记忆与密度控制的基础上，继续处理来源较少、来源层稀疏、同日素材不完整时的弱数据态，让侧栏在轻素材日也保持自然。

## 2. 背景与现状

并不是每一天都会同时有观察日志、聊天记录、人类日记三层素材。若来源侧栏只按“来源很多”的情况设计，会出现：

1. 来源很少时侧栏显得空壳
2. 缺少某些来源层时，用户误以为系统漏了
3. 稀疏场景下仍强行铺满侧栏，会破坏日记正文阅读感

## 3. 涉及范围

- Cornie 日记来源透明侧栏
- 素材摘要区
- 弱数据态与稀疏场景文案
- 对应前端测试

## 4. 前置依赖

1. `246-8.2-Cornie日记回看时的来源透明侧栏与素材摘要增强.md` 已完成或至少已有侧栏基础
2. `254-8.2-Cornie日记来源侧栏折叠状态记忆与默认密度增强.md` 已完成或至少已有密度控制

## 5. 具体开发项

### 5.1 弱数据态分类

1. 区分“只有少量来源”和“某类来源当天不存在”
2. 区分“素材层本来就少”和“数据尚未补齐”
3. 不把所有来源不足都表达成同一种空态

### 5.2 稀疏侧栏表达

1. 来源很少时，采用更简洁的摘要式布局
2. 对缺失来源层给出平实说明，不制造系统异常感
3. 保持侧栏的存在感，但不强行填满结构

### 5.3 正文优先兼容

1. 弱数据态下进一步降低侧栏对正文的打扰
2. 在来源信息很少时默认更紧凑
3. 不因为数据稀疏就让页面显得“坏了”或“空了”

### 5.4 回跳边界

1. 若某类来源当天不存在，对应回跳入口不应误展示
2. 若只有一种来源层，则突出这条真实链路
3. 保持来源透明，但不过度承诺不存在的内容

### 5.5 测试补齐

1. 覆盖单一来源层场景
2. 覆盖来源层缺失场景
3. 覆盖素材很少但非空的弱数据态
4. 覆盖弱数据态下的侧栏密度变化

## 6. 验收标准

1. Cornie 日记来源侧栏在轻素材日也表现自然
2. 用户不会把来源稀疏误解为系统异常
3. 弱数据态表达不破坏日记正文体验
4. 对应前端测试通过
