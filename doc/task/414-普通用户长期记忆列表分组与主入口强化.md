# 414-普通用户长期记忆列表分组与主入口强化

## 1. 任务目标

把当前普通用户长期记忆列表页从“统一平铺卡片”升级为“按记忆含义分组的阅读入口”，让用户能更自然地区分：

1. 关于你
2. 重要的人
3. 你的偏好
4. 你的特征

本任务要解决的不是后端能力缺失，而是普通用户在前端看到长期记忆时，仍然像在看一堆技术对象，而不是在看“铃湾帮我记住的生活内容”。

## 3. 背景与现状

当前普通用户长期记忆入口已经具备：

1. 查看长期记忆列表
2. 新建记忆
3. 打开详情
4. 在详情页进行新建、编辑、删除
5. 查看来源摘要

但当前列表页仍有几个问题：

1. 所有记忆页直接混在一起，缺少“这是关于什么的”阅读结构
2. `identity_profile / person / preference / trait` 虽然已有普通文案，但入口仍不够像产品首页
3. 用户很难一眼看出“关于我自己的主记忆”和“别人相关的记忆”有什么区别
4. 缺少面向普通用户的轻量统计和分组提示

## 5. 开发项

### 5.1 增加分组结构

按以下四组组织列表：

1. 关于你
2. 重要的人
3. 你的偏好
4. 你的特征

要求：

1. 每组有标题与一句普通用户能看懂的说明
2. 每组只展示属于该组的页面
3. 没有内容的组可以折叠成温和空态，不要显得页面很空

### 5.2 增加顶部总览

在列表页头部增加轻量总览，至少包括：

1. 长期记忆总数
2. 重要的人页数量
3. 偏好与特征页数量，或其他等价的轻量摘要

要求：

1. 文案平实
2. 不出现治理术语
3. 不做复杂图表

### 5.3 强化“关于你”主入口语义

如果存在 `identity_profile` 页面，应在列表中给予更明确的位置与语义，让用户一眼知道：

1. 这是铃湾记住“你是谁”的地方
2. 它是整套长期记忆里最核心的一类

本任务不要求自动创建默认 profile 页面，但要求在呈现上体现它的优先级。

### 5.4 保持普通用户边界

本任务明确不做：

1. Topic Index 入口
2. 审计入口
3. 版本历史
4. 合并治理
5. 高级工作台透传

## 6. 验收标准

1. 长期记忆列表页按四类语义完成分组展示
2. 页面顶部能让普通用户快速理解当前长期记忆大致构成
3. `identity_profile` 在视觉上具备主入口优先级
4. 页面整体不暴露高级治理术语
5. 移动端下分组与卡片仍可正常阅读

## 7. 自测清单

1. 同时存在四类页面时，检查是否被正确分组
2. 缺失其中某一类时，检查空态是否自然
3. 只有一页 `identity_profile` 时，检查是否足够突出
4. 新建一页后返回列表，检查是否进入对应分组
5. 手机宽度下检查头部和分组卡片是否挤坏
