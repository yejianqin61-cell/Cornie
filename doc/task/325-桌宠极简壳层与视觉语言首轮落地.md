# 325-桌宠极简壳层与视觉语言首轮落地

## 1. 任务目标

依据以下设计文档：

1. `Cornie-0628-桌宠窗口重设计方案.md`
2. `Cornie-0628-桌宠前端视觉语言设计方案.md`

完成桌宠窗口第一阶段落地，把当前旧桌宠渲染组件改造成“可直接使用的极简陪伴壳层”，至少完成安静态、悬浮态、输入态的视觉与交互基础。

## 2. 背景与现状

当前桌宠仍存在以下问题：

1. `src/renderer/CorniePet.vue` 仍是旧桌宠拼装式实现。
2. 视觉风格仍偏深色、小面板、工具流展示，不符合新设计。
3. 窗口默认呈现内容太重，不是“颜文字 + 轻浮层”的极简状态。
4. 旧桌宠编辑态、眨眼覆盖层、身体部件结构仍强耦合在主组件中。

## 3. 涉及范围

- `src/renderer/CorniePet.vue`
- `src/renderer/cornieMain.js`
- `src/renderer/style.css`
- `electron/main.js`
- 如有必要可新增桌宠专用小组件或样式变量

## 4. 前置依赖

1. `Cornie-0628-桌宠窗口重设计方案.md` 已明确桌宠是轻陪伴层。
2. `Cornie-0628-桌宠前端视觉语言设计方案.md` 已明确桌宠视觉语言。

## 5. 具体开发项

### 5.1 组件结构重构

1. 去掉旧桌宠中与身体拼装、眼睛覆盖层、编辑态调试直接耦合的主渲染结构。
2. 将桌宠主体改为：
   - 颜文字主体
   - 浮层消息区
   - 单行输入区
3. 主组件内部至少应形成清晰的状态分区，而不是把所有旧逻辑继续堆在一起。

### 5.2 安静态与悬浮态

1. 默认只显示小型颜文字框。
2. 鼠标进入后显示轻量浮层。
3. 浮层不应默认常驻大面积背景面板。
4. 鼠标移出后，在未固定、未聚焦前提下可自动收起。

### 5.3 视觉语言落地

1. 引入浅暖色、软边缘、轻阴影的桌宠专用视觉变量。
2. 输入框、消息气泡、颜文字框都要遵循新的圆角和留白规则。
3. 不再使用当前深色半透明聊天条样式。
4. 视觉上禁止继续出现后台式按钮堆叠。

### 5.4 桌宠窗口尺寸与壳层适配

1. 调整 `cornieWindow` 初始尺寸，使其更接近轻浮层壳体。
2. 保留透明、无边框、可拖动能力。
3. 确保默认状态下不会因为窗口过大而形成空旷黑块。

## 6. 验收标准

1. 桌宠默认只呈现轻量颜文字主体。
2. 鼠标进入后才出现对话浮层与输入区。
3. 视觉风格明显转向浅暖、轻漂浮，而非旧深色面板。
4. 桌宠仍可拖动。
5. 项目构建通过。
