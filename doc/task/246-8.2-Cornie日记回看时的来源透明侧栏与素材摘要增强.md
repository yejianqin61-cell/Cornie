# 246-8.2-Cornie日记回看时的来源透明侧栏与素材摘要增强

## 1. 任务目标

在 `245` 已补齐观察日志到 Cornie 日记生成后回看链路的基础上，继续增强 Cornie 日记回看时的来源透明侧栏和素材摘要区，让用户可以轻量理解这篇日记参考了哪些来源层，而不破坏文学表达本身。

## 2. 背景与现状

Cornie 日记既要保留精灵口吻和人文关怀，又要让用户知道它不是凭空出现的。若没有进一步设计，会出现：

1. 用户不知道这篇日记大致参考了哪些来源
2. 一旦想核对素材，只能完全跳回观察日志或聊天记录
3. 过度透明又可能把日记页做得像审计页面

## 3. 涉及范围

- Cornie 日记回看页
- 来源透明侧栏或摘要区
- 到观察日志 / 聊天记录 / 人类日记的轻量回跳
- 对应前端测试

## 4. 前置依赖

1. `184-8.1-Cornie日记来源透明与生成后工作流.md` 已完成或至少已有来源透明方向
2. `245-8.2-观察日志到Cornie日记生成后回看链路与来源回跳增强.md` 已完成或至少已有回看链路
3. `180-8.1-聊天记录与观察日志日记关系工作台.md` 已完成或至少已有同日关系语义

## 5. 具体开发项

### 5.1 来源透明侧栏

1. 在 Cornie 日记回看页提供轻量来源侧栏或摘要区
2. 摘要表达“参考了当天观察日志 / 聊天记录 / 人类日记”等层级信息
3. 只做来源层说明，不把文学内容拆成逐句溯源

### 5.2 素材摘要

1. 提供当天素材量级、是否有观察日志、是否有人类日记等轻量摘要
2. 帮助用户快速判断这篇日记的背景丰度
3. 不在日记页展开过多原始材料正文

### 5.3 回跳入口

1. 支持从日记页轻量回跳到观察日志或聊天记录
2. 保留回到同日关系总览的入口
3. 回跳语义应以“查看素材”或“回看当天记录”为主，避免生硬技术感

### 5.4 表达边界

1. 透明侧栏不应压过 Cornie 日记正文
2. 侧栏默认可折叠或次级展示
3. 既要让来源透明，又要避免破坏人文关怀体验

### 5.5 测试补齐

1. 覆盖来源透明侧栏渲染
2. 覆盖有不同来源层时的摘要差异
3. 覆盖回跳观察日志 / 聊天记录入口
4. 覆盖侧栏折叠与展开状态

## 6. 验收标准

1. Cornie 日记回看页具备适度来源透明能力
2. 用户可以理解日记与当天素材的关系而不被审计感打断
3. 回跳链路清楚、克制
4. 对应前端测试通过
