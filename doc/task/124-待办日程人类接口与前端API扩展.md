# 124 待办日程人类接口与前端 API 扩展

## 1. 任务目标

为 `todo / schedule` 及其类目域补齐人类可调用的后端接口，并在前端 API 层提供等价调用封装。

## 2. 任务来源

- `doc/Cornie-013-当前项目完成度复评与后续行动建议.md` 第 `8.2` 节

## 3. 前置依赖

- `123` 已完成

## 4. 涉及范围

- `electron/backend/todo/`
- `electron/backend/schedule/`
- `electron/server.js`
- `src/renderer/api.js`

## 5. 当前问题

`todo / schedule` 服务层与工具层已具备生命周期能力，但当前缺少人类接口与前端 API 封装，导致待办页、日程页和类目管理页无法落地。

## 6. 目标设计

- 增加待办 CRUD、open/completed、reopen 接口
- 增加日程 CRUD、upcoming/cancelled、restore 接口
- 增加 todo/schedule 类目读取、创建、更新、恢复、排序接口
- 在前端 API 层补齐对应请求函数

## 7. 实现步骤

### Step 1

新增 `todo` 人类接口路由文件。

### Step 2

新增 `schedule` 人类接口路由文件。

### Step 3

补 todo/schedule 及类目域的前端 API 封装。

## 8. 测试点

- 待办 open/completed/reopen 可调用
- 日程 upcoming/cancelled/restore 可调用
- todo/schedule 类目管理接口可调用

## 9. 完成标准

- 待办日程域拥有正式人类接口
- 前端具备可直接调用的待办与日程 API

## 10. 交付物

- 待办日程人类接口
- 前端待办日程 API 封装
