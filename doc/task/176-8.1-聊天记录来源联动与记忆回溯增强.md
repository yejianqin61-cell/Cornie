# 176-8.1-聊天记录来源联动与记忆回溯增强

## 1. 任务目标

在 `172` 聊天记录工作台产品化增强的基础上，继续把聊天记录页从“按天翻阅消息”升级为“可参与长期记忆回溯”的正式前端入口，让用户能从某一天的聊天记录继续追到相关 Memory Wiki 页面、相关主题和记忆来源链。

## 2. 背景与现状

当前系统已经具备：

1. 聊天记录按天归档与读取能力
2. 聊天记录到 Memory Wiki 来源引用补链
3. 聊天记录到 Topic Index 沉淀链路
4. 聊天记录基础前端翻阅入口

但前端目前仍看不到：

1. 某一天聊天记录是否已被长期记忆引用
2. 某一天聊天记录关联了哪些记忆页面
3. 某一天聊天记录沉淀到了哪些主题
4. 聊天记录在长期记忆治理链路中的位置

这导致聊天记录页当前仍偏“历史阅读器”，还不是“知识来源入口”。

## 3. 涉及范围

- `src/renderer/ChatHistory.vue`
- `src/renderer/api.js`
- 如有必要，补充聊天记录只读路由或聚合只读接口
- 对应前端测试

## 4. 前置依赖

1. `172-8.1-聊天记录工作台产品化增强.md` 已完成
2. 聊天记录到 Wiki / Topic 的后端补链已可被读取

## 5. 具体开发项

### 5.1 当天聊天记录来源摘要区

1. 在聊天记录页增加“这一天后来沉淀成了什么”摘要区
2. 显示该日期是否被 Memory Wiki 页面引用
3. 显示命中的相关主题数量
4. 对无关联的日期给出空态说明，而不是沉默留白

### 5.2 相关记忆页面联动阅读

1. 支持展示与当天聊天记录相关的 Memory Wiki 页面列表
2. 至少显示页面标题、状态、重要性、摘要片段
3. 支持从聊天记录页跳转到对应记忆页面
4. 明确说明这些页面是“引用了该日聊天记录”，避免误导为“当天自动生成了这些页面”

### 5.3 相关主题联动阅读

1. 支持展示与当天聊天记录相关的 Topic Index 项
2. 至少显示主题名、热度或关联度、关联页面数
3. 支持从聊天记录页进入对应主题详情或主题视图

### 5.4 聊天记录与观察日志 / 日记边界提示

1. 增加解释文案，说明聊天记录、观察日志、Cornie 日记、长期记忆四者职责不同
2. 让用户知道聊天记录是原始对话事实来源之一，而不是最终记忆本体

### 5.5 测试补齐

1. 覆盖“有相关 Memory Wiki 页面”的渲染分支
2. 覆盖“有相关 Topic”的渲染分支
3. 覆盖无关联来源时的空态
4. 覆盖跳转入口或详情展开逻辑

## 6. 验收标准

1. 聊天记录页不再只是按天看消息，而是具备来源回溯入口
2. 用户可从聊天记录页继续追到相关记忆页面与主题
3. 前端能清晰解释聊天记录在记忆链路中的角色
4. 对应前端测试通过
