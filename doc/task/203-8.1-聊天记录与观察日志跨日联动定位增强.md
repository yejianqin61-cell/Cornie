# 203-8.1-聊天记录与观察日志跨日联动定位增强

## 1. 任务目标

在 `176`、`177`、`180` 的同日联动基础上，继续补齐聊天记录与观察日志之间“跨日查看、跨页定位”的阅读体验，让用户不仅能看同一天的关系，还能围绕一个时间段顺畅来回切换。

## 2. 背景与现状

当前任务链已经覆盖了同日关系，但进一步使用时仍会遇到：

1. 用户想从聊天记录连续查看前后几天的观察沉淀
2. 用户想从观察日志反向看相邻日期聊天情况
3. 跨页后容易丢失当前日期上下文

## 3. 涉及范围

- `ChatHistory.vue`
- 观察日志工作台
- 如有必要，日期上下文保持逻辑
- 对应前端测试

## 4. 前置依赖

1. `176-8.1-聊天记录来源联动与记忆回溯增强.md` 已完成或至少已有联动阅读入口
2. `177-8.2-观察日志联动阅读与来源追溯增强.md` 已完成或至少已有观察侧联动入口
3. `180-8.1-聊天记录与观察日志日记关系工作台.md` 已完成或至少已有同日关系视图

## 5. 具体开发项

### 5.1 跨页日期上下文保持

1. 从聊天页跳到观察日志页时保留目标日期
2. 从观察日志页跳回聊天页时保留目标日期
3. 清楚标示当前查看的是哪一天

### 5.2 相邻日期快速切换

1. 在聊天页或观察页提供前一天 / 后一天快速切换
2. 若相邻日期无记录，给出可理解的提示
3. 不让跨页切换后日期上下文丢失

### 5.3 时间段阅读辅助

1. 支持用户围绕最近几天连续阅读聊天与观察
2. 让用户更容易判断“事实层整理是否跟上了对话层”
3. 保持界面轻量，不做过度复杂的时间轴

### 5.4 测试补齐

1. 覆盖跨页日期保持
2. 覆盖相邻日期切换
3. 覆盖无记录日期提示
4. 覆盖聊天页与观察页双向跳转

## 6. 验收标准

1. 用户可以围绕某段时间连续阅读聊天与观察
2. 跨页跳转后日期上下文不会丢失
3. 同日关系视图进一步延伸为时间段阅读能力
4. 对应前端测试通过
