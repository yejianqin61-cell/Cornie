# 180-8.1-聊天记录与观察日志日记关系工作台

## 1. 任务目标

在 `172` 与 `176` 的聊天记录产品化基础上，继续补齐“聊天记录 / 观察日志 / Cornie 日记 / 人类日记”四者关系的前端承接，让用户不再只能分别进入几个页面，而是能理解这些内容在同一天内如何流转、如何分工、如何互相成为来源。

## 2. 背景与现状

当前前端已经具备：

1. 人类日记主页面
2. 聊天记录按天翻阅入口
3. 观察日志已规划独立工作台
4. 长期记忆与 Memory Wiki 独立工作台

但仍存在明显问题：

1. 用户难以理解“同一天的聊天、观察、日记、记忆”之间的关系
2. 前端缺少一个按日期聚合的跨页面关系视图
3. 用户无法快速判断“今天的信息沉淀到哪一步了”
4. 日记生成前后的素材来源边界仍偏抽象

## 3. 涉及范围

- `src/renderer/App.vue`
- 日记页、聊天记录页、观察日志页之间的导航与联动
- 如有必要，新增按日期聚合的轻量关系面板
- 对应前端测试

## 4. 前置依赖

1. `172-8.1-聊天记录工作台产品化增强.md` 已完成
2. `173-8.2-观察日志人类工作台首轮落地.md` 已完成
3. `176-8.1-聊天记录来源联动与记忆回溯增强.md` 已完成或至少提供基础联动入口

## 5. 具体开发项

### 5.1 同日关系摘要区

1. 在按日期浏览时，增加“今天的内容流转”摘要区
2. 展示当天是否已有聊天记录
3. 展示当天是否已有观察日志
4. 展示当天是否已有人类日记、Cornie 日记

### 5.2 四层职责说明

1. 明确说明聊天记录是原始对话层
2. 明确说明观察日志是事实记录层
3. 明确说明人类日记是用户主观表达层
4. 明确说明 Cornie 日记是铃湾整理后的关怀表达层

### 5.3 跨页跳转入口

1. 支持从某一天的聊天记录跳转到当天观察日志
2. 支持从某一天的观察日志跳转回当天聊天记录
3. 支持从当日日记区查看当天素材是否充足
4. 保持跳转语义清晰，不制造“自动等同”的误解

### 5.4 当天沉淀状态提示

1. 当聊天记录很多但观察日志为空时，提示“事实层仍待整理”
2. 当观察日志已存在但 Cornie 日记为空时，提示“可以生成 Cornie 日记”
3. 当几层内容都存在时，提示“今天的记录链路已比较完整”

### 5.5 测试补齐

1. 覆盖同日关系摘要渲染
2. 覆盖跨页跳转入口展示
3. 覆盖当天沉淀状态提示的不同分支

## 6. 验收标准

1. 用户能从前端直观看懂同一天聊天、观察、日记之间的分工
2. 用户能在几个相关页面之间快速跳转
3. 前端能提示当天记录链路是否完整
4. 对应前端测试通过
