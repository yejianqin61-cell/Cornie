# 194-8.1-聊天记录日期摘要与长对话阅读收口

## 1. 任务目标

在 `172` 聊天记录工作台产品化增强基础上，继续补齐“日期摘要 + 长对话阅读体验”这两个最直接影响使用感受的部分，让聊天记录工作台真正从“可看”向“正式历史工作台”收口。

## 2. 背景与现状

`172` 已经提出要补头部摘要、日期定位、空态和长对话阅读体验，但这几块仍可继续拆成更具体的开发任务，避免后续实现时范围过大、标准模糊。

## 3. 涉及范围

- `src/renderer/ChatHistory.vue`
- 如有必要，聊天记录摘要读取辅助逻辑
- 对应前端测试

## 4. 前置依赖

1. `172-8.1-聊天记录工作台产品化增强.md` 已完成或至少已有增强版工作台骨架

## 5. 具体开发项

### 5.1 日期摘要头部

1. 在选中日期顶部展示当天对话摘要
2. 至少展示消息条数、首尾时间、是否为今天
3. 在合适处展示“最近一次聊天日”或相邻日期信息

### 5.2 长对话阅读体验

1. 长对话情况下保持消息区滚动与定位清晰
2. 明确用户消息与铃湾消息层次
3. 允许快速回到顶部或最近消息位置

### 5.3 日期切换与回落体验

1. 月份为空时给出清楚解释
2. 日期切换后保持稳定焦点与滚动体验
3. 当前日期无数据时有可理解的回落策略提示

### 5.4 空态与上下文说明

1. 当天没有聊天时，展示空态说明
2. 长时间未聊天时，文案保持平实，不制造压力
3. 保持聊天记录是“原始对话层”的边界表达

### 5.5 测试补齐

1. 覆盖日期摘要渲染
2. 覆盖长对话阅读分支
3. 覆盖月份空态与日期回落
4. 覆盖回到顶部 / 最近消息入口

## 6. 验收标准

1. 聊天记录页具备清楚的日期摘要
2. 长对话浏览体验明显优于基础列表态
3. 日期切换与空态提示更加稳定、可理解
4. 对应前端测试通过
