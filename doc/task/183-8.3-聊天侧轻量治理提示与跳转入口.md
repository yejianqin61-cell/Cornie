# 183-8.3-聊天侧轻量治理提示与跳转入口

## 1. 任务目标

在 `174` 记忆引用透明提示基础上，继续补齐聊天侧与治理工作台之间的轻量连接，让聊天界面在不承接治理主流程的前提下，具备“有新的治理候选 / 有可查看的记忆来源 / 可跳转到对应工作台”的低打断提示能力。

## 2. 背景与现状

当前聊天侧已经规划或具备：

1. 工具结果面板
2. 确认卡片
3. 记忆引用轻提示

但还缺少：

1. 对“新增治理候选”的轻量提醒
2. 对“可去 Memory Wiki 查看详情”的明确跳转入口
3. 对“这里只提示，不在这里审批”的产品边界表达

## 3. 涉及范围

- 聊天消息渲染链路
- `ToolResultPanel.vue`
- `ConfirmCard.vue`
- 如有必要，主壳层导航跳转能力
- 对应前端测试

## 4. 前置依赖

1. `174-8.3-记忆引用透明提示与工具结果面板增强.md` 已完成
2. `181-8.2-Memory-Wiki待审核角标与异步提醒增强.md` 已完成或至少提供待审核状态读取能力

## 5. 具体开发项

### 5.1 聊天侧治理轻提示

1. 当本轮对话产生新的治理候选时，聊天侧可显示轻提示
2. 提示语义应为“可前往 Wiki 查看”，而不是“请立刻在此确认”
3. 避免把聊天流变成治理审批流

### 5.2 跳转入口

1. 提供跳转到 Memory Wiki 待审核区的快捷入口
2. 若本轮使用了具体记忆页面，也可提供跳转到对应页面详情的入口
3. 入口应清楚标识目标，不让用户猜

### 5.3 聊天侧边界说明

1. 对话区只承接提醒、来源说明、结果摘要
2. 正式治理与巡检处理应回到 Memory Wiki 工作台
3. 高风险动作不应在本任务中重新拉回聊天弹窗确认

### 5.4 测试补齐

1. 覆盖出现治理候选时的轻提示展示
2. 覆盖无治理候选时的静默状态
3. 覆盖跳转入口渲染
4. 覆盖不会在聊天侧承接逐条治理的边界

## 6. 验收标准

1. 聊天区能轻量提示新的治理候选
2. 用户可从聊天区跳转到对应治理工作台或记忆页面
3. 聊天区与治理工作台之间的职责边界清晰
4. 对应前端测试通过
