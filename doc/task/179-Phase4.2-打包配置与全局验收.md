# 179-Phase4.2-打包配置与全局验收

## 目标

配置 electron-builder 打包，并进行全模块穿越验收。

## 改造范围

### 1. electron-builder 配置

- `package.json` 中添加 `build` 配置
- Windows NSIS 安装包
- 应用图标
- 输出目录 `release/`

### 2. 全局验收清单

| 模块 | 验证项 |
|------|--------|
| 聊天 | 发送消息 / 日期导航 / 历史加载 / 错误重试 |
| 日记 | 月历切换 / 日记卡片 / 往年今日 / 编辑保存 / Cornie 生成 |
| 记账 | 收支列表 / 新增表单 / 删除确认 / 筛选 |
| 日程 | 日程列表 / 新增 / 取消 / 恢复 |
| 待办 | 待办列表 / 新增 / 完成 / 删除 |
| 观察 | 列表筛选 / 详情加载 / 新建编辑 / 删除 / 关联记忆 |
| 记忆维基 | 树形导航 / 页面详情 / 编辑保存 / 治理面板 / Topic 筛选 |
| 设置 | 模型配置加载/保存/清除/状态反馈 |
| 桌宠 | 透明窗口 / 拖拽 / 点击打开主窗口 |
| 窗口 | 最小化 / 最大化 / 关闭 |
| 侧边栏 | 全模块切换 |

### 3. 验收测试脚本

在 `scripts/verify-phase4.mjs` 中编写全局验收脚本。

## 验收标准

- [ ] `electron-builder` 配置可用
- [ ] 全局穿越无阻断
- [ ] 所有模块可正常切换
