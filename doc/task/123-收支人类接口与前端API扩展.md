# 123 收支人类接口与前端 API 扩展

## 1. 任务目标

为 `ledger / ledger_category` 补齐人类可调用的后端接口，并在前端 API 层提供等价调用封装。

## 2. 任务来源

- `doc/Cornie-013-当前项目完成度复评与后续行动建议.md` 第 `8.2` 节

## 3. 前置依赖

- `8.1` 已完成

## 4. 涉及范围

- `electron/backend/ledger/`
- `electron/server.js`
- `src/renderer/api.js`

## 5. 当前问题

`ledger` 服务层和模型工具层已经存在，但当前没有正式的人类后端接口与前端 API 调用封装，因此前端无法构建收支记录页和类目管理页。

## 6. 目标设计

- 增加收支记录 CRUD 与查询接口
- 增加收支类目读取、创建、更新、恢复接口
- 在前端 API 层补齐对应请求函数

## 7. 实现步骤

### Step 1

新增 `ledger` 人类接口路由文件。

### Step 2

把记录查询、详情、创建、更新、删除、按类目筛选、最近记录等能力接出。

### Step 3

把类目列表、统一列表、详情、创建、更新、恢复能力接出。

### Step 4

在 `src/renderer/api.js` 中补齐收支域 API 封装。

## 8. 测试点

- 记录 CRUD 可调用
- 最近记录与按类目查询可调用
- 类目统一列表与恢复接口可调用

## 9. 完成标准

- 收支域拥有正式人类接口
- 前端具备可直接调用的收支 API

## 10. 交付物

- 收支人类接口
- 前端收支 API 封装
