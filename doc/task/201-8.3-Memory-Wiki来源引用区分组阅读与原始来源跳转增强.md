# 201-8.3-Memory-Wiki来源引用区分组阅读与原始来源跳转增强

## 1. 任务目标

在 `175` 的来源引用与关联阅读基础上，继续把 Memory Wiki 页面详情中的“来源引用区”做成更可读、更可追溯的阅读区，让用户能够：

1. 区分来源是聊天记录、观察日志还是其他页面
2. 快速跳到原始来源
3. 理解当前页面的主要证据来自哪里

## 2. 背景与现状

`175` 已经提出要补来源引用区，但如果继续细化到正式可开发粒度，还需要：

1. 来源按类型分组阅读
2. 来源条目的摘要信息统一化
3. 到原始来源的跳转入口更明确

## 3. 涉及范围

- Memory Wiki 页面详情来源区
- 如有必要，来源条目子组件
- 对应前端测试

## 4. 前置依赖

1. `175-8.3-Memory-Wiki来源引用与关联阅读增强.md` 已完成或至少已有来源区骨架

## 5. 具体开发项

### 5.1 来源分组阅读

1. 按聊天记录、观察日志、相关页面等类型分组展示来源
2. 每组展示数量与简短说明
3. 保持分组可折叠，避免长来源列表压垮详情页

### 5.2 来源条目摘要统一

1. 每条来源至少展示来源类型、标题或日期、简短摘要
2. 对缺少标题的来源提供稳定兜底文案
3. 当前页面最主要的来源应具备更强可见性

### 5.3 原始来源跳转

1. 支持跳转到原始聊天日期
2. 支持跳转到对应观察日志条目
3. 支持跳转到相关 Memory Wiki 页面

### 5.4 空态与来源缺失边界

1. 无来源时给出平实空态
2. 来源失效时给出失效标记或只读提醒
3. 不把失效来源和正常来源混在一起难以分辨

### 5.5 测试补齐

1. 覆盖来源分组渲染
2. 覆盖跳转入口
3. 覆盖无来源空态
4. 覆盖来源失效边界

## 6. 验收标准

1. 用户能够在页面详情中快速看懂来源结构
2. 用户能够从 Memory Wiki 直接回到原始来源
3. 来源区具备正式阅读能力，而不是简单附属列表
4. 对应前端测试通过
