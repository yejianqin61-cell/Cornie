# 205-8.3-Memory-Wiki相关页面区阅读与关系说明增强

## 1. 任务目标

在 `175` 的相关页面区基础上，继续把 Memory Wiki 页面详情中的“相关页面”区域做成更适合阅读和理解关系的工作区，让用户不只看到页面名，还能理解这些页面为什么相关。

## 2. 背景与现状

当前任务链已经提出要展示相关页面，但如果继续推进到正式可开发粒度，还缺：

1. 相关页面之间关系说明不足
2. 相关页面条目阅读信息不够
3. 用户看不出是同主题、同来源还是互相引用导致的关联

## 3. 涉及范围

- Memory Wiki 页面详情相关页面区
- 如有必要，相关页面关系说明子组件
- 对应前端测试

## 4. 前置依赖

1. `175-8.3-Memory-Wiki来源引用与关联阅读增强.md` 已完成或至少已有相关页面区骨架

## 5. 具体开发项

### 5.1 相关页面条目增强

1. 每个相关页面至少展示标题、状态、简短摘要
2. 若有重要性或最近更新时间，可轻量展示
3. 当前页面与相关页面区分清楚

### 5.2 关系说明

1. 对每条关联尽量说明是同主题、同来源还是互相引用
2. 无法确定时使用克制兜底说明，而不是硬编理由
3. 让用户理解“为什么会出现在相关页面区”

### 5.3 跳转与阅读连续性

1. 支持跳转到相关页面详情
2. 跳转后保持回退路径清晰
3. 不让用户在连续阅读多个页面时迷路

### 5.4 空态与低相关边界

1. 无相关页面时给出空态
2. 对低相关度关联避免过度堆叠
3. 保持详情页信息量可控

### 5.5 测试补齐

1. 覆盖相关页面条目渲染
2. 覆盖关系说明分支
3. 覆盖跳转入口
4. 覆盖无相关页面空态

## 6. 验收标准

1. 用户能够看懂相关页面区展示的关联意义
2. 用户可以顺畅从当前页面连续阅读多个相关页面
3. 相关页面区从“附属列表”提升为“关系阅读区”
4. 对应前端测试通过
