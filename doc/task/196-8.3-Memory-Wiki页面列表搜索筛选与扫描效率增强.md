# 196-8.3-Memory-Wiki页面列表搜索筛选与扫描效率增强

## 1. 任务目标

在现有 Memory Wiki 工作台基础上，继续补齐页面列表的搜索、筛选和扫描效率，让用户能够把 Memory Wiki 当成一个真正可管理的页面集合，而不只是从局部入口进入单页或治理区。

## 2. 背景与现状

前端备忘录中已经明确提出 Memory Wiki 需要正式列表页能力，包括状态筛选、类型筛选、重要性筛选，以及按标题 / 别名 / 关键词搜索。当前虽然已有工作台，但这块仍未单独任务化。

## 3. 涉及范围

- `src/renderer/components/MemoryWikiWorkspace.vue`
- 页面列表区与筛选栏
- 如有必要，前端搜索条件适配层
- 对应前端测试

## 4. 前置依赖

1. `126-Memory-Wiki与Topic-Index前端工作台.md` 已完成
2. `190-8.3-Memory-Wiki页面详情编辑与保存前diff增强.md` 已形成页面详情编辑方向

## 5. 具体开发项

### 5.1 页面列表基础信息

1. 页面列表至少展示标题、状态、重要性、更新时间
2. 若有别名或类型信息，可轻量显示
3. 当前选中页面状态清晰可见

### 5.2 搜索能力

1. 支持按标题搜索
2. 支持按别名搜索
3. 支持按关键词搜索
4. 搜索为空、无结果时给出不同空态

### 5.3 筛选能力

1. 支持按状态筛选
2. 支持按类型筛选
3. 支持按重要性筛选
4. 筛选项组合后保持结果可理解

### 5.4 扫描效率优化

1. 支持按更新时间或重要性排序
2. 长列表下保持快速扫描体验
3. 在搜索与筛选状态下，仍能顺畅进入页面详情与治理区

### 5.5 测试补齐

1. 覆盖标题 / 别名 / 关键词搜索
2. 覆盖状态 / 类型 / 重要性筛选
3. 覆盖无结果空态
4. 覆盖排序与选中状态

## 6. 验收标准

1. 用户能够把 Memory Wiki 当成页面集合来管理
2. 搜索和筛选足以支撑中等规模页面量的使用
3. 页面列表扫描效率明显提升
4. 对应前端测试通过
