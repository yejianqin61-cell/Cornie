# 221-8.3-Memory-Wiki详情区块折叠与阅读密度控制增强

## 1. 任务目标

在 `217`、`201`、`205`、`197` 已补齐详情阅读与跳转体验的基础上，继续把 Memory Wiki 详情页做成更适合长时间阅读和治理操作的正式工作台，支持区块折叠、阅读密度切换和重点内容优先展示。

## 2. 背景与现状

当前 Memory Wiki 详情页已经承载正文、来源、相关页面、版本等多个信息区块，但随着信息持续变多，仍会出现：

1. 用户只想处理某一块内容时，被长页面其他区块打断
2. 每次进入详情页都要重复滚动和寻找重点区域
3. 长页面在“深读”和“快速扫读”之间缺少切换能力

## 3. 涉及范围

- Memory Wiki 详情页
- 详情页区块头部交互
- 前端本地视图状态持久化
- 对应前端测试

## 4. 前置依赖

1. `217-8.3-Memory-Wiki详情页滚动定位与回退体验增强.md` 已完成或至少已有详情页区块结构
2. `201-8.3-Memory-Wiki来源引用区分组阅读与原始来源跳转增强.md` 已完成或至少已有来源区
3. `205-8.3-Memory-Wiki相关页面区阅读与关系说明增强.md` 已完成或至少已有相关页面区
4. `197-8.3-Memory-Wiki版本历史阅读与差异对比增强.md` 已完成或至少已有版本区

## 5. 具体开发项

### 5.1 区块折叠能力

1. 支持对正文、来源、相关页面、版本等区块分别展开或折叠
2. 折叠后保留区块标题、摘要和数量信息，避免完全失去上下文
3. 默认优先展开最常用区块，其余区块根据页面长度和内容量做轻量收起

### 5.2 阅读密度切换

1. 提供“紧凑阅读”和“展开阅读”两种密度模式
2. 紧凑模式突出摘要、状态和核心关系
3. 展开模式保留完整阅读体验，适合人工核对来源、查看版本和精修页面

### 5.3 重点区优先展示

1. 当用户从来源引用、巡检结果或相关页面跳入详情时，优先展示目标区块
2. 页面首屏优先呈现标题、状态、重要性、最近更新时间等关键信息
3. 避免把低优先级区块长期压在首屏之上

### 5.4 状态记忆与恢复

1. 记住当前详情页最近一次的密度选择
2. 在合理范围内记住区块折叠状态
3. 不让旧页面的折叠偏好污染完全不同的新页面

### 5.5 测试补齐

1. 覆盖区块折叠与恢复
2. 覆盖不同密度模式渲染
3. 覆盖从外部入口跳入详情后的重点区优先展示
4. 覆盖状态记忆隔离逻辑

## 6. 验收标准

1. Memory Wiki 长详情页具备可控的信息密度
2. 用户能更快聚焦当前要处理的区块
3. 折叠和密度切换不会破坏详情阅读结构
4. 对应前端测试通过
