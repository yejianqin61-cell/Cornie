# 388 聊天记录系统只读工具能力补齐

## 目标

补齐聊天记录的人类侧已存在能力到模型侧系统只读工具，使模型也能按协议完成：

- 列出历史聊天日期归档
- 分页补读单日长对话
- 导出某个月的聊天记录归档

## 设计依据

- `doc/design/Cornie-0630-聊天记录存储与历史归档改造方案.md`
- 其中明确要求：
  - 聊天记录支持“全部月份 / 最近30天 / 指定月份”
  - 单日聊天记录支持长列表懒加载
  - 增加聊天记录导出能力

## 当前缺口

- 人类侧目前已支持：
  - 历史日期列表
  - 单日详情分页
  - 月份导出
- 模型侧系统工具目前只有：
  - `conversation.get_day_record`
  - `conversation.search_day_records`
- 仍缺：
  - 列出聊天归档日期视图的工具
  - 分页补读单日长会话的工具
  - 月份归档导出的工具

## 本任务范围

1. 在 system tools 中新增聊天记录只读工具
2. 不改动现有 chatlog service 协议，只做能力暴露
3. 确保模型和其他后台调用可直接使用

## 实现要求

1. 新增工具：
   - `conversation.list_history_dates`
   - `conversation.get_day_page`
   - `conversation.export_month_record`
2. 工具能力分别对应：
   - 日期归档视图
   - 单日分页补读
   - 月份导出
3. 所有工具保持只读、`riskLevel: low`
4. 不移除旧工具，保持兼容

## 验收标准

1. 工具集中能注册上述三个新工具
2. `conversation.list_history_dates` 可返回 `scope/month/query/pagination/archiveScope`
3. `conversation.get_day_page` 可返回分页上下文与 `items`
4. `conversation.export_month_record` 可返回月份导出 payload
5. 验证脚本通过
6. `npm run build` 通过
