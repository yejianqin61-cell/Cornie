# 411-收支趋势图坐标轴与图例增强

## 1. 任务目标

将收支页趋势图从“装饰性折线”提升为“可读的信息图”，补齐坐标轴、刻度、图例和基础网格语义，让普通用户能看懂日期趋势与金额变化。

## 2. 对应来源

- GitHub Issue `#13` 收支页面
- 设计文档：`doc/design/Cornie-0701-GitHub-Issue-011-015前端问题分级与落地设计.md`
- 补充设计文档：`doc/design/Cornie-0701-GitHub-Open-Issue-011-015正式落地设计.md`

## 3. 背景与现状

当前收支页已有趋势图雏形，但缺少基本图表语义：

1. 横轴不清楚代表什么
2. 纵轴不清楚金额尺度
3. 图线缺少足够参照
4. 更像视觉装饰，而不是帮助理解数据

用户明确指出需要：

1. 第一象限感
2. X/Y 轴
3. 更完整的统计图表达

## 4. 涉及范围

- `src/renderer/components/LedgerHome.vue`
- 如趋势图已拆组件，则同步检查对应组件
- 如需新增独立图表组件，可新增：
  - `src/renderer/components/LedgerTrendChart.vue`

## 5. 前置依赖

1. 当前收支页已有按日聚合后的趋势数据。
2. 收入与支出曲线数据至少能在前端聚合获得。
3. 日历筛选和月度范围逻辑已存在。

## 6. 开发项

### 6.1 增加横轴语义

趋势图需要明确展示时间维度：

1. 横轴表示日期
2. 至少提供起点、中点、终点刻度
3. 刻度文案不宜过密

### 6.2 增加纵轴语义

趋势图需要明确展示金额尺度：

1. 纵轴表示金额
2. 至少展示：
   - 0
   - 中间量级
   - 当前图内最大值
3. 若金额为小数，应统一格式化

### 6.3 增加辅助网格或参考线

在不过度增加复杂度的前提下，补充轻量网格或参考线，帮助用户理解：

1. 哪些点更高
2. 波动幅度大概多少

### 6.4 强化图例表达

图例应明确告诉用户：

1. 红线代表支出
2. 绿线代表收入

不能只靠颜色本身，还应保留文案图例。

### 6.5 空态与低数据量处理

当数据不足时：

1. 不要画出误导性的“完整趋势图”
2. 应展示友好空态
3. 至少保证页面结构稳定，不抖动

## 7. 当前代码落点与改造要求

当前代码已经显示 `LedgerHome.vue` 内存在：

1. 趋势图框架尺寸定义
2. X/Y 轴刻度计算
3. 收入支出折线路径计算
4. 图例和轴说明位

因此本任务开发时应先判断：

1. 当前实现是否已经完成 issue 本体
2. 若已完成，是否还需要补视觉清晰度和异常数据分支
3. 若未完成，则优先在现有 SVG 方案上增强，而不是大改图表技术栈

## 8. 实现建议

### 7.1 优先保持轻量实现

若当前趋势图已经是 SVG 手绘实现，优先在现有基础上增强：

1. 轴线
2. 刻度文本
3. 参考线
4. 图例

避免为了这一项小增强就大范围重写整页图表方案。

### 7.2 文案与样式建议

1. 坐标文字要轻，不要抢正文注意力
2. 线条与网格的层级要分明
3. 保持 Cornie 产品整体温和风格，不做金融终端界面

### 7.3 不做事项

本任务不纳入：

1. 年度趋势
2. 多维筛选面板
3. 导出报表
4. 复杂交互 tooltip 系统重构

## 9. 建议开发顺序

1. 先检查 `LedgerHome.vue` 当前趋势图是否已具备 issue 所需轴线和图例。
2. 若基础语义已在，则继续核查刻度、低数据量、按日筛选后的稳定性。
3. 若仍有缺口，再补足轴线、网格、文案图例。
4. 最后回归验证不要破坏收支页已有的按日联动能力。

## 10. 验收标准

1. 趋势图具备明确的 X/Y 轴。
2. 用户能从图上直接理解横轴是日期、纵轴是金额。
3. 收入与支出曲线有明确图例说明。
4. 少数据与无数据时表现稳定且不误导。

## 11. 自测清单

1. 准备一个月内多日收支数据，确认横轴刻度显示合理。
2. 检查纵轴刻度是否与实际金额量级一致。
3. 核对某一天明显高支出时，图上位置确实抬高。
4. 检查收入/支出图例是否清楚可辨。
5. 删除当月数据后，确认空态正确。
