# 274-8.2-Cornie日记来源侧栏撤销超时后的再调入口增强

## 1. 任务目标

在 `271` 已补齐 Cornie 日记来源侧栏撤销入口超时后的收口策略基础上，继续细化超时后用户如果还想继续调整侧栏，应如何通过更轻量的再调入口回到可控状态。

## 2. 背景与现状

撤销超时后虽然页面进入稳定态，但用户仍可能马上意识到自己还想再改一点。若没有再调入口设计，会出现：

1. 用户错过撤销后只能重新摸索怎么改回来
2. 超时收口后像是“门关上了”，可控感不足
3. 恢复默认、再调偏好、普通浏览三者关系不清楚

## 3. 涉及范围

- Cornie 日记回看页
- 撤销超时后的次级入口
- 再调偏好链路
- 对应前端测试

2. `262-8.2-Cornie日记来源侧栏恢复默认入口与偏好重置增强.md` 已完成或至少已有恢复默认入口
3. `267-8.2-Cornie日记来源侧栏重置后的确认反馈微交互增强.md` 已完成或至少已有重置反馈链路

## 5. 具体开发项

### 5.1 超时后的再调入口

1. 在撤销窗口关闭后，保留更低调的“继续调整”入口
2. 入口不与临时撤销竞争，而是在稳定态下提供补救路径
3. 入口语义应清楚区分“撤销”与“重新调整”

### 5.2 路径清晰度

1. 用户通过再调入口能够快速回到侧栏控制点
2. 不要求进入复杂设置，只需回到当前页可操作状态
3. 保持正文阅读不中断

### 5.3 超时感知延续

1. 让用户知道撤销已结束，但调整能力仍保留
2. 文案和入口位置要传达“现在是后续调整，不是原样撤回”
3. 不制造错失焦虑

### 5.4 状态兼容

1. 再调入口与弱数据态、固定偏好、恢复默认逻辑兼容
2. 连续多次重置后，再调入口行为保持一致
3. 不让再调入口破坏前一次稳定态记忆

### 5.5 测试补齐

1. 覆盖撤销超时后再调入口展示
2. 覆盖通过再调入口回到可调状态
3. 覆盖与恢复默认入口并存时的语义区分
4. 覆盖连续重置后的入口一致性

## 6. 验收标准

1. 撤销超时后用户仍有清楚的再调路径
2. “撤销”与“继续调整”边界清楚
3. 超时收口不会削弱页面可控感
4. 对应前端测试通过
