# 420-长期记忆关于你页信息组织强化

## 1. 任务目标

把普通用户长期记忆中的“关于你”页，从“围绕自己写一段话”，进一步强化为“更容易组织自我信息”的页面。

重点不是做高级结构化表单，而是让用户更自然地表达：

1. 我是谁
2. 我希望铃湾怎样称呼我
3. 我和铃湾是什么关系
4. 我最近处在怎样的人生状态
5. 我现在最在意什么

## 3. 背景与现状

当前“关于你”页已经有：

1. 顶部说明区
2. 更贴近主身份的字段文案
3. 普通用户来源摘要

但它仍然存在问题：

1. 用户仍然不知道“应该先写哪些最重要的信息”
2. 名字、称呼、关系、近况这些信息都还混在自由文本里
3. 主身份页虽然更重要，但组织感还不够强

## 4. 涉及范围

- `src/renderer/components/MemoryPageDetail.vue`

## 5. 开发项

### 5.1 增加“关于你”专属信息骨架

当页面类型为“关于你”时，增加一块轻量提示区，引导用户优先思考：

1. 你叫什么
2. 你希望铃湾怎么叫你
3. 你和铃湾是什么关系
4. 你最近的状态
5. 你现在最在意什么

### 5.2 强化主身份页的填写顺序感

要让用户感到：

1. 这是最重要的一页
2. 不需要一次写全
3. 先把最关键的自我信息留下来就够了

### 5.3 优化“关于你”字段语义

继续优化“关于你”类型下的：

1. 标题
2. 摘要
3. 正文占位

让它更贴近“主身份页”，而不是泛泛地介绍自己。

## 6. 验收标准

1. “关于你”页具有明显的自我信息组织骨架
2. 用户能看懂主身份页最该先写哪些内容
3. 页面仍保持普通用户语义，不暴露高级治理术语
4. 现有来源摘要、保存、删除能力不受影响

## 7. 自测清单

1. 新建“关于你”页，检查提示是否围绕名字、称呼、关系、近况
2. 切到其他类型，确认“关于你”专属提示不会误显示
3. 保存、删除、来源摘要仍正常
4. 手机宽度下内容不应挤坏
