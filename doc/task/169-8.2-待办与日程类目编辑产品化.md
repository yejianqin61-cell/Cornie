# 169-8.2-待办与日程类目编辑产品化

## 1. 任务目标

在 [166-8.2-待办与日程类目及生命周期闭环增强.md](/C:/Users/USER/Desktop/Cornie/Cornie/doc/task/166-8.2-待办与日程类目及生命周期闭环增强.md:1) 完成后，继续补齐 Todo / Schedule 的类目编辑闭环，使其达到与账本类目管理接近的正式产品化程度。

本任务完成后，至少应支持：

1. 点击已有待办类目进入编辑态
2. 点击已有日程类目进入编辑态
3. 可编辑类目名与排序
4. 编辑态与“新增类目”态可清晰切换
5. 停用 / 恢复动作仍能围绕当前类目自然工作

## 2. 背景与现状

当前 Todo / Schedule 已具备：

1. 类目新增
2. 类目上移 / 下移
3. 类目停用 / 恢复

但仍缺少：

1. 对现有类目的显式选中
2. 对现有类目的编辑态
3. 当前正在管理哪个类目的操作提示

这会导致类目区仍更像“操作板”，而不是“正式治理面”。

## 3. 涉及范围

- `src/renderer/components/TodoWorkspace.vue`
- `src/renderer/components/ScheduleWorkspace.vue`
- 对应前端测试

## 4. 具体开发项

### 4.1 Todo 类目编辑闭环

1. 类目卡片支持点击选中
2. 选中后，类目表单回填当前值
3. 选中后，支持保存编辑结果
4. 支持从编辑态返回“新增类目”态

### 4.2 Schedule 类目编辑闭环

1. 类目卡片支持点击选中
2. 选中后，类目表单回填当前值
3. 选中后，支持保存编辑结果
4. 支持从编辑态返回“新增类目”态

### 4.3 反馈与测试

1. 页面应提示“正在管理类目：xxx”
2. 测试覆盖选中、编辑、停用 / 恢复后的状态切换

## 5. 验收标准

1. Todo / Schedule 类目都可直接选中并编辑
2. 新增态与编辑态切换清楚
3. 对应前端测试通过
