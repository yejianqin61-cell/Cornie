# Cornie Phase 1 聊天链治理收口简报

窗口：2026-10-22

基线：`Cornie-028-产品Demo改进施工计划` 的 Phase 1 一条真实聊天链能走完。

## 1. Headline

**本轮完成 6 项变更：聊天从失配的旧接口变为可流式、可重载、可确认的一条真实链。**

| # | Change | Where | Kind | State | What it means for the reader |
|---|---|---|---|---|---|
| C-1 | 真实 HTTP 契约测试 | `tests/services` | 新增 | 完成 | 聊天和确认接口失配会被直接发现 |
| C-2 | 聊天历史适配 | `src/renderer/api` | 修复 | 完成 | 日期、正文、角色和分页可正确显示 |
| C-3 | SSE 聊天发送 | `ChatPanel` | 已变更 | 完成 | 回复逐段出现，取消后可继续发送 |
| C-4 | 确认卡决定闭环 | `ConfirmCard` | 修复 | 完成 | 批准或拒绝会命中真实服务且不可重复 |
| C-5 | 全量测试门禁 | 构建配置与脚本 | 修复 | 完成 | 全量后端测试不再被 ESM lint 阻断 |
| C-6 | 可控模型端到端证明 | `tests/services` | 新增 | 完成 | 无外部模型也能证明聊天、历史和批准执行 |

常规变更：新增 6 份施工任务简报，并按任务分别提交。

## 2. What it means

开发态 Demo 的最短聊天路径现在经过同一组真实后端接口，而不是依赖过时前端假设。
用户可以看到流式文字，刷新后读回已保存消息，并对高风险动作作出一次有效决定。
测试使用可控模型替身，因此联调结果不受 API Key、网络或外部模型波动影响。

## 3. Still open

- 收支、待办、日程和完整记忆治理仍未进入本阶段，Demo 不能据此视为全业务可用。
- 聊天日期仍使用现有 UTC 取日规则，跨时区显示边界仍存在。
- 前端历史格式化基线仍未统一，当前质量门禁只覆盖既有后端、脚本、测试和构建配置范围。
- 安装包、分发路径和产品展示壳仍在后续阶段。
