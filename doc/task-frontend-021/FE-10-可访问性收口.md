# FE-10 可访问性收口（Accessibility Hardening）

## 背景

前端存在多处可访问性缺陷（Cornie-021 §3.2 F8）：

1. **可点击元素键盘不可达**：多处 `div@click`（无 role/tabindex/keydown），键盘用户无法操作。
2. **标题语义错误**：`CornieDiaryReview.vue` 在 `button` 内渲染 `h1`，读屏顺序混乱。
3. **配色冲突**：`AskBackBubble.vue` 深蓝黑底与全局暖色主题冲突（旧样式残留）。
4. **焦点管理缺失**：视图切换后焦点不落位，键盘操作不连续。

## 目标

1. 可点击 `div` 全部改为 `<button>`（或等价 role + tabindex + keydown 语义）。
2. 修正日记回顾区标题语义（`button` 内不渲染标题级元素）。
3. 弹窗/气泡配色对齐全局主题色板，去除旧样式残留。
4. 视图切换时焦点落位主操作区，键盘操作连续。

## 范围

- `src/renderer/**` 下所有 `div@click`（grep 定位，逐个评估）
- `src/renderer/components/CornieDiaryReview.vue`（标题语义）
- `src/renderer/components/AskBackBubble.vue`（配色对齐）
- `src/renderer/App.vue` 及主要视图切换点（焦点管理）
- `tests/frontend/` 新增可访问性断言测试

## 设计要求

### 1. 可点击元素改造

- 对每个 `div@click`（或 `span@click` 等）判定语义：
  - 触发动作/导航 → 改为 `<button>`（含 `type="button"`），保留样式（必要时用 reset 样式类保持视觉一致）；
  - 仅展开/折叠内容 → `<button>` + `aria-expanded`（若承载状态）；
  - 纯展示 → 移除点击样式与 handler。
- 全仓完成后 grep `@click` 不应出现在非交互元素上（保留项需注释说明）。
- 键盘可达：Tab 可聚焦、Enter/Space 触发与点击等价。

### 2. 语义修正

- `CornieDiaryReview.vue`：标题 `h1` 移出按钮；按钮只承载动作（如展开/收起），标题作为相邻文本或独立标题元素；读屏顺序为"标题 → 动作按钮"。
- 复查同类模式（按钮内嵌标题/段落）一并修正。

### 3. 主题对齐

- `AskBackBubble.vue`：配色改为全局主题色板（暖色系）；移除深蓝黑底等旧样式残留。
- 复查其他弹窗/气泡组件（ConfirmCard/ToolResultPanel 等）是否有同类残留，一并对齐（仅配色/字号，不改布局与文案）。

### 4. 焦点管理

- 视图切换（mode/view 变化）后，焦点移到主操作区（如输入框/首按钮/容器）；实现方式：`nextTick` 后 focus 目标元素，或容器 `tabindex="-1"` + focus。
- 弹窗打开聚焦弹窗、关闭归还触发元素（若现有确认流未做，补最小实现）。

## 验收标准

1. 新增 a11y 断言测试全部通过：
   - 每个交互元素键盘可触发：`trigger('keydown.enter')` / `trigger('click')` 产生等价结果（抽主要组件断言）。
   - `CornieDiaryReview` 无"button 内 h1"（DOM 断言）。
   - 视图切换后焦点落位断言（抽 1-2 个主要切换点）。
2. 现有交互测试（composer/confirm/导航等）不回归（按钮化后选择器若变化需同步适配）；`npx vitest run tests/frontend` 全绿。
3. 人工冒烟：纯键盘完成一次"切换页面 → 触发动作 → 确认"流程。
4. 本任务提交为 `fix(frontend): ...` 或 `refactor(frontend): ...` 单提交，符合 commit 规范。
