# 待办与日程类目映射回归补充

## 1. 文档目的

本补充文档聚焦 `todo` 与 `schedule` 两个业务域的类目映射闭环，用于弥补总回归文档中“以收支为主线”的阅读视角，让开发、测试、联调时可以更快定位这两个域的关键回归场景。

适用场景：

- `task029-033` 范围内的待办/日程类目映射改动
- 回归脚本扩充后，对 `todo` / `schedule` 主链路做专项复核
- 前端确认流联调时，专项核对待办/日程分支行为

## 3. 专项回归清单

### 3.1 待办域

#### TC-003 待办命中既有类目

- 用户输入：`帮我记个待办，今晚复习英语，放到学习类`
- 预期策略：`allow`
- 预期工具：`todo.create`
- 预期结果：待办成功创建，类目命中 `学习`
- 关键日志：`category_mapping_resolved`

#### TC-029 待办更新时重新映射类目

- 前置：已有一条 `生活` 类待办
- 用户输入：`把这个待办改到学习类`
- 预期策略：`allow`
- 预期工具：`todo.update`
- 预期结果：原标题保留，仅类目切换为 `学习`
- 关键日志：`category_mapping_resolved`

#### TC-031-TODO-CREATE 待办新增类目确认恢复

- 用户输入：`新增一个给猫买驱虫药的待办，类目没有就新建宠物护理`
- 预期策略：`confirm`
- 预期确认后动作：`todo_category.create` -> `todo.create`
- 预期结果：成功创建 `宠物护理` 类目，并恢复写入待办
- 关键日志：`category_creation_approved`、`category_action_resumed`

#### TC-031-TODO-UPDATE 待办更新类目确认恢复

- 前置：已有一条 `生活` 类待办
- 用户输入：`把这个待办改到宠物护理，没有就新建`
- 预期策略：`confirm`
- 预期确认后动作：`todo_category.create` -> `todo.update`
- 预期结果：原待办标题与其他字段保留，类目切换为 `宠物护理`
- 关键日志：`category_creation_approved`、`category_action_resumed`

#### TC-031-TODO-REJECT 待办新增类目被拒绝

- 用户输入：`新增一个给猫洗澡的待办，类目没有就新建宇宙远足`
- 预期策略：`confirm`
- 用户操作：拒绝新增类目
- 预期结果：不创建类目，不创建待办
- 关键日志：`category_creation_rejected`

### 3.2 日程域

- 预期策略：`allow`
- 预期工具：`schedule.update`
- 预期结果：原标题、地点等字段保留，仅类目切换为 `提醒`

#### TC-031-SCHEDULE-CREATE 日程新增类目确认恢复

- 关键日志：`category_creation_approved`、`category_action_resumed`

#### TC-031-SCHEDULE-UPDATE 日程更新类目确认恢复

- 用户输入：`把这个日程改到宠物医疗，没有就新建`
- 预期策略：`confirm`
- 预期确认后动作：`schedule_category.create` -> `schedule.update`
- 预期结果：原标题、地点等字段保留，类目切换为 `宠物医疗`
- 关键日志：`category_creation_approved`、`category_action_resumed`

#### TC-031-SCHEDULE-REJECT 日程新增类目被拒绝

- 预期策略：`confirm`
- 用户操作：拒绝新增类目
- 预期结果：不创建类目，不创建日程
- 关键日志：`category_creation_rejected`

### 3.3 跨域统一策略

#### TC-032 各域只读补查轮控统一

- 目标：验证 `todo`、`schedule` 与 `ledger` 共用同一套“单域一次补查”语义
- 预期结果：
  - `todo` 第一次补查允许，第二次同域补查阻止
  - `schedule` 第一次补查允许，第二次同域补查阻止
  - 一个域用掉补查后，不影响其他域首次补查

## 4. 联调时的重点观察项

- 待办与日程域的确认卡文案是否与实际工具动作一致
- 拒绝新增类目后，前端是否明确展示“未写入”
- 恢复执行后，最终回复是否能准确说明“新建了类目并继续完成动作”
- 待办与日程域是否错误复用了收支域的类目语义
