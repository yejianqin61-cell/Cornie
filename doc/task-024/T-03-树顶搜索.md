# T-03 树顶搜索（Memory Wiki Tree Search）

## 背景

Cornie-024 ID-5：树顶部搜索框，对标题/别名/摘要模糊匹配；树按命中结果呈现，清空恢复完整树。

## 目标

1. 搜索框（容器顶部，T-02 占位处接入）。
2. 命中：标题 / aliasesText / summary 模糊匹配（`includes`，大小写不敏感）。
3. 搜索态：树切换为"搜索结果"平铺（或命中的目录自动展开 + 命中项高亮）；空结果简短空态。

## 范围

- `src/renderer/components/`（T-02 容器或树组件内接入搜索态）
- `tests/frontend/memory-wiki-tree.test.mjs` 或 `memory-wiki-home.test.mjs` 扩展

## 设计要求

### 1. 搜索输入

- 防抖（复用 `useDebouncedValue`，220ms）；搜索词非空时进入搜索态。
- 命中字段：`title`、`aliasesText`（别名，逗号分隔文本内匹配）、`summary`。

### 2. 搜索态呈现

- 方案：命中的页面平铺为"搜索结果"列表（含所在类型小标）；点击命中项 → select 该页面（右侧加载正文），搜索框保留。
- 或方案 B：完整树保留，命中的目录自动展开并高亮命中文件（实现成本略高）。任选其一，推荐方案 A（平铺）先行。
- 空结果：简短空态（如"没有找到相关的记忆"）。

### 3. 退出搜索

- 清空搜索词 → 恢复完整树（保持原展开/选中状态）。

## 验收标准

1. 测试通过：标题命中、别名命中、摘要命中各一例；不命中（空结果）；清空恢复完整树。
2. 点击搜索结果 → 右侧加载对应页面。
3. `npx vitest run tests/frontend` 全绿。
4. 提交为 `feat(frontend): ...` 单提交，符合 commit 规范。
