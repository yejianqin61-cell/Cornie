# T-02 双栏容器与右侧正文接入（Memory Wiki Split View）

## 背景

Cornie-024 ID-1/ID-6/ID-7：双栏容器（左树右文）替代当前"列表视图 → 详情视图"跳转。右侧复用 R-06 详情两态组件；选中树节点即加载正文；新建在右侧开空编辑页；删除/归档后树与右侧联动。

## 目标

1. 新建双栏容器：左 = T-01 文件树，右 = 详情两态组件。
2. 选节点 → 右侧加载正文（阅读态）；编辑/保存/取消沿用 R-06。
3. 新建记忆 → 右侧空编辑页；创建后树更新并选中新页。
4. 删除/归档 → 树与右侧同步（移除节点，右侧回空/上一节点）。

## 范围

- `src/renderer/components/` 下新建双栏容器（如 `MemoryWikiHome.vue`）
- `src/renderer/App.vue`（memory mode 挂载改为容器；移除 memory-detail/memory-create 子视图切换，或容器内处理）
- 数据加载（容器一次性拉全量页面：active + archived）
- `tests/frontend/` 新增 `memory-wiki-home.test.mjs`

## 设计要求

### 1. 布局与数据

- 容器顶部栏：标题"记忆 Wiki" + 搜索框占位（T-03 接入）+ "新建记忆"主按钮。
- 数据：进入容器拉全部页面（`listMemoryWikiPages` 大 limit 或循环拉全，含 archived）；`emitDataChanged`/容器刷新保持树与右侧一致。
- 布局：左树固定宽（可拖拽调宽为可选增强，本任务先固定），右正文 flex 填充；树滚动独立。

### 2. 右侧正文接入

- 选中树节点 → 右侧渲染详情两态组件（props `id`）；R-06 的 back/created/deleted/open-* emits 适配：
  - back：树内场景不需要（隐藏或清空选中回树）。
  - created：创建成功后刷新树并选中新页。
  - deleted：刷新树，右侧清空（或选上一节点）。
  - open-memory：树内选中对应节点。
  - open-observation / open-chat-source：维持 App 级跳转（容器转发 emit 到 App）。
- 未选中时右侧空态（简短文案或引导"从左边选一页"）。

### 3. 新建

- "新建记忆" → 右侧进入新建模式（详情两态 isCreateMode，R-06 已有）；创建成功后树刷新 + 新页出现在对应类型目录。

### 4. 状态

- 当前选中 id、展开目录在容器内保持；切换导航再回来时恢复（组件内 state 即可，跨会话持久化归 T-05）。

## 验收标准

1. 新增 `memory-wiki-home.test.mjs` 通过：
   - 选树节点 → 右侧详情组件收到正确 id（加载正文）。
   - 新建 → 右侧新建模式；创建成功 → 树含新页且选中。
   - 删除 → 树移除该节点、右侧清空。
   - 归档 → 树中移到"已归档"目录。
2. 既有 memory-page-user-flow（详情两态）不回归；`npx vitest run tests/frontend` 全绿。
3. App.vue 导航适配后 app-navigation 测试通过。
4. 提交为 `feat(frontend): ...` 单提交（可拆 2 个：容器+接线 / App 挂载适配，各保持全绿），符合 commit 规范。
