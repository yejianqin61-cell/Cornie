# T-01 文件树组件（Memory Wiki File Tree）

## 背景

Cornie-024 目标态：记忆 Wiki 改为 VSCode 式双栏（左树右文）。本任务实现**文件树组件**本身——输入扁平页面列表，输出可折叠/可选中/带归档灰显的树（ID-2/ID-3/ID-4）。

用户已确认：一级类型目录；树取代 Tab/分页；已归档独立目录灰显。

## 目标

1. 新建树组件：`type → pages[]` 树构建、目录折叠/展开、节点选中高亮、空目录占位。
2. 类型目录顺序固定（身份 4 类 → 普通类型 → 已归档）。
3. 已归档目录独立、文件灰显。

## 范围

- `src/renderer/components/` 下新建文件树组件（如 `MemoryWikiTree.vue`）
- `tests/frontend/` 新增 `memory-wiki-tree.test.mjs`

## 设计要求

### 1. 组件接口

- props：`pages`（扁平页面数组，含 `{ id, title, pageType, status, aliasesText?, summary? }`）、`selectedId`、`expandedKeys`（可选受控）。
- emits：`select(page)`（点击文件）、`toggle(key)`（折叠/展开目录）、可选 `create()`（空目录/顶部新建）。
- 纯展示组件：**不做数据请求**，由容器喂数据（T-02）。

### 2. 树构建与目录顺序

- 顶层目录 key/顺序：`identity_profile`（关于你）、`identity_person`（重要的人）、`identity_preference`（你的偏好）、`identity_trait`（你的特征）→ 普通类型固定序（event/topic/goal/project/routine/need）→ 最后 `archived`（已归档，收 `status==='archived'` 的页面，含身份与普通类型）。
- 目录内文件按标题排序（localeCompare）或按更新时间（取后者优先，标题相同时）。
- 空目录（该类型无页面）显示占位（如"（空）"弱化小字），仍可展开（展开后是空态行）。

### 3. 交互

- 目录点击 → 仅切换展开状态（emit toggle），不选中内容。
- 文件点击 → emit select(page)；选中节点高亮。
- 折叠/展开默认：身份 4 类展开，普通类型折叠，已归档折叠（或由容器传 expandedKeys 控制）。

### 4. 归档灰显

- `archived` 目录内文件样式灰显（--muted + 减弱背景），点击仍 emit select（右侧只读由 T-02 处理）。

### 5. 视觉

- 树样式贴近文件树（目录 `📁` 展开/`📂` 折叠，文件 `📄`）；缩进层级；hover 高亮；选中高亮（accent 色）。
- 高度撑满左侧面板，超出滚动。

## 验收标准

1. 新增 `memory-wiki-tree.test.mjs` 通过：
   - 树结构：类型分组正确、顺序固定（身份在前、归档最后）。
   - 空目录占位显示；展开/折叠切换 emit toggle。
   - 文件点击 emit select 且选中高亮 class。
   - 归档目录文件灰显 class、点击可 select。
2. `npx vitest run tests/frontend` 全绿（新组件不影响既有）。
3. 提交为 `feat(frontend): ...` 单提交，符合 commit 规范。
