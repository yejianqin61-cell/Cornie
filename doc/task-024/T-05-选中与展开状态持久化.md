# T-05 选中与展开状态持久化（Tree State Persistence）

## 背景

Cornie-024 ID-7：文件树的目录展开状态与当前选中页面在会话间保持——用户切走再回记忆 Wiki，仍停留在上次的位置（VSCode 式体验）。

## 目标

1. 目录展开状态写入 localStorage（按 key 记忆）。
2. 上次选中的页面 id 记忆；重新进入容器时恢复选中并加载正文。
3. 页面被删除/归档后，记忆的选中 id 失效时静默回退（不报错）。

## 范围

- `src/renderer/components/`（T-02 容器内接入）
- `tests/frontend/`（容器测试扩展）

## 设计要求

### 1. 存储

- localStorage key（如 `cornie.memory-wiki.tree`）：`{ expanded: string[], selectedId: string }`。
- 读写容错（localStorage 不可用时静默跳过）。

### 2. 恢复

- 容器挂载：读取存储 → 恢复展开目录 → 若 selectedId 仍存在于加载的页面列表则自动选中并加载右侧正文。
- 目录展开与选中变更时写回（防抖或直接写）。

### 3. 失效回退

- selectedId 不在页面列表（已删/归档隐藏？归档仍在树中，仅删除后失效）→ 清空 selectedId，右侧回空态，不报错。

## 验收标准

1. 测试：设置展开/选中 → 重新挂载容器 → 状态恢复（展开目录、选中页加载）；删除后选中失效回退空态。
2. `npx vitest run tests/frontend` 全绿。
3. 提交为 `feat(frontend): ...` 单提交，符合 commit 规范。
