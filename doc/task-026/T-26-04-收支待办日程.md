# T-26-04 收支 / 待办 / 日程模块组件化

## 范围文件

- `components/LedgerHome.vue`（hex×12、长文案×6——本模块最重）
- `components/LedgerCalendar.vue`
- `components/TodoHome.vue`（hex×7、fontPx×12）
- `components/ScheduleHome.vue`（fontPx×12）
- `components/ScheduleCalendar.vue`

## 改造清单

### 组件化（R5）
1. LedgerHome 的图表卡、类目管理卡、表单区换 `<UiCard>`；新增/编辑/删除按钮换 `<UiButton>`；类目徽标换 `<UiBadge>`；
2. TodoHome 的列表卡与已完成区换 `<UiCard>` + `<UiEmpty>`；完成/恢复按钮 `<UiButton>`；
3. ScheduleHome 日程列表与表单同理；两个日历组件保持自绘格子但颜色走 token。

### Token（R1/R2）
4. LedgerHome 12 处 hex（图表色板 `chartColors` 为 JS 数据，改引用 CSS 变量名字符串或集中到 tokens 派生数组并加注释豁免——二选一在实现时定）；rgba 边框/背景 → color-mix；
5. TodoHome 12 处、ScheduleHome 12 处像素字号 → token。

### 文案（R3）
6. 「这个类目名现在还不太合适，换一个更清楚的名字试试吧。」→「类目名不合适，换一个吧」（≤24 字原则内尽量更短）；
7. 「这里会收好已经完成的事情，想重新捡起来也很方便。」→「已完成的待办」；
8. 「先把眼前还没做完的小事放在最前面，铃湾会陪你一件件看。」→ 删除或「先做眼前的事」；
9. 「先看支出结构，比较容易一眼发现最近的花销重心。」「先从这个月的节奏看起，想看某一天就点上面的日期。」→ 删除（导航引导由布局自明）。

### 去堆叠（R4）
10. LedgerHome 图表卡内部的图例块、表单卡的输入分区分隔线化，不再套第二层盒子。

## 验收标准

1. 门禁注册后 R1–R5 全绿；
2. 既有 ledger/todo/schedule 相关测试全绿；
3. `npm run lint` 0 错误。
