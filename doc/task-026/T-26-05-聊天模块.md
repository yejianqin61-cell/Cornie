# T-26-05 聊天模块组件化

## 范围文件

- `components/ChatHome.vue`（fontPx×12）
- `ChatHistory.vue`（fontPx×8）
- `components/ChatDayView.vue`
- `CornieComposer.vue`（rgba×10；桌宠输入条，注意小窗语境）
- `components/ToolResultPanel.vue`（fontPx×7）
- `components/ConfirmCard.vue`（hex×4、rgba×11、长文案）
- `components/AskBackBubble.vue`

## 改造清单

### 组件化（R5）
1. ConfirmCard 的主/次操作按钮换 `<UiButton>`（primary/danger 语义映射）；
2. ToolResultPanel 容器换 `<UiCard>` 或去卡分区（工具结果本身是弱信息层，倾向**去卡**：仅分隔线+等宽文本块）；
3. ChatHome 的快捷入口/历史入口按钮换 `<UiButton variant="ghost">`；
4. AskBackBubble 保持气泡自绘，但颜色走 token。

### Token（R1/R2）
5. ConfirmCard 4 hex + 11 rgba → 语义 token/color-mix；
6. 各文件像素字号 → token。

### 文案（R3）
7. 「这件事继续做下去之前，铃湾想先征求你的同意。」→「需要你确认后继续」；
8. CornieComposer 的注释性文案「铃铛布局已从配置固化…」为代码注释则保留；若出现在界面上一律删除。

### 去堆叠（R4）
9. 聊天日的消息气泡不套卡片；ConfirmCard 在消息流中保持单层凸出（阴影一层），内部不再有边框盒。

## 验收标准

1. 门禁注册后 R1–R5 全绿；
2. `confirm-card.test.mjs`、`chat-history.test.mjs`、`cornie-composer.test.mjs`、`stream-send.test.mjs` 等聊天相关测试全绿；
3. `npm run lint` 0 错误。
