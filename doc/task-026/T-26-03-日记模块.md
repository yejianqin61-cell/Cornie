# T-26-03 日记模块组件化

## 范围文件

- `components/DiaryHome.vue`（fontPx×14）
- `components/DiaryEditor.vue`（fontPx×14）
- `components/CornieDiaryReview.vue`（长文案×2）
- `components/OnThisDayPage.vue`

## 改造清单

### 组件化（R5）
1. DiaryHome 的「今天」卡、日期列表卡换 `<UiCard>`；入口按钮换 `<UiButton>`；
2. DiaryEditor 顶部动作区按钮换 `<UiButton>`；往年今日区块内层去卡；
3. CornieDiaryReview / OnThisDayPage 空态与错误占位换 `<UiEmpty>`。

### Token（R1/R2）
4. DiaryHome + DiaryEditor 共 28 处像素字号 → token；其余 hex/rgba 同理。

### 文案（R3）
5. 「这个月铃湾还没开始写日记呢，去和她说说话吧。」→「这个月还没有日记」；
6. 「这篇日记翻出来的时候有点小打结了，等铃湾缓一缓再陪你看。」→「加载失败，请稍后再试」。

### 去堆叠（R4）
7. 「今天」卡内的状态行不再包第二层底色盒。

## 验收标准

1. 门禁注册后 R1–R5 全绿；
2. `app-diary-flow.test.mjs` 全绿；
3. `npm run lint` 0 错误。
