# T-26-06 设置模块与壳层组件化

## 范围文件

- `App.vue`（hex×5、rgba×6、fontPx×11——壳层样式）
- `components/SettingsHome.vue`（长文案×3）
- `components/DeepseekConfig.vue`
- `components/AdvancedSettings.vue`

## 改造清单

### 组件化（R5）
1. App.vue 左侧导航项与顶部栏保持自绘（壳层身份），但配网引导表单按钮换 `<UiButton>`；
2. SettingsHome 的三张入口卡换 `<UiCard>` + `<UiButton>`；
3. DeepseekConfig 表单按钮换 `<UiButton>`；状态徽标换 `<UiBadge>`；
4. AdvancedSettings 入口网格换 `<UiCard>`。

### Token（R1/R2）
5. App.vue 壳层的 statusDot 绿 `#5b9a6b` → `var(--color-success)`；guideBanner 底色 → tint token；其余 rgba → color-mix；
6. fontPx 11 处 → token。

### 文案（R3）
7. 「你的数据保存在本地。当你和铃湾对话时，内容会发送给…」→「数据保存在本地；对话内容会发送给模型服务。」（压缩到事实陈述）；
8. 「包含高级模式和复杂治理功能，普通用户不需要进入。」「这些功能面向高级用户，包含复杂治理和系统管理能力。」→ 合并为「面向高级用户」一处，另一处删除；
9. 「铃湾会尽量少带无关内容，但对话本身需要联网。」→ 删除（联网事实已在上一句）。

### 去堆叠（R4）
10. AdvancedSettings 的入口卡在选中态不再叠边框+底色双层强调（只保留一种）；设置页内面板容器去掉第二层卡。

## 验收标准

1. 门禁注册后 R1–R5 全绿；
2. `app-settings-flow.test.mjs`、`app-navigation.test.mjs`、`app-smoke.test.mjs` 全绿；
3. `npm run lint` 0 错误。
