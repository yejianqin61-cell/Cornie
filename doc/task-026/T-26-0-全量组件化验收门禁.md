# T-26-0 全量组件化验收门禁与文案红线

## 背景

Cornie-027 目标：UI 布局全量组件化。本任务先建立**可机器验收的门禁**，后续每个子任务完成后跑同一脚本，避免"改完靠感觉"。

用户四条硬要求：

1. 全量使用组件库组件（`components/ui/*`）；
2. token 设计符合约定（`styles/tokens.css` 刻度，禁止裸值）；
3. 前端文案不允许繁杂，不允许出现「叙述功能机制」的文本（那是设计文档的事）；
4. 组件、卡片不允许有堆叠感（卡中卡）。

## 门禁规则（scripts/verify-task026.mjs 实现）

对 T-26 系列声明覆盖的每一个文件检查：

| # | 规则 | 判定 |
| --- | --- | --- |
| R1 | 样式中禁止裸色值：`#[0-9a-fA-F]{3,8}` 与 `rgba?(…)` 字面量 | 0 处（`var(--*)`/`color-mix(var)` 不受限） |
| R2 | 样式中禁止像素字号：`font-size:\s*\d+px` | 0 处（一律 `var(--text-*)`） |
| R3 | 模板中文案长度：连续汉字串（含标点）≥ 24 字 | 0 条（错误提示类允许 ≤24 字的短句） |
| R4 | 卡中卡：`.uiCard`/`.card` 类元素的直接子层不得再出现 `class` 含 `card` 的元素 | 0 处 |
| R5 | 组件库使用：按钮一律 `<UiButton>` 或全局语义 class（primary/danger/ghost）；卡片容器一律 `<UiCard>`；空态一律 `<UiEmpty>` | 按 T-xx 任务声明的文件清单核对 |

> 豁免：`CorniePet.vue`（桌宠小窗有独立 `pet-*` token 体系，本系列不覆盖）；注释里的文字不受 R3 限制。

## 验收标准

1. `node scripts/verify-task026.mjs` 存在且可运行；未覆盖文件时输出 `(no modules registered)`。
2. 每完成一个 T-26 子任务，把该任务覆盖的文件注册进门禁并全绿。
3. `npm run lint` 保持 0 错误。

## 依赖

无（先行）。T-26-01 起每个子任务完成时在门禁注册表登记其文件清单。
