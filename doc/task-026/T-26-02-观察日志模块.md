# T-26-02 观察日志模块组件化

## 范围文件

- `components/ObserveMemoryHome.vue`（fontPx×13、长文案）
- `components/ObservationList.vue`（rgba×13、fontPx×22、长文案×5）
- `components/ObservationDetail.vue`（fontPx×9、长文案×7）

## 改造清单

### 组件化（R5）
1. 列表页的分组卡片容器换 `<UiCard>`；行条目保持 `entryRow` 结构但按钮语义统一；
2. 详情页操作按钮（编辑/保存/删除）换 `<UiButton>`；空态换 `<UiEmpty>`；
3. 首页的「当天观察」摘要卡换 `<UiCard>`。

### Token（R1/R2）
4. ObservationList 22 处像素字号 → `var(--text-*)`；ObserveMemoryHome 13 处、ObservationDetail 9 处同理；
5. rgba 分组背景/边框 → token 或 color-mix。

### 文案（R3）
6. 删除机制解释，例如：
   - 「铃湾不会把每句闲聊都记下来，只有觉得值得留一下的时候，才会写进观察。」→ 整句删除（机制说明属于设计文档）；
   - 「要把这条小事删掉吗？删掉后，它就不会再留在观察里了。」→「确认删除这条观察？」
   - 「可以写这件事是什么时候发生的、当时有什么细节、为什么值得留一下。」等 placeholder →「时间与细节」/「发生了什么」/「当时的感受」；
   - 「防抖搜索接入统一定时器工具…」为注释，保留不受限。

### 去堆叠（R4）
7. 详情页内部信息分区去掉嵌套边框盒；列表分组头不再套卡。

## 验收标准

1. 门禁注册后 R1–R5 全绿；
2. 相关测试全绿（断言若绑定被删文案则同步更新）；
3. `npm run lint` 0 错误。
