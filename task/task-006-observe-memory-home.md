# task-006 观察与记忆首页重构

## 目标

将当前 `MemoryWikiWorkspace` 重做为面向普通人的「观察与记忆」首页。这是最容易做歪的模块——必须从治理台变成"生活片段记录入口 + 重要回忆回看入口"。

## 背景

当前 `MemoryWikiWorkspace.vue` 暴露了 Memory Wiki 的页面列表、主题索引等后台式结构。设计文档明确要求：
1. 合并"观察"和"记忆"为普通用户能理解的概念
2. 不暴露 Topic、Index、版本、治理等内部结构
3. 首页应该像"生活片段记录本" + "回忆和偏好笔记页"

## 变更规格

### 首屏结构（4 个区块，严格按此顺序）

```
1. 今天的小事与想记住的事（温和说明引导区）
2. 快速记一条观察
3. 最近观察（最近几条）
4. 重要记忆入口（几条最重要的长期记忆）
```

### 区块一：今天的小事与想记住的事

- 一句温和引导说明
- 文案示例："这里是你想记住的生活小事。铃湾也会帮你把重要的东西记下来。"
- 引导用户理解这不是技术模块，而是记录模块
- 背景使用 `var(--memory-tint)` 浅蓝底

### 区块二：快速记一条观察

- 标题/一句话输入（单行 input）
- 保存按钮（`var(--accent)`）
- 不需要复杂表单
- API：调用 `POST /api/observations`（如不存在则需后端配合或复用现有 API）

### 区块三：最近观察

- 最近 5-8 条观察记录
- 每条：标题 + 日期 + 简短摘要
- "查看全部观察" 入口 → 观察记录列表页 (task-007)
- 空状态："还没有记下什么，要记一件小事吗？"

### 区块四：重要记忆入口

- 3-5 条最重要的长期记忆（按 importance/weight 排序）
- 每条：标题 + 简短摘要
- "查看更多记忆" 入口 → 记忆页列表 (task-008)
- 空状态："铃湾还在慢慢记住重要的事"

**禁止出现在首页**：
- 来源结构图
- 关系网络图
- 治理候选
- Topic 热度
- 版本系统
- 巡检结果
- 页面合并/回滚
- 批量治理入口

## 验收条件

1. 首页有温和引导语，不像技术模块
2. 可以快速输入一条观察
3. 显示最近观察记录
4. 显示重要记忆入口
5. 无 Topic、Index、版本、治理相关内容
6. 视觉使用 `var(--memory-tint)` 浅蓝底调
7. 可以跳转到观察列表页和记忆列表页
