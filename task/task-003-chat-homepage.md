# task-003 聊天首页重构

## 目标

将聊天首页打造为整个产品的绝对主入口——一个让人愿意开口说话、感到被陪伴的界面。

## 背景

当前项目没有独立聊天首页。聊天功能仅存在于桌宠窗口 `CorniePet.vue`。本次重构要求在 MainWindow 中也提供完整的聊天体验，作为一级导航第一项和默认入口。

## 变更规格

### 首屏结构（严格按此顺序）

```
1. 顶部陪伴区
2. 主对话区
3. 输入区
4. 少量待确认提示（仅在有待确认时出现）
```

### 顶部陪伴区

- 铃湾当下的简短问候（如"下午好，今天过得怎么样？"）
- 当前日期或时间感
- 一句极短的陪伴语
- 使用聊天模块浅珊瑚色底 (`var(--chat-tint)`)
- **禁止**：模型状态信息、工具能力说明、复杂统计

### 主对话区

- 显示最近对话消息列表
- 只显示**最终回复**，不显示工具执行中间过程
- 用户消息靠右，Cornie 回复靠左
- 区分消息气泡样式
- 空状态文案：温和引导"想和我聊点什么？"
- **禁止**：工具流水卡瀑布、长篇透明说明、调用过程

### 输入区

- 输入框（textarea 自适应高度）+ 发送按钮
- 发送按钮使用 `var(--accent)`（柔和珊瑚色）
- 可选：2-3 个灵感提示词（如"帮我记一笔开销"、"今天心情怎么样"）
- **禁止**：复杂工具栏

### 待确认提示

- 仅当存在待确认事项时显示
- 极短卡片："有 1 条待确认事项" → 点击跳转待确认页
- **禁止**：常驻大面板、系统通知堆叠

### API 复用

聊天核心逻辑可从 `CorniePet.vue` 提取复用：
- `sendMessage()` → 发送消息
- `appendResponse()` → 处理响应
- 消息列表数据结构

建议抽取 `src/renderer/composables/useChat.js`，供 `ChatHome.vue` 和 `CorniePet.vue` 共用。

### 样式约束

- 背景使用 `var(--chat-tint)` 极浅暖调
- 卡片使用 `var(--surface)`
- 强调色使用柔和珊瑚 (`var(--accent)`)
- 留白充足，单屏信息密度低
- **禁止**：深色底、玻璃拟态、紫色

## 验收条件

1. 聊天首页是默认打开的一级页面
2. 顶部显示铃湾问候语和当前日期
3. 可以输入文字发送，看到 Cornie 回复
4. 用户气泡靠右，Cornie 气泡靠左
5. 工具调用过程不显示在对话区
6. 有待确认事项时底部出现轻提示卡片
7. 视觉温和、有陪伴感，不像后台系统
8. `CorniePet.vue` 聊天功能不受影响
