# task-007 观察记录列表与详情页

## 目标

构建观察记录列表页和详情/编辑页。观察模块应像"生活片段记录本"，不是"事实素材治理台"。

## 背景

当前项目有 `observation_logs` 表和相关 API，但前端没有独立的观察记录浏览页。需新建。

## 变更规格

### ObservationList.vue — 观察记录列表页

**内容**：
- 回到观察与记忆首页的导航
- 按日期分组的观察记录列表
- 每条：标题、日期、类型标签、简短摘要
- "新增观察" 按钮
- 加载/空状态
- 点击进入详情

**不应出现**：
- 与记忆、聊天、Topic 的复杂关系
- "被用于素材" 的提示
- 去重与调整过程
- 来源归一化过程

**API**：如无现有 API，需新增 `GET /api/observations`、`POST /api/observations`

### ObservationDetail.vue — 观察记录详情/编辑页

**内容**：
- 标题编辑
- 内容编辑（textarea）
- 日期
- 类型选择
- 保存 / 删除 按钮
- 简短边界说明（如"这会帮助铃湾更好地了解你"）

**不应出现**：
- 关联页面网络
- 记忆回流提示
- 来源追溯

**样式**：
- 浅色卡片
- 编辑区留白充足
- 按钮遵循全局规范

## 验收条件

1. 观察记录列表可按日期浏览
2. 可新增观察记录
3. 可编辑/删除已有观察
4. 列表页和详情页之间导航正常
5. 无技术治理内容暴露
6. 视觉符合新设计语言
